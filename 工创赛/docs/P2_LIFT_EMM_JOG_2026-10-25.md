- HARDWARE/LIFT/lift_protocol.c/h：纯报文编码，拒绝越界方向或超过16的脉冲。

2. g_vm_test_request=1并保持外部VM开关允许，等约3秒完成原自动身份读取。
3. Watch中g_lift_motion_request=1一次：方向0、5RPM、16个相对脉冲。不反复写1，不自动往返。
4. 回报机构实际方向/驱动器角度是否变化；若需要停止，request=3。方向0确认后才按需要试request=2（方向1）。新位置改变可能很小，可同时看驱动器显示角度。

返回只代表相应控制层事实：

| 变量 | 含义 |
|---|---|
| g_lift_state=4 | 已完成原版本/状态读取 |
| g_lift_motion_state=1～6 | 自动准备或运动反馈监测 |
| g_lift_motion_state=7 / result=1 | 新位置改变、驱动到位位且速度为0；仍需实际观察方向/机构 |
| state=8 / result=2 | 用户停止命令已得到应答，尚不是独立机械停止测量 |
| state=9 | 失败已锁存，不自动重新运动 |
| motion_result=3 | 3秒超时，已尝试发停止 |
| result=4 / 5 / 6 | 通讯或格式/固件不符、驱动保护、尚未就绪或失去供电条件 |
| g_lift_move_result | FD命令交换结果，1不是动作完成 |
| g_lift_stop_result | FE停止命令交换结果，1不是独立机械停止验证 |
| g_lift_delta_raw | 前后编码位置计数差，不是毫米 |

若失败，发g_lift_motion_state/result、g_lift_move_result、g_lift_stop_result和实际现象即可，再定向处理；无需先补波形/电平验证。失败后先request=3明确停止成功或重新供电/建立身份会话，再继续，不靠自动重试动作。停止命令不等于断电/松轴，代码不主动发失能。
