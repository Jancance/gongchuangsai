# Batch 2 Analysis（2.333–4.300 s）

视频：`c6261eae4770681730127531a7efc43c.mp4`。母任务提供的视频元数据为4.333333 s、130帧、30 fps。本批逐张查看7张抽帧；以下是可见现象描述，不是连续逐帧测量。

## 基线检查与证据边界

已读取 `docs/competition_requirements_2027.md`。本报告属于 **E：工程参考素材观察**，不改变R规则、不形成项目实车验收结论。

已检查需求 ID：MOT-01～MOT-04、LOC-02/06/07、MECH-03、FIELD-02/04/05/06、OBS-04、RUN-01。

- **R**：RUN-01的自主运行、FIELD-02的同启停区返回、FIELD-06的车体包络约束和OBS-04的400 mm车道要求均不能由本批抽帧证明。该参考场地的可见布置不等于本项目2027规则场地。
- **E**：视频可辅助描述平移及朝向变化的外观效果，不能证明MOT-01～04或LOC-07已闭环。本项目仍按MOT-04从完整装机载物开始，不从视频中的三个空白圆托盘推导空底盘测试顺序。
- **Q**：FIELD-05官方回区最终判定标准仍为“待技术答疑确认”。画面末段位置不能替代该项确认。
- **未闭环**：固定机位/地面标定、连续位姿测量、同步轮速/航向/指令日志、控制来源、载物稳定性及末尾持续停稳均缺失。
- **验证证据**：使用图像查看工具实际查看本报告列出的7张JPEG；时间戳来自母任务的抽帧清单。没有执行硬件试验。

## Frame-by-Frame

### Frame 0008（2.333 s）

- **SCENE**：斜俯视室内场地。灰色地垫上有浅黄色方形区、印字白色边带和数字圆环；机器人位于画面下部偏左，靠近近侧的1/2/3圆环带。场地远处还有红、绿等色的小物体及圆形台面。
- **CONTENT**：机器人有四轮底盘、升起的结构/机械臂、连线和三个白色圆形托盘；托盘上未见明确物料。显示器有亮色画面但文字无法辨读。近侧圆环可辨1、2、3，边带中文字为部分可见。
- **ACTION**：本批第一帧仅建立位置参考，不能单帧判断速度。机器人白色托盘侧朝画面右下，升起结构位于其左上侧，臂端朝画面右上。
- **DETAILS**：车体主要外廓可见，内部和轮子部分被自身结构遮挡。地垫有褶皱，未提供毫米标定；不可根据画面像素换算车体尺寸或车道余量。

### Frame 0009（2.667 s）

- **SCENE**：同一场地，机器人仍靠近近侧圆环带，构图已有小幅变化。
- **CONTENT**：三个白色托盘、升起机构、线束和四轮底盘仍可见；亮屏内容仍不可读。边带上的红、绿物体以及圆环位置仍可用于定性比较。
- **ACTION**：与0008相比，底盘在画面中略向上移动。投影朝向大体相同，未出现可明确确认的大幅转头。画面背景位置也有变化，不能将这点屏幕位移全部解释成车体平移。
- **DETAILS**：没有看到人手直接接触机器人，但操作者和控制装置不在完整视野内，不能据此确认自主运行。机械臂姿态总体保持展开。

### Frame 0010（3.000 s）

- **SCENE**：机器人转移到画面中部偏左，正在远离近侧1/2/3圆环带，浅黄色方形区在其右上侧。
- **CONTENT**：白色托盘侧仍主要朝画面右下，臂端继续在车体的右上侧；屏幕亮着，无可读控制文字。地垫褶皱、划痕及边带均可见。
- **ACTION**：与0009相比，车体位置明显向画面左上迁移，而且相对于近侧圆环带也发生位移，支持存在真实地面平移。车体大体保持同一侧朝向，外观更接近斜向/侧向移动；不能从此帧判定滑胎或“漂移”力学过程。
- **DETAILS**：背景边带和远处物体同时移位，说明相机视角正在调整。不能用屏幕轨迹直接量出实际运动方向、速度或旋转角速度。

### Frame 0011（3.333 s）

- **SCENE**：机器人来到画面左侧灰色区域，进一步远离近侧圆环带，靠近远侧印字边带；相机视野向左上侧跟随。
- **CONTENT**：底盘及白色托盘侧仍可见，机械臂保持举起/伸出。红色物体位于机器人后上方边带附近；浅黄色方形区在右侧。
- **ACTION**：车体继续朝场地左上侧转移，没有出现清楚的“停在一个点后大幅原地转向”画面。托盘侧前缘在画面中的倾斜略有改变，但拍摄视点也在变化，不能把这项变化全归因于真实车体旋转。
- **DETAILS**：仍没有明显外物遮住整个车体；车轮/线束等存在自身遮挡。四轮底盘的各轮转速和滚动方向不能由静态JPEG可靠读取。

### Frame 0012（3.667 s）

- **SCENE**：机器人位于场地左上侧，离左边界带和远侧印字带较近；画面有更多室内地面、箱体及座椅背景。
- **CONTENT**：三个白色托盘侧仍朝向画面下方偏右；臂端在机器人上方偏右。远侧有绿色小物体和三枚数字圆环，近侧圆环带已经在较远下方。
- **ACTION**：与0011相比，机器人继续向左上侧平移，但画面中相邻抽帧的位移幅度在变小。由于相机跟随和透视同时改变，不能仅据此认定实车正在定量减速。
- **DETAILS**：可以确认机器人已接近这段边界附近，但无法仅凭斜视画面确认整个车体铅垂投影与边带的精确关系，也不能认定本项目车道约束已通过。

### Frame 0013（4.000 s）

- **SCENE**：机器人位于场地左上部，靠近红色小物体所在的印字边带；构图继续轻微跟随。
- **CONTENT**：白色托盘侧、底盘正面框架、亮屏、上部机构和线束仍可见。边带部分可辨“中国大学生工程实践”字样；这些字样只描述参考视频内容，不用于规则判定。
- **ACTION**：与0012相比，车体在画面中的位置变化较小，托盘侧前缘看上去比前面更接近横向。可能包含少量朝向调整，但拍摄视点变化也会产生此投影变化，不能确认旋转量或严格判定平移与旋转同时执行。
- **DETAILS**：未见抓取或放置动作，三个圆托盘上没有清楚可辨的搬运物料。不能据此推定空载质量、惯量或控制参数。

### Frame 0014（4.300 s）

- **SCENE**：末帧仍为场地左上部的机器人，附近印字边带、红/绿小物体及灰色地面均在视野内。
- **CONTENT**：车体外观、三个圆托盘及上举机构保持可见。没有新的可读屏幕文字，没有看到一键启动、控制指令或程序界面。
- **ACTION**：与4.000 s相比，末帧车体位置和投影朝向差异较小，同时背景构图也有细微变化。可描述为“末段可见运动幅度减小、接近停留状态”；不能确认已经完全停稳，也不能排除末段缓慢移动。
- **DETAILS**：4.300 s接近4.333333 s视频结束，仅剩约0.033 s，缺少停止后保持观察的时间。末帧本身无法证明制动完成、无回弹或规定时长的稳定停止。

## Batch Summary

- **Content Type**：Footage（室内机器人实拍）。
- **Key Events**：2.333–3.667 s，底盘从近侧1/2/3圆环带附近向场地左上侧灰区明显转移；3.667–4.300 s，来到远侧/左侧边界附近，后段相邻帧的画面变化较小。
- **底盘位置与朝向**：真实地面平移有多张场地参照物支持。三个托盘所在车体侧始终主要朝画面右下/下方，后段主导现象是大致保持同一朝向的斜向/侧向移动；车体轮廓投影有小幅朝向变化，但与相机视点变化混合。
- **是否同时平移旋转**：本批不能严格确认。未见明确的大幅原地转头，也不排除运动中有少量旋转；需要固定机位地面标定或同步位姿日志才能区分。
- **跟拍与遮挡**：相机明显调整视野跟随机器人；边带、箱体、浅色方块和远处物体的画面位置都发生变化。未出现整个底盘长时被外物挡住的抽帧，但轮子与部件有自身遮挡，控制来源不在完整视野内。
- **最后停稳**：不能确认。最后两帧变化小仅支持接近停留，缺少结束后持续静止证据。
- **Quoted Text/Prompts**：没有用户输入的文本、提示词或命令。仅场地印字/数字部分可见，屏幕内容不可读。
- **不能推断**：内部算法、定位传感器方案、真实线/角速度、实测误差、自主/遥控模式、四轮是否闭环、是否打滑、载物稳定性和本项目验收结果。
