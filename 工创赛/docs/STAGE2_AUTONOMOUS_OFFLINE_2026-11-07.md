# 第二段自主编排离线主体（2026-11-07）

用户本轮明确继续离线软件，不方便动硬件。主线为真实视觉、纠偏、三位置取料、三槽实物确认、第三段/回位和脱机自主。本轮只推进整段编排，未烧录、未连接板卡/相机/串口、未发动作。

## 新完成

- `source_stage2_runtime.c/h`复用已有`SPF_Flow`：展开→A纠偏确认→等待本轮目标→接近→闭爪/抓牢确认→转运→放置/放稳确认→下一件；三件提交后发布一条`ROUTE_AND_STOW`命令，两分支可独立结束。
- `source_stage2_owner.c/h`挂到现有唯一CAN任务。默认配置未装载，不自动启动、不新增线程、不提供Watch启动开关。机械/路线后端没有绑定时无法开始，不填虚假标定或成功标志。
- 动作`begin`只提交一次，忙时不重复物理启动；`poll`的run/动作序号、完成轴mask和真实证据分别检查。错误、超时、取消都保留STOP重试，直到确认；故障不自动重启。
- 对准、抓牢、释放/在槽/稳定证据有本轮时序要求。单个ACK、PWM写入、固定延时不会推进装载。
- `source_stage2_vision_bridge.c/h`把观察到的证据原样传给现有视觉任务账本，保留原证据时刻；目标事务序号与后续动作序号分开，避免错记到另一笔事务。
- 实际任务账本确认三件后，编排器只发布一次第三段+回位命令。接收该命令的真实路线/机构回位后端仍待绑定；**不等于本轮已经实现或验证行驶中机构回位**。
- 自主分支活动时旧IT动作请求不会竞争同一机构，原STOP入口仍取消自主分支。默认未开启，不改变旧机械调试入口。
