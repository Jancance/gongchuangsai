# PC13脱机底盘测试（2026-10-18）

## 当前操作

此版为开发测试固件，PC13专用于底盘三段测试，不走扫码启动。

1. 烧写最新程序（无线烧写按用户模块既有方式操作；本文不假设模块协议或远程复位功能）。不需要进入Debug，也不需改Watch。
2. 主控与驱动采用既有车载供电。确认调试线不牵连车体，将车置于平整、有空余空间的地面。重新上电或复位后即可按PC13，无需先松开等2秒；未按键不请求VM，但上电时已按住也会触发一次。
3. 按下PC13，稳定20ms消抖后立即请求VM，自动等待Safety/CAN健康（最多5秒），再自动四轮失能/确认、使能/零速确认。取消人为5秒倒计时；不跳过安全前置步骤，因此按下到实际转动仍有必要准备时间。
4. 自动前进约10秒→停车确认→左移约10秒→停车确认→俯视逆时针约10秒→停车并关VM。各轮目标绝对值固定5RPM、方向沿用已验证映射0/1/0/1。准备和交易有耗时，不承诺按下同一时刻转动。按77mm轮径及210mm间距估算，平移约20cm/段，旋转约55度；不是实测距离或定位闭环。
5. 观察方向、是否停住、最终VM是否实测0V；反馈实际情况。完整流程约35～45秒。没有发送精密同步四轮命令，几何尚为约值，不保证精确位移。

等健康或测试中再按PC13会取消并请求关VM；这是开发软件取消功能，不能代替直接切断电机电源。运动中不要追车按键或接调试线；异常时使用可触及的电源切断方式。速度候选保护改为绝对值大于7RPM中止，反向和新鲜度检查保留。

本版上电只允许一次按键测试，取消/拒绝/故障/完成后都不会按键重新启动；排除原因并复位或重新上电才可重测。本开发模式上电按住PC13也会触发一次，不再要求首次松开。长按不重复，第二次事件需稳定松开后再按。设模式0时保留原扫码模式上电先松开规则。

## 实现与隔离

修改USER/main.c、USER/app_config.h、HARDWARE/KEY/key.c、USER/chassis_auto_test.c/h，保留GBK/CRLF，未改引脚/PCB/协议、未增加任务。APP_CHASSIS_KEY_TEST_ENABLE=1是当前开发模式；设0并编译恢复原PC13扫码启动。按键源码仅在此模式首次检测时预置可接受按下，20ms消抖不变，原扫码模式保留先释放门控；两处源码原模式ARMCC编译通过。正式比赛入口仍未放行，g_motion_allowed仍固定0。

按键任务1ms推进非阻塞状态，不发CAN或直接Power_Enable，按下后立即提交g_vm_test_request；等原Safety/CAN健康后选择dry_run0并提交g_chassis_auto_request。Watch自动入口默认dry_run仍1，按键是明确实转选择。原自动执行器、Safety监督、IWDG和每段/总截止继续工作；不主动清原故障或排队人工命令。完成/取消/故障关闭VM请求。

## 可选有线诊断

g_chassis_key_state：0待键、1不再使用、2等健康、3自动测试、4完成、5取消/拒绝/失败。
g_chassis_key_cause：0无、1再次按键、2门控、3等健康超时、4执行失败或等待执行超时。
g_chassis_auto_state/result/cause/segment保留详细自动流程结果。需要有线排查时先停车断VM，再接线查看；不要在实际运动中暂停或打断点。无线模块支持哪些烧写/复位功能尚未核实，不将用户描述扩展成模块规格结论。
