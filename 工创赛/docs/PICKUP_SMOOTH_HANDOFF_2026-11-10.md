# 抓放连贯动作与高档伸缩末端候选

日期：2026-11-10。当前为已通过离线验证的独立候选，现场结果须以新增原始日志及用户观察更新。先前第二档在左侧反馈越过目标199.575虚拟度（约5.62mm）停止，用户确认停稳、第一件在槽、左件在盘、无碰擦。

## 用户本次决定

- 到37°槽位后尽快发松爪指令。用户回复“等个50mm的样子再转臂”，本次已明确按时间50ms执行；替代此前松爪后200ms。
- 升降下降夹取、回升的衔接要连贯；4310在取料时保持朝向。
- 测试仍是一轮连续三件，不拆单件，不自动循环。

## 实现与边界

1. 仅并行动作所有者使用4310“1°位置窗口、低速≤0.035rad/s、连续3次新鲜反馈”；原非并行模式15次反馈不改。故障、反馈时效及停止能力保留。
2. 松爪指令实际写出后开始计时，满50ms才发布下一次转臂请求；这是请求间隔，不承诺机械响应恰为50ms。动作组其他轴仍须完成后才能放料。
3. 提前5mm闭爪条件下，伸缩有首个新鲜的“最终目标内、零速、驱动到位”样本即可闭爪；伸缩组完成仍要求原3次确认。中间点、旧数据和故障状态不能触发闭爪。
4. 第二/三档伸缩在双向大段使用300/400RPM，目标前8mm切换到106RPM、加减速600RPM/s的末段。中间点不报组完成；到中间点后以新鲜位置构造剩余相对运动，仍由唯一CAN任务发送，原完整起终点位置边界保留。
5. 左右高档下降等待伸缩末段指令实际发出，再让升降运动与末段重叠；回收按已确认的高度条件与升降/4310重叠。第一档仍为200RPM、加速600/减速400及已验有界收敛。
