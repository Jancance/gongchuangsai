## 增量换算

先将幅值提升为64位有符号整数再应用正负：

```
signed_count = sign == 0 ? (int64_t)raw : -(int64_t)raw;
delta_count = current_signed_count - previous_signed_count;
delta_motor_deg = delta_count * 360.0 / 65536.0;
delta_wheel_mm = delta_count * (pi * 77.0) / 65536.0;
```

每圈理论241.902634mm（24.190263cm），每原始单位约0.003691141mm。不要将uint32最大幅值先转int32，也不要先将大绝对位置转float再相减而丢失小增量。符号跨零用有符号坐标相减；不要把每过65536当单圈回绕而截断多圈行程。32位幅值边界、驱动复位/重新上电/位置跳变需要重建基准，不能未确认就跨会话累计。低速实际增量率、最大合理变化与中断采样恢复规则需后续单独定义。

四轮行程还需转换为车体前/左方向，再结合HWT航向估算X/Y。理论分辨率不是位置精度；轮径误差、打滑、轮子承重差与四轮采样不同步均会产生误差。不能用HWT单独测出平移距离。
