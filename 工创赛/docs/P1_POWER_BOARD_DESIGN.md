# P1 单电池电源板与安全配电设计

状态：原理图冻结候选（2026-08-30）  
适用：Orange Pi 5 Pro + STM32F407VET6 + 4×X42S + X35S + X28S + DM4310 + 5路舵机 + MaixCAM2/双USB相机/扫码器/串口屏  
边界：本文冻结电源架构、接口和安全逻辑；具体保险丝、MOSFET、DC/DC、电感、铜厚与连接器额定值必须在所有负载型号和堵转/峰值电流实测后签署。

## 1. 规则事实、工程建议与待确认项

### 规则事实（R）

- `PWR-01`：比赛及调试过程只能使用机器人内一个电源，不能中途更换。
- `PWR-02`：需要用同一电池完成完整调试和两轮运行，并保留老化、低温及失败重试余量。
- `RUN-01`：机器人完全自主、一键启动；正式运行不能依赖外部电源或外部电脑。
- `MECH-01`：电池、电源板、开关、保险丝和线束都计入初始300×300×400mm包络。

### 工程建议（E）

- 参考开源车的“6S直供动力、分轨降压、硬件急停、主控/电源/塔吊分板”架构，但不复制12V工控机轨和热换电。
- 采用一块6S内置电池；动力母线、Orange Pi、逻辑、舵机四个电源域从同一电池星形分配。
- 急停只强制关闭动力执行器和舵机，Orange Pi、STM32、视觉和日志继续供电，以便安全停车、显示故障和保存证据。
- Orange Pi使用专用固定5V轨，连续能力不低于5A；不与舵机、电机或普通逻辑5V共用DC/DC。
- 舵机轨使用带软启动、限流、过温保护的高边负载开关/eFuse，PE6只提供3.3V使能请求。
- PE2只提供执行器允许请求；硬件急停、硬件看门狗和电源故障必须能在STM32失控时独立撤销动力允许。

### 待确认/实物验收（Q）

- 最终电池：6S锂电类型、容量、持续/峰值放电电流、BMS额定值、低压截止策略和连接器。
- X42S/X35S/X28S、DM4310的准确工作电压、最大电流、回生能力和推荐母线电容。
- 五个舵机的额定电压、空载/动作/堵转电流，以及允许同时动作的最大数量。
- MaixCAM2、串口屏、扫码器、USB相机和有源Hub的实际输入电压和峰值电流。
- 是否需要为DM4310设置制动电阻/回生吸收；未取得说明书前不得仅靠TVS长期吸收回生能量。

## 2. 与参考板相比保留和修改

参考文章：[工创赛2025智能物流搬运塔吊方案开源](https://blog.csdn.net/m0_74056439/article/details/150104661)。

| 参考板做法 | 本项目处理 | 原因 |
|---|---|---|
| 6S电池直接供动力电机 | 保留，形成`VBAT_6S`/`MOTOR_BUS` | X42S/X35S/X28S/DM4310均需先核对6S电压范围 |
| 5V稳压模块供逻辑 | 拆成Orange Pi专用5V和逻辑5V两路 | 防止电机/舵机压降导致Orange Pi重启 |
| 12V隔离电源供工控机 | 删除，改为固定5V/5A Orange Pi轨 | Orange Pi 5 Pro需要5V供电，不是12V |
| 双电池热替换 | 删除 | 违反比赛过程不换电的单电池约束，且增加倒灌和操作风险 |
| 急停强制切断动力 | 保留并加强 | 不允许只靠STM32软件停车 |
| 程序控制动力电 | 保留为PE2请求，经硬件安全链路后生效 | MCU复位/死机时必须默认禁止 |
| 塔吊分线板、拖链电缆 | 保留 | 减少主板连接器应力和磨损短路风险 |
| MCP2551单路CAN | 改为两路3.3V兼容CAN收发器 | CAN1供六个步进，CAN2预留DM4310独立协议 |

## 3. 总体电源树

```text
单个6S电池（标称22.2V，满电25.2V，最终以电池/BMS为准）
  |
  +-- 主保险丝 -- 防反接/理想二极管 -- 浪涌/TVS -- 主电源开关
       |
       +-- 常供低压域
       |    +-- DC/DC_OPI: 5.0V >=5A --> Orange Pi 5 Pro
       |    +-- DC/DC_LOGIC: 5V >=3A --> STM32板、MaixCAM2/屏/扫码器（按实测分配）
       |    |                           +-- LDO_3V3 --> STM32/PAW3395/HWT101/CAN逻辑
       |    +-- PERIPHERAL_5V --> 有源USB Hub/相机（需要时）
       |
       +-- 安全执行器域
            +-- ACT_SAFE_EN --> MOTOR_BUS --> 4×X42S + X35S + X28S + DM4310
            +-- PE6 + 高边开关 --> SERVO_BUS --> 3盘舵机 + 夹爪舵机 + 相机旋转舵机
```

所有分支来自同一电池，符合`PWR-01`。不允许比赛时用电脑USB、外接充电宝或第二块电池补电。

## 3.1 现有参考原理图逐项修改

以下编号对应用户提供的三张参考电源板截图；截图只能证明参考连接，不能证明元件适合本项目电流和浪涌。

| 参考图元件/网络 | 处理决定 | 修改后的要求 |
|---|---|---|
| CN8、CN9及D18/D19、D21/D22双输入热换电 | **整块删除** | 只保留一个防反插主电池输入`BAT_IN`；比赛不换电，二极管并联还存在电流不均风险 |
| `24V_PC`、U3、SW23、C67、`V_PC`工控机电源 | **删除** | Orange Pi不用参考板的工控机电源，改为专用`OPI_5V` DC/DC |
| U16单路“5V降压模块” | **拆成两路** | 一路只供Orange Pi，固定5V/≥5A；另一路供逻辑5V/≥3A候选 |
| USB1供电口 | **改网名和用途** | 若用作Orange Pi电源，连接`OPI_5V`并使用能承受5A的Type-C电源连接器/线束；D+/D-不接 |
| Q1、R42/R43、D10、U15输入开关 | **不原样复制** | 重画为主保险＋防反接＋预充/防火花＋合适的高边开关；Q1型号和SOA按总电流验证 |
| Q2、Q3、R48～R51、D12动力开关 | **保留功能、重选器件** | 输入改为`ACT_SAFE_EN`；高边器件必须确认P/N沟道、耐压、SOA、散热和失效状态，不能仅按封装替换 |
| D13、D23、D10 `BZT52C27` | **不能作为主浪涌保护** | BZT52是小功率稳压管；主母线改用按实测尖峰选定的功率TVS，栅极钳位另用合适齐纳 |
| D24 `SK106C`跨接VM/GND | **删除或重画** | 不用1A二极管承担整车动力母线反向/回生；改为母线TVS、回生方案和就近电容 |
| C69、C70 100µF/50V | **只能作为局部电容之一** | 在输入、动力开关后和各DC/DC输入分别配置电解＋陶瓷；容量与纹波电流按负载阶跃实测 |
| U4～U7 `VM/GND/42_RX/42_TX` | **接口待版本确认** | 若X42S是CAN版，改为`MOTOR_BUS/GND/CAN1_H/CAN1_L`；如果实物是TTL版则不能接CAN，需重新冻结方案 |
| 云台电机`VM/GND/CANH/CANL` | **接CAN2候选** | 改名DM4310，供电与CAN2分开保护；协议兼容后才能决定是否并入CAN1 |
| H2牛角排线含VM/24V | **拆分大电流** | 牛角座只传低压逻辑、使能和通信；动力母线、舵机电源与Orange Pi 5V使用独立额定电流连接器 |
| R54/R55/R56＋LED | **可保留指示功能** | 按目标电压和LED电流重新计算；不能用LED亮灭代替电源健康检测 |

修改后的网络命名统一为：

```text
BAT_IN           单个6S电池原始输入
VBAT_PROTECTED   保险/防反接/浪涌保护后的常供母线
MOTOR_BUS        急停和ACT_SAFE_EN控制后的动力母线
OPI_5V           Orange Pi独立5V
LOGIC_5V         STM32及低功率外围5V
LOGIC_3V3        STM32/PAW/HWT/CAN逻辑3.3V
SERVO_RAW        舵机DC/DC输出
SERVO_BUS        PE6高边开关后的舵机电源
POWER_GND_STAR   电源入口星形地
```

旧网名`24V`、`24VIN`、`24V_PC`、`V_PC`、`VM`和`5V`不应继续混用；每个连接器必须标出属于哪个电源域。

## 4. 输入保护与主开关

推荐顺序：

```text
BAT+ -> F_MAIN -> 反接保护 -> TVS/浪涌抑制 -> 电流采样 -> VBAT_PROTECTED
BAT- --------------------------------------------------------> POWER_GND_STAR
```

- 电池入口使用XT60或同等级防反插连接器，正极保险丝必须尽量靠近电池入口。
- `F_MAIN`按实际最大连续电流和线束承载能力选择，不按电池理论最大放电电流盲选。
- 防反接优先使用低压降理想二极管MOS方案；简单串联肖特基在大电流下损耗和发热较大。
- 6S满电25.2V，因此输入电容、MOS、DC/DC和连接器不能只按24V额定；建议开关器件至少留到40V，受电机回生影响的器件优先按更高耐压评估。
- TVS型号需用实际母线尖峰示波器证据选择，既不能在25.2V满电时误导通，也不能超过后级器件安全电压。
- 大电容和多个DC/DC会产生上电浪涌；主电源需要软启动、预充或防火花方案，禁止仅靠小拨动开关硬接全部电容。

## 5. 四个电源域

### 5.1 动力母线 `MOTOR_BUS`

- 目标负载：4×X42S、X35S、X28S和DM4310。
- 每类负载采用独立支路保险或可恢复保护，不把七个执行器全部串在一条细铜箔上。
- 每个电机连接器至少包含电源正、动力地、CANH、CANL；CAN屏蔽/机壳地单独规划。
- 板端在总线入口布置大容量低ESR电解、薄膜/陶瓷高频旁路和母线电压测试点；每个远端电机仍按厂家要求就近去耦。
- 动力母线由`ACT_SAFE_EN`控制的接触器/eFuse/高边开关允许。急停必须硬件撤销`ACT_SAFE_EN`。
- 接触器或电子开关只用于上电、急停和故障隔离，不能作为日常PWM或频繁制动器。

### 5.2 Orange Pi专用 `OPI_5V`

- 输入：`VBAT_PROTECTED`；输出：固定5.0V，连续能力至少5A，建议DC/DC额定能力高于持续需求。
- 独立保险、独立LC/π滤波、独立输出连接器和电压测试点。
- 使用短粗线接Orange Pi Type-C供电口；禁止依赖PD协商，禁止输出超过板卡允许的5V范围。
- DC/DC应具备欠压、过压、过流、过温和软启动；输出端先验证空载、5A负载、动态负载和启动波形。
- Orange Pi轨在急停时不断电；只有主电源关闭或严重电源故障才关断。

#### P05C 5V/5A模块候选接法

用户拟采用标称“6～30V输入、固定5V/5A输出、Type-C/双5V双GND排针输出”的P05C模块。该模块电压范围覆盖6S候选电池，但卖家标称不等于持续5A实测通过，首版按外置可更换模块设计：

```text
VBAT_PROTECTED
   |
   +-- F_OPI_IN（候选2～3A慢断，按实测修订）
   |
   +-- J_P05C_IN+  =====短粗线=====> P05C VIN+
POWER_GND_STAR
   +-- J_P05C_IN-  =====短粗线=====> P05C VIN-

P05C Type-C固定5V输出 =====5A短线=====> Orange Pi 5 Pro Type-C电源口
```

- P05C输入必须来自`VBAT_PROTECTED`，位于PE2/急停控制的`MOTOR_BUS`之前；急停不能令Orange Pi掉电。
- 优先直接使用P05C的Type-C输出连接Orange Pi，删除参考图USB1中间转接，减少接触电阻和误接。
- 若必须使用模块4针排针，两个5V脚并联、两个GND脚并联，并使用额定电流足够且防反插的4针连接器；不能只用一个2.54mm针脚承载5A。
- P05C输出只命名`OPI_5V`，不得并到`LOGIC_5V`、`SERVO_BUS`或电机电源。
- P05C为非隔离候选，输入地、输出地和整车`POWER_GND_STAR`共地；不能再串入参考板的`24V_PC/V_PC`隔离/热换电网络。
- Type-C端必须确认无PD协商也会固定输出5V；使用短、粗、能承受5A的线缆，实测Orange Pi接口处电压而不是只测模块焊盘。

原理图中将原U16改名为`U_LOGIC_5V`并只供逻辑负载；另外新增一个两针大电流座`J_P05C_IN`给P05C输入。U3、SW23、C67和`V_PC/24V_PC`工控机电源支路删除。

P05C签署门禁：

1. 6S满电25.2V和低电压18V两端均能稳定启动。
2. 电子负载5A持续至少1小时，无热保护、异味或输出漂移；记录芯片、电感、输入/输出端子最高温度。
3. 0.5A↔5A负载阶跃时，Orange Pi端电压和过冲处于安全范围。
4. Orange Pi执行CPU压力、双USB相机采集、Wi-Fi/USB同时工作至少6小时，无重启和USB掉线。
5. 电机与舵机同时启停时，P05C输入和输出无异常跌落/尖峰。

任一门禁失败，应更换为有明确持续功率、热设计和保护规格的同步降压模块，不能仅通过提高输出电压补偿线损。

#### P05C 5V/5A模块的使用决定

用户拟采用标称“P05C、6～30V输入、Type-C/排针5V/5A输出、带防反接和短路保护”的成品模块。该模块当前状态为**条件使用，尚未签署**：

```text
VBAT_PROTECTED
   |
 F_OPI（候选2A慢断，最终按输入实测）
   |
 输入LC/π滤波 + 本地浪涌监测
   |
 P05C螺钉端子输入
   |
 P05C Type-C 5V输出 --短粗Type-C线--> Orange Pi 5 Pro
```

- 模块接`VBAT_PROTECTED`常供分支，不能接急停后才有电的`MOTOR_BUS`，否则急停会直接断Orange Pi。
- 只使用Type-C输出给Orange Pi；4针5V/5A排针不再并接舵机、主控板或其他大负载，避免模块总电流被分走。
- 6S满电25.2V距离卖家标称30V上限仅4.8V，且没有公开的输入绝对最大值、开关芯片型号和浪涌曲线。若实测电机回生/插拔尖峰可能超过30V，优先换成输入额定至少36～40V且有完整数据手册的5V降压模块；不能假设普通TVS一定把尖峰压在30V以下。
- 卖家标称的防反接和短路保护只作模块自身功能，不能替代整车主保险、防反接、输入浪涌保护和分支保险。
- 螺钉端子确认极性并做防松；模块使用绝缘支柱固定，底面与金属结构保持爬电距离。

P05C必须通过以下门禁后才能装车：

1. 6S最低电压和25.2V满电输入下，空载输出无异常。
2. 1A、3A、5A电子负载分档，每档记录输入/输出电压、效率和关键器件温度；5A持续至少1小时。
3. 0.5A↔5A负载阶跃、开机、关机和重复插拔时，示波器记录Orange Pi端电压过冲/跌落。
4. 四轮同时加速、塔吊与舵机动作、双USB相机工作时，Orange Pi端仍无欠压、重启和USB掉线。
5. 输入侧示波器确认P05C引脚处峰值不越过模块允许范围；如果没有可靠数据手册，就按30V为不可越过的保守上限。
6. 冷启动20次、满载6小时和整车完整两轮运行通过后，才能标记`verified=true`。

### 5.3 逻辑 `LOGIC_5V` 与 `LOGIC_3V3`

- `LOGIC_5V`单独DC/DC，候选连续能力≥3A，实际以MaixCAM2、屏和扫码器总电流修订。
- `LOGIC_3V3`由5V经低噪声稳压产生，供STM32、PAW3395 VDD/VDDIO、HWT101接口侧、CAN逻辑和传感器。
- STM32每个VDD旁100nF，芯片附近增加4.7～10µF；VDDA经磁珠/RC从3.3V引入并独立去耦。
- PAW3395模块的VDD和VDDIO都按已确认模块接3.3V并分别去耦。
- 外接TTL/RS232/5V信号必须经过对应电平转换，不能因共享5V轨而直接接STM32。

#### TPS62933F实现`LOGIC_5V`候选

TPS62933F可将受保护的6S母线降至5V，额定连续输出3A；它不能承担Orange Pi 5V/5A轨。芯片推荐工作输入上限30V，而6S满电为25.2V，只有4.8V静态余量，因此只允许连接已经完成防反接、浪涌钳位和支路滤波的`VBAT_PROTECTED_LOGIC`。若示波器在所有电机回生/急停工况下测得VIN仍可能达到30V，必须换成更高输入耐压的降压芯片，不能把30V推荐上限当作可反复承受的钳位电压。

```text
                           +-- C_OUT1 22uF/10~16V X7R -- GND
                           +-- C_OUT2 22uF/10~16V X7R -- GND
                           +-- C_OUT3 100nF ------------- GND

pin6 BST -- R_BST 0R -- C_BST 100nF/16V X7R -- pin5 SW
pin7 SS  ---- C_SS 33nF ----------------------- GND

LOGIC_5V ---- R_FB_TOP 53.6k ----+---- pin8 FB
                                  |
                                R_FB_BOT 10.2k
                                  |
                                 GND

C_FF 10pF并联在R_FB_TOP两端，首版DNP，仅在瞬态/环路测试需要时安装。
```

元件约束：

- `L1=6.8µH`按TI 5V/3A、500kHz参考值起步；饱和电流建议不低于芯片最坏峰值限流上界，RMS电流不低于3A，并选择低DCR屏蔽电感。
- 两个10µF/50V输入陶瓷必须考虑25V直流偏压后的有效容量，紧靠VIN/GND；不能只放远处100µF电解。
- 输出从两个22µF X7R起步，目标是满足有效容量要求；不要未经环路和启动测试直接并联470µF。
- `C_SS=33nF`对应约5ms软启动；SS不能悬空，最小必须安装6.8nF。
- BST到SW必须安装100nF，R_BST从0Ω起步且不得大于10Ω。
- FB分压使用1%或更高精度，FB走线从电感后的输出电容正端Kelvin取样，远离SW节点。
- TPS62933F的pin7是SS而不是PG。若安全链需要`LOGIC_5V_OK`，增加外部电压监控/复位芯片；或者重新评估带PG脚的TPS62933P/O版本。
- 芯片SOT583很小，3A热性能强依赖布局；参考TI建议使用上下层2oz铜、宽VIN/GND/VOUT铜皮和足够过孔，并进行环境温度和持续3A热测试。

关键布局顺序：U1、输入陶瓷、BST电容、L1和输出陶瓷全部放在同一面并紧邻；`VIN-CIN-GND-U1`高di/dt环路面积最小；SW铜皮只够连接芯片、BST和电感，不扩成大面积天线；FB/SS/RT放在安静侧并用地隔离。

#### TPS62933F前级分支保险、限流和过压断开

整车为多支路共地系统，电池反接保护必须放在主电池入口并对动力、Orange Pi、逻辑和舵机全部生效。仅用27V小齐纳或普通TVS无法保证TPS62933F的VIN始终低于30V。若保留该30V芯片，推荐在全局防反接之后的逻辑支路增加TPS26600PWP 60V eFuse候选，只使用其分支限流、软启动和过压切断功能，设置约18V启动、约28V过压切断和约1.5A输入限流：

```text
VBAT_PROTECTED_RAW（已通过整车主保险和全局防反接）
  |
 F_LOGIC：Bourns SF-0603S200-2，2A慢断候选
  |
  +-- SMCJ33A候选功率TVS -- GND_STAR
  |
  +-- C_EFUSE_IN 1uF/63V -- GND_STAR
  |
  +-- TPS26600 IN1/IN2（pin1、pin2）

TPS26600 OUT1/OUT2（pin15、pin16） ---- VBAT_PROTECTED_LOGIC
                                               |
                                               +--> TPS62933F输入陶瓷/VIN

整车星形地 ----------------------------- RTN（pin8）
整车星形地 ----------------------------- GND（pin9）
```

TPS26600 HTSSOP-16候选连接：

| 引脚 | 名称 | 候选接法 |
|---:|---|---|
| 1、2 | IN | 并联接F_LOGIC后输入 |
| 3 | UVLO | 接R1/R2分压节点 |
| 4、13 | NC | 不连接 |
| 5 | OVP | 接R2/R3分压节点 |
| 6 | MODE | 首版悬空，电子断路器＋自动重试；预留到RTN焊位 |
| 7 | SHDN | 首版利用内部偏置保持开启，预留开漏管拉到RTN用于关断 |
| 8 | RTN | 接GND_STAR，所有保护设定元件以此为参考；本项目不使用TPS26600内部反接功能 |
| 9 | GND | 接下游系统地 |
| 10 | IMON | 不用时悬空；需要监测时按数据手册接ADC |
| 11 | ILIM | 8.06kΩ/1%到RTN，约1.5A输入限流候选 |
| 12 | dVdT | 22nF到RTN，控制支路启动斜率 |
| 14 | FLT | 开漏故障；可由10k上拉到建立后的LOGIC_3V3 |
| 15、16 | OUT | 并联输出到`VBAT_PROTECTED_LOGIC` |
| PowerPad | 散热焊盘 | 接RTN铜皮并打多颗散热过孔；不能作为RTN唯一连接 |

`F_LOGIC`候选改用Bourns SF-0603S200-2（2A、慢断、50VDC、0603贴片封装）。该保险只保护TPS26600/TPS62933F逻辑支路线束和PCB；放在从`VBAT_PROTECTED_RAW`分支后的最前端、TVS和TPS26600之前。保险丝两端各预留测试点，并按厂家推荐0603焊盘画封装，不能用普通0603电阻封装或零欧电阻代替。若实测逻辑5V持续负载导致24V侧正常电流超过约1.2A，先重新核算负载和TPS26600限流，不应直接把保险升到更大值。

UVLO/OVP采用一串三个1%电阻：

```text
IN -- R1 665k --+-- UVLO pin3
                |
              R2 16.5k
                |
                +-- OVP pin5
                |
              R3 30.1k
                |
               RTN pin8
```

按典型1.19V阈值，该组合约在18.2V上升时允许启动、约28.1V时切断输出；最终阈值需包含比较器全温度范围、1%电阻和6S电池/BMS误差做最坏情况复核。不能把TPS26600的默认33V OVP用于保护30V的TPS62933F。

重要：TI说明RTN与GND直接相连会禁用TPS26600自身的反接保护。本项目因为电机、舵机、Orange Pi与逻辑必须共地，不能让逻辑分支单独依赖该负端反接结构；因此在整车主电池正极入口先完成高电流全局防反接，再将TPS26600的RTN、GND和PowerPad在本地接到同一`GND_STAR`。这只有在全局防反接已经完成并验证的前提下成立，TPS26600不得再被宣传为本支路的反接保护器。选用的33V TVS只负责把大尖峰限制在TPS26600的60V能力内，真正保护TPS62933F低于30V的是TPS26600的约28V OVP切断。

若不愿增加TPS26600及其布局复杂度，更简单可靠的方案是取消TPS62933F，直接选择推荐输入耐压至少40V、最好60V的3A同步降压芯片。两种方案只能在完成成本、布局、热和瞬态评审后择一，不能把TPS62933F直接接到原始电机母线。

### 5.4 舵机 `SERVO_BUS`

- 输出电压由舵机铭牌决定，只能在全部五个舵机允许的共同电压范围内选定；若额定电压不一致，必须拆成两个舵机电源轨。
- DC/DC和连接器按可能同时动作的舵机堵转电流求和设计，并留瞬态余量；在未取得型号前不能把“8V/10A”等候选写成最终参数。
- PE6通过100Ω串联电阻驱动3.3V兼容高边开关/eFuse的EN；EN对地10k下拉，保证复位默认关闭。
- 输出端布置软启动、限流、1000～2200µF候选低ESR电容、10µF和100nF；最终电容以启动浪涌和舵机脉冲实测调整。
- 舵机PWM信号可在舵机断电时保持低电平，避免经信号脚反向供电。

## 6. PE2、PE6与硬件急停

### 6.1 全局执行器使能PE2

```text
PE2_ACT_REQ --100R--+-----------------------+
                    |                       |
                   10k                     AND/安全逻辑 --> ACT_SAFE_EN --> 动力开关驱动
                    |                       |
                   GND     ESTOP_OK --------+
                            WDG_OK ----------+
                            POWER_OK --------+
```

- PE2在复位、高阻、下载和BOOT状态下由10k下拉保持禁止。
- 急停采用常闭回路；按下、断线或急停板掉电均使`ESTOP_OK=0`。
- `ACT_SAFE_EN = PE2_ACT_REQ AND ESTOP_OK AND WDG_OK AND POWER_OK`必须由硬件完成，不能只在软件中判断。
- 若使用继电器/接触器线圈，使用N-MOS/NPN驱动和续流/TVS；PE2不能直接驱动线圈。

### 6.2 舵机电源使能PE6

```text
PE6 --100R--> SERVO_SWITCH_EN
 |                 |
10k                高边负载开关/eFuse --> SERVO_BUS
 |
GND
```

- PE6低为关闭、高为请求开启。
- 建议将`ESTOP_OK`也硬件串入舵机EN，使急停同时关闭舵机动力。
- 上电后先建立稳定电源，再延时300～500ms输出PWM；关断前先将PWM置安全状态。

## 7. 接地、布线与连接器

- 电池负极/电源板入口作为`POWER_GND_STAR`，动力回流、舵机回流、Orange Pi回流和逻辑回流分别返回星点。
- 不在数字地平面中间开槽；重点是让大电流回流不穿过STM32、晶振、PAW3395、ADC和CAN收发器区域。
- DC/DC开关节点面积最小，远离PAW3395 SPI、HWT101 UART、晶振和模拟采样。
- 电机和舵机电源使用独立粗线；CAN使用双绞线；塔吊使用耐磨拖链电缆并做应力释放，不能复用易磨破的普通灰排线。
- Orange Pi电源线、USB相机线和电机线分开布线；摄像头USB屏蔽层按整机EMC方案连接。
- 所有外部高电流连接器标注额定电流、极性和防反插；不同电压使用不同连接器或键位，防止误插。

## 8. 电压与电流监测

| 信号 | STM32引脚 | 建议测量 |
|---|---|---|
| `VBAT_SENSE` | PC0 | 电池/动力母线电压 |
| `LOGIC_5V_SENSE` | PC1 | 逻辑5V健康状态 |
| `SERVO_CURRENT` | PC2 | 舵机轨总电流 |
| `MOTOR_CURRENT` | PC3 | 动力母线总电流 |

- 6S电压分压候选可从47k/5.6k起步，25.2V时ADC约2.68V；必须结合ADC采样时间、阻值误差、校准和输入保护复核。
- 5V监测可从10k/10k起步；所有ADC输入增加串联限流、RC滤波和钳位保护。
- 电流采样使用分流器＋电流检测放大器或隔离霍尔方案，量程和分流器功耗按实测峰值选择。
- 欠压策略分三级：提示/限速、禁止新动作、安全结束；不得等BMS硬切断后才处理。

## 9. 电源预算表与选型公式

在填写准确型号前，禁止直接选最终DC/DC和保险丝。必须先完成：

| 电源域 | 负载 | 电压 | 连续电流 | 峰值/堵转 | 同时系数 | 设计电流 |
|---|---|---:|---:|---:|---:|---:|
| MOTOR_BUS | 4×X42S V2.0 | 卖家称常规10～29V/高压10～48V，实物版本待确认 | 卖家设定上限5A/台，不等于母线实测 | 合计20A标称上限 | 1.0 | 母线实测后签署 |
| MOTOR_BUS | X35S V2.0＋X28S V2.0 | 卖家称10～48V | 4A＋3A设定上限，不等于母线实测 | 合计7A标称上限 | 1.0 | 母线实测后签署 |
| MOTOR_BUS | DM4310 | 待确认 | 待测 | 待测/回生 | 1.0 | 待算 |
| OPI_5V | Orange Pi 5 Pro | 5.0V | 5A目标 | 待测 | 1.0 | ≥5A持续 |
| LOGIC_5V | STM32/视觉外围/屏 | 待确认 | 待测 | 待测 | 1.0 | 待算 |
| SERVO_BUS | 5路舵机 | 待确认 | 待测 | 堵转和 | 按动作组 | 待算 |

计算原则：

```text
分支设计电流 >= 同时运行负载的最大实测电流 × 1.25
DC/DC输入功率 = 输出功率 / 最低实测效率
电池最坏电流 = 所有同时工作分支输入电流之和
续航门禁 = 完整调试 + 两轮比赛 + 恢复重试 + 老化余量
```

保险丝保护的是线束和PCB，不是为了匹配软件电流限制；额定值必须低于线束安全承载、又高于正常峰值持续时间。

根据2026-09-01用户提供的卖家参数，六个闭环步进的电流设定上限相加为27A，但这不是整车电池侧持续电流证据。首版原理图可先预留以下可更换保险座，保险芯值保持候选：

| 支路 | 保险候选 | 当前依据 |
|---|---:|---|
| 4×X42S底盘 | 25A汽车/MIDI候选 | 4×5A卖家设定上限＋启动余量；必须用母线实测修订 |
| X35S＋X28S吊塔 | 10A汽车保险候选 | 4A＋3A卖家设定上限＋启动余量 |
| DM4310 | TBD | 缺准确额定/峰值/回生参数 |
| Orange Pi P05C输入 | 3A慢断候选 | 25W输出在6S低压侧的输入功率估算 |
| TPS62933F逻辑输入 | 2A慢断，SF-0603S200-2 | 已冻结候选 |
| 舵机DC/DC输入 | TBD | 缺五个舵机堵转电流与动作同时系数 |
| F_MAIN整车主保险 | Littelfuse BF1 58V/50A候选，型号142.5631.5502；MIDI螺栓保险座额定≥80A | 用户决定按50A峰值母线设计；若50A为持续电流则需升级到60～80A级并重新评审 |

若电池/BMS或线束持续能力低于上述分支之和，保险丝不能被用来掩盖电源能力不足；应降低电机电流参数、错峰动作或更换电池/BMS/线束。主保险必须小于电池线束、连接器、PCB铜排和BMS中最弱一项的安全电流。

### 50A总入口冻结候选

根据用户2026-09-01决定，首版按`50A峰值、约30A持续`设计整车母线：

| 项目 | 首版候选要求 |
|---|---|
| CN1 | 正品XT60配对，额定能力≥60A，电池端优先母头 |
| F_MAIN | Littelfuse 142.5631.5502，BF1 58V/50A MIDI螺栓保险候选；保险座额定≥80A，紧邻CN1正极 |
| 主电池线 | 8AWG高柔硅胶线候选，长度尽量短，压接/焊接后做拉力和温升测试 |
| 全局防反接 | LM74502H候选＋背靠背N-MOS，整条通路按50A峰值设计 |
| 外部MOS | VDS≥60V、优先80～100V；按实际VGS下单颗RDS(on)和SOA选型，必要时每侧两颗并联 |
| 主TVS | SMCJ33A仅作候选，脉冲能量和钳位电压以示波器实测签署 |
| 主母线电容 | 470～1000µF/50V低ESR＋1µF/50V＋100nF/50V候选，并配置预充/防火花 |
| PCB动力路径 | 不依赖普通细铜箔承载50A；2oz上下层大面积铜＋密集过孔＋焊接铜条/粗线旁路 |
| BMS | 持续能力候选≥60A、峰值候选≥100A，并确认允许电机回生；最终以电芯能力为上限 |

50A MIDI保险只有在实际持续电流明显低于50A时适用；保险不能长期运行在额定值边缘。若后续测试显示持续电流超过约40A，必须重新选择60～80A保险、保险座、XT90或更高等级连接器、线束和MOS热设计，而不是继续使用50A保险。

防反接MOS总导通损耗按下式验收：

```text
P_MOS_TOTAL = I_BUS² × RDS_PATH_TOTAL
```

例如背靠背通路热态总电阻3mΩ，在50A时损耗约7.5W，必须通过并联器件、铜条、散热片或更低阻器件降低温升。不能按数据手册25°C典型RDS(on)直接判断实车热性能。

## 10. 原理图分页建议

1. `POWER_ENTRY`：电池、主保险、防反接、主开关、预充/防火花、TVS、总电流采样。
2. `MOTOR_DISTRIBUTION`：ACT_SAFE_EN、动力开关、CAN电机支路保险与连接器、回生/浪涌接口。
3. `OPI_5V`：Orange Pi专用DC/DC、滤波、保险、Type-C电源输出。
4. `LOGIC_POWER`：逻辑5V、3.3V、VDDA、MaixCAM/屏/扫码器供电与负载开关。
5. `SERVO_POWER`：舵机DC/DC、高边开关、PE6、输出电容和五路连接器。
6. `SAFETY`：急停常闭环、硬件看门狗、PE2请求、POWER_OK与接触器驱动。
7. `MONITORING`：电池/5V/电流检测、温度、测试点和故障输出。

主控板、电源板、塔吊分线板之间使用带锁连接器；动力、逻辑和信号不要混在一个无防呆排线里。

## 11. 上电门禁

### 台架阶段

1. 不接Orange Pi和执行器，电子负载分别测试每路DC/DC空载、满载、短路和热稳定。
2. 示波器检查6S满电、最低电压、开关机和负载阶跃时的过冲/跌落。
3. 接假负载验证急停、PE2、PE6、看门狗和掉电默认状态。
4. 只接STM32和通信设备，确认逻辑轨无复位和串口/CAN错误。
5. 单独接Orange Pi，以CPU/USB负载验证5V轨，禁止与舵机同时首次上电。
6. 舵机逐个接入，再测试允许的最坏动作组合。
7. 电机逐个接入，最后进行全车同时加速、塔吊动作和视觉负载测试。

### 通过条件

- 复位、下载、软件崩溃时PE2/PE6均保持关闭。
- 急停不依赖STM32即可撤销动力和舵机允许，逻辑与Orange Pi继续运行。
- Orange Pi输入保持在允许范围，无重启、USB掉线或文件系统错误。
- 满载时3.3V/5V无棕断，CAN无错误帧暴增，PAW3395/HWT101无异常跳变。
- 线束、连接器、MOS、DC/DC、电感和保险在最坏工况下温升合格。
- 使用同一块内置电池完成完整调试与两轮运行，不换电。
