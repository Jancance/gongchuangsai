# 底盘从X切换到Emm：代码、验证与电机设置

日期：2026-11-03。用户要求底盘统一Emm，先改源码并离线验证，后续提醒电机设置；同时要求把全部规划交接后再提交GitHub。

## 当前状态

主工程`3.stm32f407工程/gongxun-f407.uvprojx`和离线工程已统一Emm。四台实物驱动尚未切换；本轮没有开串口、连接调试器、下载、改驱动设置或发车。板上最后确认仍是旧X协议升降调试程序caec4a01…；这不是当前Emm候选。此前第一阶段X候选f0f6e273…也从未下载，其证据保持历史原样。

源码确认项`USER/zdt_emm_config.h`中的`ZDT_EMM_SETTINGS_CONFIRMED`当前为0。前端在申请运动VM之前拒绝启动，底层拒绝使能/非零速度；停止、失能和只读查询保留。四台菜单实物核对后才改1并重编译，不能为通过测试提前放行。此项是人工核对记录，不是软件已自动测得S_Vel_IS状态。

## 后续电机菜单：四台逐一核对

先停稳、停止运动请求，机构可靠支撑；按硬件说明在适当状态下操作菜单。只改底盘地址1～4，不改机械臂驱动。切换固件类型后按厂家要求保存/重启；如提示校准或参数变化，先记录并核对，不能在带载机构上直接执行高速校准。

| 项目 | 本次所需状态 |
|---|---|
| FWType | FW_Emm，四台一致 |
| S_Vel_IS | Enable，四台都开启速度输入缩小10倍；否则同一指令可能变为10倍速度 |
| CtrlMode | 确认仍为闭环CR_VFOC，不因切固件变成开环 |
| ID/地址 | 左后1、右后2、左前3、右前4，保持原轮位映射 |
| CAN | 保持本车CAN1接线/端口复用与500K，勿照搬其他驱动示例 |
| 校验 | 固定6B，与主控一致 |
| Response | 确认收到命令即回复02，优先Receive；不能None或仅Reached |
| Clog_Pro | 保留堵转保护，不能关闭或改成自动清零来通过检查；原阈值先记录，不擅自放宽 |

电流、方向、细分、上电自动运行/回零、EmmTurbo等其他项目先记录并保持，不为追求速度顺手开启。上电自动运动不能启用。不要发送整包配置覆盖命令，也不自动写4F缩放选项或切FWType命令。

四台完成后反馈菜单照片/读数，再把`ZDT_EMM_SETTINGS_CONFIRMED`从0改1、重新编译并冻结镜像。使能前的43状态包可识别Emm格式，但不能从中确认S_Vel_IS，仍必须核对菜单。设置不一致时不发车。

## 离线验证与边界

证据目录：`工创赛/evidence/integration/2026-11-03/emm_migration/`。源文件原件/摘要在before与before_manifest.json；本次各构建、C检查和最终摘要单独保存，未覆盖旧X冻结证据。

`scripts/check_emm_migration.py`运行真实Emm编解码、运动学及实际can.c收发业务，CAN外设/RTOS为桩。检查正式/离线×设置未确认/已确认四种配置，覆盖1024组速度帧组合、方向/符号/边界、整数RPM反馈、整圈/大位置、系统状态偏移、错固件/乱序/超时、收到非02应答的故障锁存、使能前Emm检查、未确认及离线非零禁动、停止/失能保留。每种约2100项，最终精确数见actual_can_report.json。

第一阶段实际C回归仍96+72=168项；脚本的阶段准备/外设是桩，不能代替实际主控设置门禁或停车扫码验收。主机日志9项及历史串口工具114项回归；正式/离线两工程构建结果见日志。仿真夹具最初缺vTaskDelay桩、随后一项拒绝码优先级期望错误，均修正夹具而非放宽固件检查，最终报告保留真实结果。

这些是协议与逻辑离线检查，未模拟真实Emm带载阶跃、抓地、真实CAN/RTOS时序或现场扫码；不等于30/40cm/s及45°/s提速仿真，也不意味着新协议实车通过。首次恢复现场先静态读回和停止检查，再按已确认的低速阶段1单次验收，保存USART1日志和用户尺量结果。

## 交接后的工作顺序

1. 读根《队友接续_2026-11-03.md》，四台底盘菜单核对后再源码放行、构建/下载；车辆启动仍由用户按PC13，不能从历史RAM发车脚本启动。
2. 验收启停区1前进15cm@5cm/s、左移105cm@10cm/s，全程车头+Y、车尾对二维码板；停车读新任务码并显示串口屏，USART1只读存日志。
3. 解决重复运行端点记录生命周期，再整合机械臂CAN/VM所有权、八阶段调度与逐动作中文参数。雷达路径先只收不走，确认格布局、节点事务和坐标映射。
4. 四方向按地图顺时针编号0=+Y、1=+X、2=-Y、3=-X；优先最短转角，90°优于反向270°。当前位置朝向用有效反馈，实际转角保留偏差；原料/粗加工/暂存/回程最终朝向需用户确认。
5. 按通道、包络及总耗时选择先转后移或先移后转，再在合适路段加入边移边转。长路段平移20/30/40cm/s、旋转30/45°/s及更高候选必须先仿真对照，不直接调高当前版本。
6. 各段验收后再完整八阶段和三分钟演练。详细要求见HEADING_AND_SPEED_OPTIMIZATION_2026-11-03.md；三分钟仍是用户工程目标，不冒充已确认的正式限时。

规则检查：FIELD-06、PWR-01、MECH-01/02、RUN-01（R）及LOC-03、MOT-01～04、RUN-06（E）。切换协议是用户工程选择，不改正式规则R，不关闭原Q项。

厂家依据：本地《ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527》第19、46、53、71～72、97～98、104～106页。厂家空载最高转速与速度命令表范围是不同事项，不从6000RPM+空载参数推导主控允许速度。
