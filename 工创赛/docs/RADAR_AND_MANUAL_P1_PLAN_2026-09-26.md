## 4. 雷达协议的边界与初始化

V1.35手册确认：115200、8N1、3.3V TTL，电源5V；原始帧magic为4C 52，协议版本6，多字节小端，最大载荷224字节，CRC16-CCITT（初值FFFF、多项式1021、无反射/输出异或），COBS编码后以00结尾。它不是扫码器的定长ASCII协议。

连接先HELLO及成功ACK，再读取保存状态及成功ACK；当前zone=0才按实际起点选区。zone已为1/2仍须核对是否与本次抽签起点一致，不匹配时显式切区并等ACK＋匹配zone的HELLO。source_zone不代表当前区，不能用其选区。

单次完整扫描：CMD_SCAN_LOCKED(0x07)→成功ACK→14圈进度→同scan_sequence方格/障碍坐标结果→结果锁定状态；溢出、缺包、错节点或旧事务结果拒绝。数量0且完整有效可以表示空扫描，不能把超时当成无障碍。

雷达心跳每500ms；连接后至少每2s查询HELLO；手册5s重连判定不替代整车安全停车时限。失去有效环境观测时由运动安全层更早限制运动。14圈操作建议总时限8s、进度静默3.5s；超时先停止旧事务再有限重试，不能无限延长RUN-04停滞预算。实际开局总时长包含机构动作、停稳、扫描、握手和规划，需实测，不能只算扫描8s。

所需候选缓冲：解码235字节、线上237字节、RX环形缓冲至少512字节；ISR/DMA只收字节，主循环增量解码。停止高优先级、队列满报错，ACK与最终完成区分。节点同类命令串行；路径request_sequence、扫描scan_sequence用于关联。

手册的路径接口0x14返回方格节点，需有效grid_result_valid；布局只在配套上位机配置，调用端无法读取布局，不能假设每格固定480mm。项目地图与雷达配置须人工版本对齐；返回路线仍需验证灰色车道、转弯包络、车身尺寸和跟踪误差，再生成速度/曲线。没有证据表明雷达提供时间最优轨迹。

手册中位姿是设置/校准的扫描位姿，且公开SET_POSE受启停区范围限制；不能当成任意全场实时定位接口。撤掉PAW后，HWT101单独不能提供X/Y。候选视觉定位＋轮速里程计/其他传感器须另行设计和失效验收，目前只明确开局静止扫描。

## 5. 升降与旋转的执行顺序

上电软件初始化及诊断 → 准备状态并锁存所选雷达配置 → 合规启动 → 升至扫描高度 → 建立旋转原点并转至标定方向 → 机械停稳、雷达水平 → 确认节点/区域/标定 → 单次完整扫描 → 发布本轮有效障碍图 → 初始化成功蜂鸣（默认1次） → 后续任务。

若已在安全标定位置，不重复无意义动作。缺少原点、升降到位证据、未确认扫描高度或协议不符时停在对应未就绪状态，不自动走完假流程。

14圈采集窗口内底盘、升降、旋转机构保持静止。外部步进转动改变雷达位姿；默认只在扫描前调整并停稳，不能边转边混用同一标定。若需多个方向扫描，每个方向分别标定/验证坐标变换并区分结果来源；多角度合并与运动去畸变未获实现证据。

旋转轴应有原点或实际角度反馈，记录减速比、驱动步序、单圈步数、最大角度和线束边界；不假定4096步/圈，不按堵转撞止挡回零。步数只能是估计，失步/掉电后需恢复方向基准。升降舵机PWM命令也不等于真实高度到位。

MECH-01/02仍生效：如果升降/展开使出发前包络超限，必须调整机构/启动流程，使出发前尺寸合规、离开启停区后再自动展开；不能把上电即展开当成规则允许。具体扫描时机与机构高度待实物确认。运行期间人工选择雷达不纳入正式赛程，选择在启动前锁存。

三槽若120°等分，0/120/240只可作几何候选，实际应为端点留余量并标定。不要用0/135/270默认表示120°等分槽位。有限270°不能跨端点按360°最短路绕回。

蜂鸣接口后续设计为开始请求与定时更新分离；计数完成后关闭PB0，READY状态进入事件只触发一次。FreeRTOS下由低优先级服务任务或短回调推进，不能阻塞安全、通信与控制任务。成功含义为所要求初始化项目均通过，不是仅执行完几个Init函数。

F103特别注意：screen.c已经通过部分重映射把USART3分给屏幕PC10/PC11，不能再把同一个USART3全重映射到PD8/PD9接雷达。当前工程保持不动；将来若临时在F103测试雷达，需要选未占用UART或先正式迁移屏幕。F407才按本表将屏幕用UART4、雷达用USART3。

servo.c的TIM_Prescaler=72-1只适用于其假设的72MHz定时器输入；F407必须按实际APB/定时器时钟重算。Servo_Init默认CCR=1500并立即启用输出，按当前270°映射约135°，会发出中位目标；不要直接插入main.c造成机构未经确认跳到中位。180°升降舵机与270°载物舵机分别保留角度/脉宽标定，不能共用一个最大角度宏。蜂鸣标注2.4kHz不能证明它是有源器件，型号还要确认。
