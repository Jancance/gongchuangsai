## 改动与边界

保留 `scripts/p2_color_probe.py` v0原样，SHA256仍为 `5d99ec76bfe9d45f79958dfb5fb587e7bfe989859b1232b33723c25983978f19`。新增 `scripts/p2_color_probe_v1.py`，只改变前景候选生成：蓝色提议从S≥90改为S≥140且V≥35；暗区提议从灰度≤60改为HSV最大通道V<45。颜色投票、歧义拒绝、边界拒绝及形状检查保持不变，不裁掉固定ROI，也不隐藏未知输出。

目的：降低暗背景在蓝色/暗区掩膜中的误入，同时保留真实黑色和深蓝。最初把蓝色提议限制V≥60，在V=45～59留下缺口，使旧黑蓝双物料样本的蓝轮廓变得不规则而被形状门拒绝；已将提议V下限恢复35。分类投票仍要求可靠蓝像素V≥60，未放宽分类判定来强行通过。

阈值为本批台架数据导出的工程候选。不能保证任意光照下无漏检，暗处/低饱和蓝色须独立验证。夜间阴影和侧面仍可能进入物料轮廓，中心依然不能当顶面抓取点。
