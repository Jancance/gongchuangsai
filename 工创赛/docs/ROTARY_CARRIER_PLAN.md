- 机械臂在固定取放工位操作；放料先选择已确认空位，取料先选择存有目标物料的载物位，然后转盘将该位对准工位。

## 接口与驱动条件

PB1/TIM3_CH4暂作位置型PWM舵机控制候选，接口为PWM、执行器电源、GND。只有驱动器确为兼容3.3V控制的270°位置舵机，才可复用原三针接口；CAN步进、总线舵机或裸电机需要重新定义电气接口，不能直接插入。电压、堵转电流、脉宽与角度对应关系尚未冻结，不沿用未经核实的5V/50Hz/500～2500us假设。PB0有源蜂鸣器仅用GPIO，不使用TIM3。

PD10、PD11、PD12保留为占用检测资源预留；不强制三个传感器随转盘旋转。固定取放工位传感器只能确认当前到位载物位，其他载物位需历史库存加当前视觉复核，不能把单点观测复制成三个实时状态。若旋转传感器走线，需满足270°范围内线束寿命、余量及防缠绕。

## 几何及定位

- 使用slot_angle_deg[]、angle_min/max、zero_offset和calibration_id配置位置，不写死270°为PWM最大值。
- 若三个载物位120°等分，同一工位的候选索引角可示例为15°/135°/255°，仅为几何示例，必须按实际旋向、零点、减速比及安全余量标定。
- 有限转角不能按360°循环取最短路径。255°回15°时只能在已验证范围内反向运行，禁止越过机械端点绕回。
- 普通三线位置舵机的PWM指令不是到位反馈。机械臂下降前，需要视觉定位标记、合适的到位传感器或执行器真实位置反馈确认角度与静止；等待固定时间只能作为辅助条件。
- 上电角度未知时不立即扫动：先确认机械臂退出转盘扫掠区，再按实际执行器方案定位/回原点。断电重启不恢复旧角度和库存有效状态，重新识别后才继续。
- 载物位用凹槽/挡边和防滑结构定位；实测转动、底盘加减速时物料不滑移、倾倒。摄像头及补光固定后重新验收视野和标定。

## 操作流程

放料：确认空位 → 预占该slot → 确认机械臂及其所持物料退出扫掠区 → 底盘静止条件下分度 → 到位与静止验证 → 机械臂放料并释放 → 当前视觉/占用确认 → 提交库存OCCUPIED → 机械臂撤离 → 才能下一次分度。

取料：按任务选择目标slot → 确认机械臂退出扫掠区 → 分度及到位验证 → 复核目标颜色/实例 → 抓取 → 验证该位已空及物料已抓起 → 提交库存EMPTY → 机械臂撤离。

slot状态为EMPTY/OCCUPIED/UNKNOWN/RESERVED，记录color、material_id、batch_id、证据时间。所有位满时返回FULL，不盲目覆盖。未知槽位不能作为空位。掉料、角度不明、视觉过期、反馈超时或通信失联时不得继续抓放；转动和抓放互斥，重试有上限。

转盘分度动作本身不增加抓取/放置计数；库存确认与比赛抓放计数分离。取消“料盘夹紧DONE”条件，改成机械臂动作完成、当前物料占用/释放证据及相应计数语义共同确认。

## 验收及未闭环

先验证三位置空载分度及端点余量，再做单物料、多物料抓放、满盘、遮挡/未知、上电偏角、断电重启、手臂未撤离拒绝转动、失联与重复命令测试。保存真实位置误差、静止时间、供电压降、滑移/倒塌及库存一致性结果。

未闭环：转盘执行器准确型号与控制协议、270°是输出盘角度还是舵机角度、额定电压/堵转电流、载物位数量/角间距、定位反馈方式、固定相机视野。既有软件和配置可能仍含三夹紧舵机语义，本文件和同步后的引脚表为本次变更依据，不代表旧软件已迁移。
