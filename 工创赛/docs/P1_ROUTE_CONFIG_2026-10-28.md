## 只修改这一个参数文件

实际工程的 `3.stm32f407工程/USER/route_config.h` 已加入 Keil 工程树。
保持 GBK 编码和 CRLF 换行，每行表示一段：

```c
#define APP_ROUTE_USE_CUSTOM 0
#define APP_ROUTE_ROWS(X) \
    X(FORWARD, 30.0f, 5.0f) \
    X(LEFT,    20.0f, 3.0f) \
    X(TURN,    90.0f, 5.0f)
```

- FORWARD／LEFT／RIGHT：第二项为厘米，第三项为名义基础速度上限（厘米/秒）。前、左、右均相对该段开始时车头，不是地图固定方向。
- TURN：第二项为相对角度，正数逆时针、负数顺时针；第三项为名义角速度上限（度/秒）。
- 每行末尾保留续行符，最后一行不加。只填数字，不填算式；预览拒绝无法理解的内容，不执行C表达式。
- 当前每段停稳再继续，沿用段间保电与停车确认；末段完成关闭VM。没有连续过弯、任务等待或任意中途续跑功能。

第三项会向下量化为整数电机RPM。例如5cm/s转换为12RPM，名义基速约4.838cm/s；5度/s转向转换为4RPM，名义约4.421度/s。纠偏、加减速、距离补偿、侧滑和负载会影响实际运动，不能把这当成真实地速或整车严格限速承诺。短段不保证达到设定速度。

## 先在电脑检查

在仓库根目录使用当前电脑的Python：

```powershell
D:/python/python.exe -X utf8 工创赛/scripts/p1_route_preview.py
```

工具只读参数文件和当前底盘几何数据，显示各段动作、设置速度、量化RPM、名义速度和保守保护预算。不打开COM、不生成控制命令、不编译下载。
`--json` 输出结构化结果及参数文件SHA256，供保存记录；退出码0表示参数检查通过，1表示拒绝。

当前普通距离范围10～100cm，转换后3～15RPM；以77mm轮径约为1.210～6.048cm/s输入范围。
转向范围±5～±90度，转换后1～5RPM；按当前轮距约为1.105～5.526度/s。20cm/s、210cm特殊候选不通过此表开放。

除了数值范围，工具和固件转换器还检查名义匀速最短时间；若连这个时间都超出单段30秒保护，直接拒绝。通过该检查不等于含加减速的动作必能在30秒内完成。

**段数限制：** 存储容量仍为8，但普通距离和转向均按30秒上限加3.5秒段间余量计入，整组另加5秒，原120秒保护不变。因而本版自定义表实际最多3段（105.5秒预算），第4段拒绝（139秒）。这是保守保护预算，不是预计运行耗时。要支持完整赛场长路线，后续须另做按动作估计时限与总调度预算，不能单纯调大上限绕过保护。

此工具只检查本版自定义表的参数规则，不检查传感器健康、S曲线规划是否能完成、地图、车道、车身扫掠包络或障碍。它不是路线安全证明。

## 实现和故障边界

`route_plan.h` 先验证整表并转换到临时动作数组，全部成功才写入目标数组；负数、NaN、无穷和速度超限在无符号整数转换前拒绝。
`app_entry.c` 只在开关开启且调试模式3的默认表入口加载此表。失败时不回退成另一条路线；启动阶段动作数保持0，原启动自检会阻止启动。空闲阶段切换失败则保留旧表，原主机必须等收到选择接受回执才继续。
调试器可读 `g_route_check.error/segment/budget_ms`，段号从1开始，0为整表问题：1数量、2动作、3距离/角度、4速度、5单段时长必要条件、6总预算、7几何参数。未扩展串口字段，电脑预览提供中文错误位置。

`main.c` 的动作表校验接受转向base_rpm=1～5，调度传入该上限；历史base_rpm=0仍表示原5RPM转向。其他运动接口、CAN、VM、故障锁存、看门狗和停止流程不变。
