# 桌面目标编号预览

日期：2026-09-27。对应VIS-12/15、RUN-06（E），仅V3的图像关联入门测试。

## 范围与边界

用户暂缓完整内参标定，厂家77度无畸变声明不替代几何验证。本阶段可在固定相机桌面上研究图像关联，不输出毫米位姿、物理MOVING/STATIONARY、抓取点或机构控制。VIS-14的自身运动补偿/地面速度尚未实现。

新增 `scripts/p2_tabletop_tracker.py`、`scripts/p2_tracking_preview.py`。沿用v1颜色规则和freshness独立采集进程，请求缓冲4，曝光50/增益30/白平衡4600，原尺寸1280×960。输入或结果的主机read完成后年龄超过150ms就清除轨迹；超过500ms无新read时退出。相机/USB底层排队仍未验证，不将主机年龄称端到端延迟。

桌面简化约束：每种颜色最多一个可见物料。颜色相同、位移≤100px且候选面积比0.5～2可关联，连续3个观测显示OBSERVED，之前显示CANDIDATE；这两个词不代表静止、测量可信度或可执行抓取。同色同时出现多件时该颜色拒绝；目标未检测到就撤销ID，不显示旧位置。遮挡后重新检测分配新ID，尚不宣称物理身份重识别或同色交叉跟踪。过大位移/颜色变化也重新编号。每轮记录session_id，数字编号只在该会话内有意义。

采用保守独立demo是为不把现有主工程MultiFrameTracker的帧数失踪、速度预测等未验证能力升级为本次板端验收；未修改主工程tracker。轮廓质心仍受侧面/阴影影响。

## 使用与证据

板端需要同目录四个脚本：p2_color_probe_v1.py、p2_freshness_audit.py、p2_tabletop_tracker.py、p2_tracking_preview.py。运行最后一个即开启GUI；S保存原图、叠加图和快照JSON；Q正常结束，保存逐帧observations.jsonl及run.json。处理状态及UNKNOWN明确显示，未连接串口或执行器。

本机5项测试通过：连续位置变化保ID；缺失撤销及重现新ID；同色多目标拒绝；过期/逆序时间拒绝；大跳变和颜色变化换ID。CLI与语法检查通过，板端运行尚未发生。首个实测仅一个红色物料静置并确认T编号与OBSERVED；随后再安排小范围移动、移出视野和重新放回。

2026-09-29诊断更新：用户确认移动时手指未遮住红色顶面，并观察到反光变化导致识别消失。日志 `evidence/20260927-023342-012495/` 显示首个稳定T002约21.36秒后出现observed=[]；随后反复新建T003～T024，它们的首次颜色区域中心多在约(615.8,524.0)附近，几乎无位置跳变。整轮stale_rejections=0、error=null。可确定直接换号前检测器出现了空结果；反光是用户观察到的诱因，但旧日志没有失检原图/原始拒绝原因，不能单凭它定量确认阈值故障。

为避免未取证直接放宽颜色阈值或延长旧目标有效时间，预览新增首次红色失检/直接换号自动保存原图与检测器所有区域数据，分别命名`first-red-loss-*`、`first-red-id-change-*`，最多各保存一次。无红色结果时仍立即不显示旧坐标；再次出现按原保守策略分配新ID。本机6项tracker逻辑测试和预览语法检查通过，板端新版仍待运行。短距离手推一次即可；文件保存在当轮tracking-runs目录，分析后再选遮光、照明或质量门等具体办法。

仍仅桌面台架，不需要安装机械臂或场地。正式安装、毫米定位和动作联调前按P2_INSTALLATION_AND_FIELD_GATES.md提醒。未闭环：真实运动/遮挡/误检的关联表现、帧新鲜度全链路、JPEG间歇问题、几何误差与所有真实抓放。
