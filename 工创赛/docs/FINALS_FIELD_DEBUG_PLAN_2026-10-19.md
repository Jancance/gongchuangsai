## 3. 调试入口设计

先利用现有USART1接收/独立任务和香橙派程序进行后续诊断入口设计。所有命令的名称、编码和载荷在各阶段冻结，本文件不擅自分配线上命令字；中断只收字节，命令经唯一服务/任务串行执行。

| 调试能力 | 后续行为要求 | 验收证据 |
|---|---|---|
| 状态读取 | 一次读回本轮运行/模式、有效配置版本、各模块就绪/故障、数据年龄、VM及运动许可；区分命令值与反馈值 | 中文说明能对应到实际状态，模块未就绪时指出具体原因 |
| 分模块检查 | CAN、HWT、定位、雷达、相机/标定、夹爪/盘/臂分别检查；未接模块明确未装/未启用/未知 | 单一模块失败不会伪造全系统成功，也不会强迫重复已验其他模块 |
| 有界动作测试 | 已验模块允许在调试态单项回零、到指定工位或限时/限程低速运动；必要时单件抓放 | 校验范围、模式、互锁和反馈，动作窗口到期/失联/故障按验证过的路径停止；不在正式运行态接受点动 |
| 读取/应用参数 | 先读取和检查候选参数，再明确提交；读回已生效值及版本，返回拒绝原因 | 越界/格式错误/不匹配版本不生效，修改不会留下半套配置 |
| 停止与恢复 | 停止路径独立可用；恢复需原因消除、状态复核和显式重新允许 | 重新连接、清日志、恢复配置不自动启动底盘或机构 |

## 4. 备份、回退与离线准备

每个验收通过的组合保存一份对应的源码/固件、工具链与构建说明、参数、地图、标定、几何、设备profile、验证记录及校验清单。暂按项目内文件和复制/校验步骤交付，后续如果增加自动管理工具需另外实现验收。

候选现场修改使用副本，并记录旧值、新值、原因和版本；失败时恢复匹配的整套配置/固件。恢复之后清旧目标和缓存，确认版本/状态，完成对应最小复核才重新允许动作。不能只恢复视觉阈值却继续使用来自另一套高度/相机姿态的目标，也不能恢复固件后静默沿用不兼容载荷。

## 6. 决赛适配演练及完成标准

两组在正式模拟前共同做一次工程演练：按已经验证的范围选一个场地/机构/视觉变更，保存稳定版 → 查看和修改对应参数 → 读回实际生效值及版本 → 执行相应模块自检/局部单件或路线复测 → 保存结果 → 演练恢复稳定版。可选变更例如原料盘高度或工位位置；它们是训练示例，不预测官方创新实践题目。

用户要能独立找到参数入口、解释单位和范围、看出拒绝/故障、导出日志并恢复已验版本。记录实际修改用时、重验用时、失败和恢复结果；具体用时目标以后按官方现场时限和本车实测设定，不先承诺几分钟完成。

该适配演练作为现有最终教学/阶段8的一部分，和用户已要求的一次完整自主模拟分别记录，不替代双起点、续航、故障回归或完整自主运行。改装后的成果须按正式命题实际应用，以满足MECH-04。
