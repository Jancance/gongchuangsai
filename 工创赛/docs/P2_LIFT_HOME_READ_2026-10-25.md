# 35升降无开关回零：先读取驱动参数

用户已确认下方有挡块，并决定不装35原点开关。当前仅接入原厂0x22参数查询；尚不触发碰撞回零、不修改驱动参数、不启用上电自动回零。挡块存在不等于已验证其承载能力、重复性或碰撞阈值。

## 本版实际操作

1. 实际工程重新下载、F5运行，`g_vm_test_request=1`，等约3秒身份读取完成。
2. 机构静止时，Watch写`g_lift_home_read_request=1`一次。
3. 回传`g_lift_home_read_result`及展开的`g_lift_home_params`截图。不写运动请求。

`read_result=1`是查询与格式检查成功；5是回复超时，6是组包/参数格式错误，7是入口未就绪/动作忙，4是发送失败。查询失败时公开参数先清零，不能把零值当驱动实值，需结合结果及原始帧。`g_lift_home_raw[17]`和`g_lift_home_replies[3]`保留原始数据供定位。

| 结构字段 | 含义 |
|---|---|
| mode | 0单圈就近、1单圈方向、2无限位碰撞、3限位开关、4坐标零点、5上次掉电角度 |
| direction | 厂家方向0/1；当前装配0下、1上，仅作后续配置参照 |
| rpm | 独立的回零转速，不使用正常升降3000RPM目标替代 |
| timeout_ms | 回零超时，毫秒 |
| detect_rpm | 碰撞检测转速阈值，RPM |
| detect_current_ma | 碰撞检测相电流阈值，mA |
| detect_time_ms | 连续满足速度/电流条件的时间，毫秒 |
| auto_home | 0不上电自动回零，1已配置上电自动回零；本版只读取不修改 |

## 实现和验证

CAN只发送地址5、扩展ID0500、DLC2、`22 6B`。回包按0500/0501/0502严格组装，重复功能码22，每帧有效数据分别7/7/2字节，DLC8/8/3，完整无地址报文17字节。保留总200ms回复时限，不因收到一帧重置时限；缺包、重复/乱序、长度和末尾6B异常均不接受。收其他地址帧不作本机回复。

lift模块只在有效供电、身份state4、无待处理运动请求且运动非1～6忙状态查询。请求仅一次消费，不自动查询或自动重试，由原唯一CAN任务执行，不新增CAN任务。解码按原厂第63～65页的大小端顺序，合法才发布结构体。保留现有3000RPM目标/加速250/5000脉冲/模式02/12秒动作超时与保护隔离。

原厂来源：《ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527》，CAN第42～43页，回零说明第30～31页，参数第63～65页。厂家能力说明不是竞赛R规则。默认值只用于测试，不假定用户实机为默认参数。
