## 当前用法

实际工程入口：`D:/新建文件夹4/工创赛/代码/stm32/3.stm32f407工程/gongxun-f407.uvprojx`。须下载本次毫米入口构建后才有新变量；助手不烧录或发送动作。

默认请求仍0，上电不动作；默认毫米模式和10mm只表示下一条请求的准备值。在VM/lift4就绪、其他轴闲置、方向通路/余量明确时：

```text
g_extension_use_mm = 1
g_extension_distance_mm = 10.0
g_extension_motion_request = 1    // 缩回10mm粗标目标
```

同样参数下请求2为伸出；请求3停止，必须让CPU继续执行。实际运行中有任何异常立即停止；无需为入口专门再跑一组50mm重复验收，直接在下一次必要的固定点位调试中使用，并一次记录新增结果。

```text
g_extension_target_pulses       // 本次接单脉冲目标回显：10mm对应320
g_extension_target_mm           // 由脉冲数反算的命令毫米回显，不是实测位置
g_extension_motion_state
g_extension_motion_result
```

接单时把毫米/单位换算为内部私有目标，忙时修改输入不改变正在执行的动作。0、负值、NaN、无穷、超过1600脉冲上限的距离、过小不足半脉冲或非法单位都会拒绝（motion result8），未发命令不自动改成端点。停止入口优先于这些检查，即使输入被改坏仍能显式停止。

保留原脉冲方式：`g_extension_use_mm=0`时仍用原固定1600脉冲，`distance_mm`不参与换算。此为兼容保留，不要求重跑；当前缩回余量约50mm，不能把1600≈50mm当作可直接向挡块走满的许可。
