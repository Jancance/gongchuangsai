# 低速距离S曲线执行候选（2026-10-26）

本轮将已验证的纯S曲线计算模块接到距离任务执行器，默认`APP_DISTANCE_SCURVE_ENABLE=0`，仅调试入口mode3可启用。仍用四台FW_Emm/S_Vel_IS Disable、整数RPM和原CAN发送/查询；未切0.1RPM、未改驱动/保护设置、未烧录/发车。首版比赛巡航目标仍20cm/s，候选本轮仅0～15RPM基速（最高约6.05cm/s名义速度），保留原30RPM反馈保护。

## 代码路径与准备

`app_config.h`新增默认关闭开关和候选参数：加速度40mm/s²、jerk80mm/s³、参考跟随误差50mm、参考结束后编码到距容差2mm、零速最终等待2000ms。它们只是软件候选，未根据地面、满载、CAN实机时延标定。

`ChassisAuto_PrepareTranslation`在外层临界区之外构建计划，已有距离/方向/RPM及30/60秒精确长距门禁仍检查。前进进度沿用独立距离校准，计划速度使用同一校准坐标对应的每RPM行程，换回轮RPM时除回该系数；左右投影不改。不放宽超时：计划时长加最终等待必须小于原运行截止，否则拒绝。定时动作不启用曲线。

候选prepared对象增加计划缓存，main只在候选编译时使用唯一CAN任务私有的静态准备对象，避免增大其局部栈。BeginPrepared重查session、idle/故障/许可、原运动参数及计划首状态/限值/期限；首次四轮速度向量强制零速，避免错误准备向量直接以巡航速度起步。直接后端距离API也走同一准备路径，在临界区/关中断上下文调用会被拒绝，不能在其中做sqrt/pow规划。

## 执行与低速编码

从首次启动批次时刻起，按实际uint32 tick差计算累计秒数，取当前位置/速度参考，不积压补发旧点。四轮同一批命令继续冻结，只在原整批边界接受最新基速和有效航向修正；距离在候选START批次中也继续检查，不为等待完整发送而忽略到距/故障。

新增`Chassis_TranslationProfileCommands`接受0～15整数RPM；旧Hold接口仍只接受3～15RPM，小数编码拒绝规则不变。候选将参考速度明确四舍五入为整数RPM；这是离散执行，不宣称轮指令本身具有连续速度/加速度/jerk。新`Chassis_ProfileCorrectionRpm`将修正限于±min(基速,2)，零基速有效修正为0，防止起步末段某轮反转。请求纠偏和有效已应用纠偏可能不同，BT1记录后者；原TM1 correction字段仍是前端接受的纠偏值。

参考曲线不替代现有航向、位置、状态反馈、100ms源/提交时效、400ms位置时效、5mm回退/50mm四轮差异及超程等保护。航向修正仍按原整数控制器更新，尚未联合限制其加速度/jerk，故本轮不签完整MOT-02四轮平顺性验收。

## 到距、参考结束与停车

1. 编码校准进度达到目标，立即走原停止请求；不等参考结束。编码进度仍不等于真实地面XY。
2. 曲线参考结束后，仅当编码进度达到目标减2mm候选容差，才请求正常停止；参考结束本身不能成功。
3. 跟随误差超过50mm，走距离故障reason7。样本无效/参考速度非法reason8。
4. 参考结束但编码仍未到，输出零基速/零有效纠偏，只继续有界反馈等待，不自动爬行补距；2000ms后仍未满足条件则reason9故障。原整体/源/位置截止仍可更早停止。
5. 到距只设置reached和停止请求。须原四轮停止确认、阶段后新鲜零速反馈、稳定等待及端点采样通过，后台才DONE；请求取消/故障和STOP优先，不等正常曲线减速。VM仍由原整组收尾或保护控制。

reason1～6原定义不变，reason7～9仅候选新增；TM1字段数、布局及节奏不变，0～2RPM时base_rpm/理论速度显示修正为真实基速。`ChassisAutoStatus`增加本地profile模式/参考结束/参考位置与轮RPM快照，暂不追加串口字段。
