# 视觉系统功能、精度与鲁棒性专项

> 状态：视觉后续实现与验收基线  
> 平台：Orange Pi 5 Pro + USB工业全局快门主相机 + 前视相机 + STM32F407  
> 规则权威来源：[2027竞赛规则与设计约束基线](competition_requirements_2027.md)

## 1. 规则事实、工程目标和待确认项

### 规则事实（R）

- `QR-01`：任务码按四段解析。
- `VIS-01`：识别红、黄、蓝、绿、黑、浅蓝六色。
- `SCORE-01`：圆环1～6环分值依次15、10、7、5、3、1，圈外或倾倒0分。
- `OBS-01`：黑色随机障碍是位于灰色车道内的 `φ50×100mm` 模拟障碍。
- `FIELD-07`：只允许垂直向下补光。

### 工程目标（E）

数字模板、圆环、条形码、物料、码垛、抗直射光、稳定跟踪、残缺特征识别、运动判断和精度预算均为本项目新增工程目标，不得写成官方规则。对应基线为 `VIS-06～VIS-15`、`CAL-02～CAL-04`。

### 待技术答疑（Q）

- `QR-04`：任务码完整语法及数字/颜色映射——**待技术答疑确认**。
- 条形码是否出现在正式任务、采用的码制、尺寸、印刷质量和允许读取距离——**待技术答疑确认**。
- 数字标牌/圆环的字体、字号、材料、颜色、尺寸公差和遮挡范围——**待技术答疑确认**。
- 现场太阳直射角度、照度上限及是否允许遮光罩/偏振片——**待技术答疑确认**。

## 2. 当前代码功能审计

| 功能 | 当前状态 | 证据与限制 |
|---|---|---|
| 四段二维码文本校验 | 基础具备 | `vision.py` 已有正则和 `QRCodeDetector`，但只有单帧解码，没有多帧一致性、透视质量、重复码和超时状态 |
| 条形码识别 | 缺失 | 无检测器、码制配置、校验和测试图 |
| 数字模板匹配 | 缺失 | 无数字模板库、整形/尺度归一化、歧义拒绝和遮挡测试 |
| 六色分类 | 基础骨架 | 只有整块ROI的HSV像素占比；未完成物料实例定位、颜色校准、蓝/浅蓝困难集和现场光照回归 |
| 物料识别/抓取点 | 缺失 | 无实例ID、轮廓、中心、姿态、可抓取点和任务区语义 |
| 圆环识别/编号映射 | 缺失 | 无圆/椭圆候选、局部精定位、环号映射和残缺圆弧处理 |
| 码垛识别 | 缺失 | 无层数、顶层物料、中心/姿态、倾斜/倒塌和放置验证 |
| 抗太阳直射 | 缺失 | 无饱和/阴影质量门禁、遮光结构、偏振验证或曝光配置矩阵 |
| 圆环稳定跟踪 | 缺失 | 无track ID、数据关联、预测、丢失/重捕获和新鲜度门禁 |
| 物料稳定跟踪 | 缺失 | `TemporalObstacleFilter`只用于障碍集合稳定，不等于物料跟踪 |
| 物料运动判断 | 缺失 | 无相机运动补偿、世界坐标速度、静止/移动/未知迟滞状态 |
| 残缺特征识别 | 缺失 | 无可见比例、部分圆弧/局部模板、遮挡模型和歧义拒绝 |
| 相机去畸变 | 缺失 | 有平面单应性工具，但没有内参/畸变参数加载和运行时undistort链路 |
| 全程一像素定位 | 不成立 | 当前没有精度预算或测量证据；像素误差不能代表地面毫米误差和机械落点误差 |

## 3. 统一视觉数据合同

所有检测结果必须携带以下公共字段：

```text
VisionObservation
  frame_id, timestamp_ns, source_id
  calibration_id, detector_version, tracking_epoch
  class_id, instance_id
  pixel_pose, ground_pose_mm
  covariance_or_error_bound
  confidence, visible_fraction
  quality_flags[], rejection_reason
```

约束：

- 过期帧、标定版本不一致、质量失败、目标身份不确定时不得输出运动目标。
- `confidence`不能替代误差边界；定位结果同时报告像素与毫米不确定度。
- 检测、跟踪、运动判定和任务计数分层，不能把“同一帧看见”直接当成“稳定静止”或“已抓取”。
- 只有连续新鲜观测满足门禁后才能进入抓取、放置或视觉伺服。

## 4. 数字模板匹配

### 实现路线

1. 先检测标牌/圆环ROI并完成透视矫正、亮度归一化和统一尺寸。
2. 建立带版本的数字模板库；模板来源、字体、采集相机、尺寸和预处理参数必须可追溯。
3. 受控印刷条件优先采用二值轮廓、归一化相关或Chamfer距离；尺度/旋转变化较大时使用多尺度模板或ORB/SIFT辅助。
4. 同时比较第一名、第二名得分和有效像素比例；相近结果必须输出 `UNKNOWN`，不能强猜。
5. 遮挡时只在可见区域计算一致性，并用几何布局和多帧跟踪验证身份。

### 验收

- 完整、轻微旋转、透视、亮/暗、眩光、模糊和部分遮挡分别统计混淆矩阵。
- 模板外字体、空白、污渍和无数字ROI必须正确拒绝。
- 具体允许遮挡比例等待实物数据后确定，不提前写死。

## 5. 圆环识别、编号和局部精定位

### 实现路线

1. 使用颜色/灰度和任务区ROI获得候选，轮廓圆度与椭圆拟合为主，Hough圆只作辅助候选。
2. 在已去畸变或地面矫正图上拟合圆/椭圆，输出中心、半径/长短轴、法向/平面姿态、拟合残差和可见圆弧比例。
3. 圆环编号由数字模板或确定的空间映射提供；检测到圆不等于编号可信。
4. 最终对准采用粗检测→高分辨率局部ROI→边缘亚像素/鲁棒圆弧拟合→连续帧稳定门禁。
5. 1环优先时以局部毫米坐标闭环对准，不直接用全图像素中心控制抓放。

### 残缺圆环

- 使用RANSAC圆/椭圆或鲁棒最小二乘拟合部分圆弧。
- 校验弧长覆盖、点分布、半径范围、拟合残差和跨帧中心一致性。
- 圆弧集中在很小角度、候选存在多解或遮挡比例过高时拒绝，不能用圆拟合强行补全。

## 6. 二维码与条形码识别

### 二维码

- 检测四角、透视矫正、保留quiet zone，并记录解码质量和原始文本。
- 四段任务码必须通过 `QR-01～QR-04`结构校验；连续多帧一致后锁存一次，防止重复任务。
- 失败时有限次改变ROI/尺度/曝光，不能无限阻塞超过运行预算。

### 条形码

- 优先探测板端OpenCV是否提供 `cv2.barcode_BarcodeDetector`；若不可用，再评估ZBar等aarch64可部署后端，并保留CPU离线测试。
- 对条码先定位、旋转/透视矫正、保证窄条采样宽度，再解码和校验。
- 码制必须配置化；未知码制或校验失败输出拒绝。
- 正式任务是否需要条形码以及码制为Q项，当前只建立可插拔接口和数据集门禁。

## 7. 物料识别、跟踪与运动判断

### 物料实例识别

- 在原料区/转盘/载台/功能区的语义ROI内检测实例，而不是只对整图做颜色占比。
- 融合LAB/HSV颜色、轮廓面积、圆度/外形、尺寸、接地位置和任务上下文。
- 输出颜色、实例ID、中心、姿态、边界、可见比例、抓取安全点和误差边界。
- 蓝/浅蓝、黑色物料/黑色障碍必须分别建立困难负样本。

### 稳定跟踪

- 用位置、颜色、形状、尺寸和预测位置做全局数据关联；不能依赖轮廓枚举顺序。
- 每个track包含出生、确认、遮挡、丢失、重捕获和终止状态，并在相机重启/任务切换时更换tracking epoch。
- 卡尔曼滤波只用于预测和降噪，不能替代时间戳、身份和观测新鲜度验证。
- 抓取/放置前要求连续新鲜帧满足位置和速度门限。

### 移动/静止判断

1. 先用地面标记、车体位姿或图像配准补偿相机/底盘自身运动。
2. 将物料中心转换到同一地面毫米坐标系，按真实时间差估计速度。
3. 使用进入/退出不同阈值和连续帧迟滞，输出 `MOVING/STATIONARY/UNKNOWN`。
4. 遮挡、身份切换、帧间隔异常或位姿补偿失效时输出 `UNKNOWN`，不得误报静止。

## 8. 码垛识别与放置验证

- 检测码垛区域、每层物料轮廓/颜色、顶层可放置区域、堆叠中心、朝向和层数。
- 判断错位、悬空、倾斜、倒塌、遮挡和边界接触；部分可见时结合已知放置历史，但必须由新鲜视觉证据验证。
- 每次放置前定位顶层目标，放置后重新检测并比较层数、中心偏差和稳定性。
- 太阳直射/反光导致顶面饱和时不得沿用上一帧位置继续放置。

## 9. 抗太阳光直射与反光

### 硬件优先

- 选择动态范围、手动曝光/增益/白平衡可控的全局快门相机和合适镜头。
- 增加镜头遮光罩、消光内壁；评估可旋转CPL偏振片对ABS/PLA反光的改善及其进光损失。
- 只使用规则允许的垂直向下补光；遮光罩和偏振片是否允许需结合技术答疑复核。

### 软件门禁

- 监测高光饱和比例、暗部剪切、局部对比度、清晰度和颜色参考偏移。
- 比赛参数冻结后锁定或限制曝光、增益、白平衡；不要让逐帧自动参数变化破坏颜色与跟踪。
- 用LAB亮度/色度分离、局部对比度和颜色参考校正增强鲁棒性，但不能从全饱和区域恢复不存在的信息。
- 直射光、阴影边界、镜面高光、反光ABS/PLA必须作为独立数据分层；质量不合格时减速、重采或安全停止。

## 10. “残缺特征也能识别”的安全边界

残缺识别定义为“在明确模型、足够可见证据和可验证不确定度下恢复身份/几何”，不等于任何残片都强行分类。

- 数字：可见笔画模板/局部描述子 + 布局先验 + 多帧一致性。
- 圆环：部分圆弧鲁棒拟合 + 半径/位置先验 + 拟合残差。
- 物料：部分轮廓、颜色、历史track和运动预测联合关联。
- 码垛：已知放置历史只是先验，必须有当前层/边缘视觉证据。
- 二维码/条码：依赖码制自身纠错能力；超出纠错范围必须拒绝。

所有结果报告 `visible_fraction`、有效特征数、第一/第二候选间隔和误差界。信息不足、近似并列或模型冲突时输出 `UNKNOWN` 并进入有限重试/换视角/安全停止。

## 11. 精度、畸变与坐标验收

### 11.1 不能使用的表述

- “全程X、Y均误差一像素以内”不能作为未经测量的整机承诺。
- “视觉图像无畸变”在物理上不成立；只能说按标定模型校正后，残余误差满足测量指标。
- 像素误差、地面毫米误差、机械重复定位误差和最终放置误差必须分别报告。

### 11.2 分层工程目标

| 层级 | 指标 | 当前目标/说明 |
|---|---|---|
| 相机内参 | 独立验证集重投影误差 | 目标RMS≤0.5px、95分位≤1.0px；以实测为准，未达标不得宣称 |
| 去畸变图 | 全视场直线残差/独立控制点残差 | 分区域报告；边缘不能被平均值掩盖 |
| 静态局部特征 | 相同目标、固定相机的中心重复性 | 目标X/Y的95分位均≤1px；仅代表局部检测重复性 |
| 平面映射 | 独立地面点X/Y误差 | 使用mm报告，分别给均值、RMS、95分位和最大值 |
| 动态跟踪 | 延迟补偿后的像素/mm误差 | 按速度、光照、遮挡分层，不使用静态结果代替 |
| 整机落点 | 抓取/圆环/码垛物理误差 | 用mm和成功率验收，包含通信、控制和机械误差 |

上述数值是工程门槛候选，不是官方规则，也不是当前已达到的性能。镜头、分辨率、安装高度和真实场地确定后，必须验证可达性并更新目标。

### 11.3 标定链

1. 棋盘格/ChArUco覆盖全视场、不同位置和倾角，锁定镜头、焦距、分辨率和裁剪。
2. 估计内参和畸变并保存版本；使用独立图像验证，不用训练标定图自证精度。
3. 运行时先去畸变，再建立图像→地面→机器人→执行器坐标链。
4. 在工作区独立物理点验证X/Y符号、尺度和局部误差热图。
5. 相机、镜头、焦距、安装位姿、分辨率或裁剪变化后，旧标定立即失效。

## 12. 后续实现门禁（V0～V9）

| 阶段 | 必须新增 | 完成条件 |
|---|---|---|
| V0 图像质量与标定 | 内参/畸变、undistort、质量指标、标定版本 | 独立验证报告和误差热图完成 |
| V1 任务码 | 二维码多帧一致、四段结构校验、超时/锁存 | 合法码稳定读取，非法/部分码拒绝 |
| V2 数字/条码 | 数字模板、歧义拒绝、条码可插拔后端 | 正负样本、旋转、透视、模糊和遮挡回归通过 |
| V3 物料实例 | 六色实例检测、姿态、抓取点、困难负样本 | 六色分层混淆矩阵和毫米定位报告完成 |
| V4 圆环 | 圆/椭圆、编号映射、局部亚像素细化 | 完整/残缺环均有拟合残差和拒绝门禁 |
| V5 通用跟踪 | track ID、数据关联、遮挡/重捕获、新鲜度 | 目标不乱号，丢失时不输出旧运动目标 |
| V6 运动判断 | 自运动补偿、世界速度、三态迟滞 | 移动物料不误判静止，未知状态失败关闭 |
| V7 码垛 | 层数、顶层、中心、倾斜/倒塌、放后验证 | 连续码垛视频和失败样本回归通过 |
| V8 太阳光鲁棒性 | 遮光/偏振评估、饱和门禁、光照数据矩阵 | 直射、阴影、反光场景有分层指标和安全降级 |
| V9 整机精度 | 视觉→UART→STM32→机械落点误差预算 | 静态像素、毫米定位和最终物理误差分别达标 |

依赖关系：`V0 → V1/V2/V3/V4 → V5 → V6/V7 → V8 → V9`。V0未通过前不能用阈值调参宣称高精度；V5未通过前不能用单帧位置驱动抓取。

## 13. 数据集与验收矩阵

每类功能至少覆盖：正常、强/弱光、太阳直射、阴影、反光、过曝、欠曝、运动模糊、旋转、透视、边缘位置、部分遮挡、目标接触/重叠、相似负样本、相机短时丢帧和标定版本错误。

数据按采集日期/场景划分训练、调参和独立测试集，不把相邻视频帧随机拆到不同集合。报告每类准确率/召回率、拒绝率、ID切换、静止/移动混淆、定位误差分布、P50/P95/P99延迟和失败样本。
