## 准备与拍照

1. 用A4纸裁一张约200×200mm的平整方纸。实际长宽可以略有不同，但四角须为直角；量并记录实际AB、AD边长，单位mm，不能直接把目标裁纸尺寸当成实测。量两条对角线检查裁切，明显不等则修整。200mm只是工程建议，不是竞赛规则。
2. 沿纸周边依次标A、B、C、D，字母靠近角而不盖住角。A为原点，AB和AD是方纸自己的X/Y，不需要对齐车体或转盘。两条对角线AC、BD交点标小十字M；在AM的中点标E，在BM的中点标F。使用直尺确定中点，不凭照片比例猜。M/E/F不参与四角拟合，作为留出几何检查。
3. 方纸平贴盘面中央，不悬空、卷曲或搭在螺钉头/厚胶带上；原盘面贴纸可移开以贴平，不必保留原布局。转盘、底盘、机构和相机保持本次固定姿态。检查相机画面能完整看见四角和M/E/F。无需为对齐方纸转动机构。
4. 保存新的1920×1080原图，沿用此前已实际使用的相机采集命令。使用新时间戳文件，保留原图；告知实际AB/AD长度。我方根据新原图填写像素和上下文，用户无需手填JSON或九个点的X/Y。

已收到实测盘面离地85.5mm、用户确认相机到盘面17.5cm=175mm；相机距离的测量起点尚未确认。175mm不作为镜头光心高度或固定像素比例使用。纸厚/平整误差须计入平面误差，不能因报告写85.5mm就宣称纸面高度已精确测得。

## 工具与坐标合同

`calibration/source_paper_template_20261105.json`存放新模板；实际宽高、像素和版本留空。初始3mm检查上限属于E的离线诊断参数，不是官方精度或抓取验收门限，也不能为让数据通过而事后随意放宽。

`scripts/source_marker_calibration.py fit-paper ... --output ...`调用实际矩形几何：A=(0,0)、B=(w,0)、C=(w,h)、D=(0,h)；M=(w/2,h/2)、E=(w/4,h/4)、F=(3w/4,h/4)。使用四角求单应性，M/E/F仅做留出检查。四个拟合点的残差接近零不意味着标定准确；留出检查也不能独立证明尺的比例、裁纸精度、镜头畸变或实际抓取误差。

```powershell
python scripts/pick_source_markers.py paper_original.png calibration/source_paper_template_20261105.json --output calibration/source_paper_measured.json
python scripts/source_marker_calibration.py fit-paper calibration/source_paper_measured.json --output calibration/source_paper_result.json
```

新标定使用`plane_origin`、`x_along_ab_y_toward_ad_mm`、`homography_image_to_plane`与`plane_mm`；不能用`chassis_mm`偷换局部坐标。preview在方纸坐标下拒绝alignment请求。原车体坐标接口继续可用，新增局部坐标不会绕过旧的姿态、平面、版本和覆盖区域检查。

纸的覆盖范围决定首轮有效区域，超出四角包围区仍拒绝外推；若三个取料点未全覆盖，需扩大/调整纸或另外测量验证，不强行放开边界。相机运动后原映射须重新匹配姿态；盘面映射不能直接用到物料顶面。自动A物理盘心拟合、纸坐标到车体/TCP关系、三位置可达/避让、位置保持与抓放事务仍未完成。仅四角不会让相机自动获得机器人坐标。
