## 1. 来源与目标

用户明确要求小车能够像参考视频一样，在移动中逐步改变朝向，把转向和平移接在一起。参考文件：`C:/Users/Tenderness/Pictures/c8814d9189db4507141f3db517508b82.mp4`（约14.6秒、1280×720、30fps）。视频仅为动作效果参考，不是本车性能证据；不能据此确认参考车算法、实际速度、是否自主或播放倍率。

验收目标是：在安全可行的行驶段，同时产生平移和旋转，连续通过中间路径点，稳定减速到终点；不把所有路线机械拆成“直走—停车—原地转向—再起步”。不承诺复现视频速度，不取消作业停靠和故障停车。

- R：FIELD-02/06、OBS-04、RUN-01/02；双起点、灰色车道包络、400mm中央车道、自主运行、物料放入载台后跨区运输继续生效。

- Q：FIELD-05、OBS-03保留待技术答疑；本车轮型、轮距、驱动反馈能力、满载重心和运动参数另属待实测项，不混同官方规则。
- P2：场地感知、目标位置与独立目标朝向、可行走廊/路径点、视觉定位修正；不发送裸PWM。
- P1：接受并验证目标，在统一时基下生成连续运动参考，执行位姿跟踪、车体到轮速的运动学转换、速度闭环及最终限幅/停车。轨迹生成不得在P1/P2两端各自重复计时。

## 3. 实现要求

1. 先核实实际底盘具有对应全向运动能力、四轮编号/旋向和驱动接口；不能仅因参考车使用麦轮就认定本车运动学已验证。
2. 分别规划位置与车身朝向，支持非零平移速度与非零角速度同时存在。车头不必始终沿路径切线；角度跨±π时连续处理。
3. 路径过渡必须处于安全走廊内。普通中间点不强制速度归零；抓放点、最终回区点、不可行转弯及安全事件允许或要求停车。保持原地旋转/分段通行回退能力，但原地旋转本身也须通过包络检查。
4. 对线速度、角速度及各自加速度设置限制；以S曲线或等效加加速度约束作为平顺性目标。调试可先采用加速度受限速度规划，再完善加加速度约束，不能把中间版本当成最终通过。
5. 统一车体坐标x向前、y向左、yaw逆时针；场地速度先按当前航向变换，再计算轮速。组合运动时核查每个轮子的速度/加速度与驱动饱和，不可仅分别限制vx、vy、ω后认为一定可行。
6. 通过时间缩放或统一可行速度缩放处理轮速约束，避免各轮随意独立削顶导致路径变形；饱和时需防积分累积。视觉修正、换段和重规划不能引起速度参考突跳。
7. 按2026-09-26生效决定使用HWT101航向及待冻结的运行中X/Y来源，结合视觉纠偏；PAW不再参与当前方案。验证偏置补偿、时间同步和新鲜度；轮反馈里程计只是候选，命令步数不代替整车实测位姿。此条修订记录见2026-10-01专题计划。
8. 使用随朝向变化的整车扫掠包络，加上定位误差、制动距离和安全余量检查车道/障碍。示例：300mm方形车身在45°时横向投影约424mm，不能因中心线仍在400mm车道内就允许通过；该尺寸仅作几何说明，不是本车测量值。
9. 空载、载物、不同机械臂运输姿态分别设运动限值。首版只在机械臂已处于经验证的运输姿态、物料已稳定入载台时连续行驶；不额外授权行驶中抓放或载物转盘分度。
10. 通信超时、定位失效、障碍侵入或跟踪超差时按既有安全策略减速/停车；不得为了保持“丝滑”延迟安全响应，恢复前重新验证轨迹。

## 4. 从完整装机载物状态开始实施与验收

2026-09-20用户进一步明确：直接从装上机械臂、载物后的稳定性和车道内通行开始，不单独开展空底盘/空载实车阶段。本节替代此前M1低速空底盘、M2独立组合运动再进入M3装机的顺序。软件及静态检查仍是上电运动前置条件，不等于要求重新开展空底盘试验；整车首次运动采用低速，不能直接套用视频速度。

| 阶段 | 内容 | 通过条件与证据 |
|---|---|---|
| M0 参数与软件检查 | 核对轮型/尺寸/旋向/反馈、坐标变换、角度跨界、轮速饱和和超时 | 测量表与确定性测试；未通过不进入运动试验 |
| M1 完整整车低速起步 | 装好机械臂，物料放入载台并处于运输姿态；低速直行、横移、制动及可行范围内转向 | 无异常旋向、明显打滑、物料滑移、车身失稳或持续振荡；记录参考/实测速度和装载配置 |
| M2 载物连续衔接与车道通行 | 同一整车配置测试平移同时转向、左右连续路线过渡，逐级提高到候选工作速度 | 指定过渡段实测平移与旋转同时存在，无非任务性停车；完整扫掠包络不越界、不碰障碍；不掉料、不倾覆，终点稳定 |
| M3 实际任务负载覆盖 | 覆盖任务会遇到的物料数量/槽位分布、最不利允许重心、运输姿态和电池工作范围 | 各配置运动限值重新验证；任务实际包含空载行程时在整车流程中覆盖，不另设空底盘阶段 |
| M4 场地与失效 | 双起点、窄道/障碍、视觉修正、重规划、定位及通信故障 | 完整扫掠包络合规，无法安全连续转弯时降速/停车/换路；故障响应符合既有门禁 |

验收必须使用固定机位视频和同步日志，不能仅凭跟拍视频“看着顺”。每种方向/实际任务负载组合候选要求连续成功5次（E，非官方次数）；记录所有失败而非只保留最佳一轮。

日志至少记录：时间戳、目标/实测x/y/yaw与vx/vy/ω、各轮目标/实测速度、定位健康、轨迹ID、负载配置、饱和与停车原因、车道/障碍最小余量。加速度和加加速度由明确采样/滤波方法评估，避免噪声差分被当作真实振动。

正式测试前冻结版本化参数：速度/加速度/加加速度上限、位置与航向误差上限、停稳速度阈值和持续时间、通行安全余量。数值需由本车测量和低速试验确定；未填写不得签署通过，不从参考视频估算后写成已验证参数。普通导航终点与抓放局部精定位分开验收。
