## G6220_Init实际做什么

tower.c:52仅调用G6220_Command(1)。tower.h定义Enable=1、CAN_ID=1、Modo=POZ=0x100；hcan.c的CAN_SendData发标准数据帧。因此实际排入CAN发送邮箱的是：标准ID 0x101、DLC8、FF FF FF FF FF FF FF FC。

这只请求使能电机，不自动配置位置速度模式、不校准编码器/电流环、不设置CAN ID、不找机械原点、不保存零点，也不检查是否成功。源码的HAL_CAN_AddTxMessage返回值未处理，因此连发送入队成功也未在此函数显式确认。修改Modo宏只是改变报文ID，不代表修改了电机保存的Control Mode。

## 函数与文件分工

| 函数 | 实际行为 |
|---|---|
| Tower_init | 启动CAN过滤/中断，osDelay(1000)，向35与28步进电机发回零命令，再发送G6220使能；没有在此等待全部回零完成 |
| Tower_Control | 先发yaw位置，HAL_Delay(200)，发Z位置，再HAL_Delay(200)，发伸缩位置；分时发指令，不保证前一轴到位，不是三轴轨迹同步 |
| G6220_Command | 7个FF＋FC使能/FD失能/FE保存当前零点/FB清错误；固定按Modo+ID发送，非法CMD会使Data[7]未初始化 |
| G6220_Position | position单位0.1度，乘0.00174533变rad；speed单位度/秒，乘0.0174533变rad/s；两个float低字节先发，标准ID=0x100+ID、8字节；speed表示运动速度上限 |
| G6220_Speed | 度/秒转rad/s，以float低字节先发，标准ID=0x200+ID、4字节；参数uint16_t不能正常表示负方向速度，头文件也未声明此函数 |
| TowerMotor_Init/Motor_Homing | 对ID0x300与0x400发送扩展帧9A 02 00 6B，属于示例的张大头步进协议；不属于J4310控制 |
| Motor_AbsPosition | 构造16字节步进位置命令，经Can_SendCmd拆成扩展帧，写方向、转速、步数 |
| Motor35_AbsPosition | 由claw_h_max-h计算Z位移并限幅，乘44.94转步数，速度乘30；是原机构换算 |
| Motor28_AbsPosition | 以r_min为起点，限位后乘3.189转步数，速度乘0.53；同样不是通用机械参数 |
| Response_Handle | 仅看ExtId=0x300/0x400或StdId=0就置标志，不检查数据内容、DLC、故障、实际位置或本次事务 |

tower.h同时定义原车高度/半径和夹爪TIM1 CH1 PWM宏。主任务Tower_task.c才包含持续更新Motor28/35/DM目标、夹爪姿态与取放动作相关逻辑。OS_Tower_Init的while只等MOTOR35_flag且无超时；不能由这个标志认为三轴全部初始化或到位。主循环约含10ms任务延时及两次1ms延时，反复发送轴目标，但这本身不等于基于新鲜视觉的动态抓取。

## 适配本项目必须处理的差异

1. 模式与ID：当前源默认位置速度模式+CAN_ID=1，对应0x101。电机必须实际配置同模式；MIT需不同打包。反馈Master ID默认0只是手册默认，不能把所有StdId=0都当本电机到位。
2. 波特率：型号手册CAN标准帧固定1Mbps。示例CAN1 prescaler6、BS1=3、BS2=3，在其8MHz HSE/168MHz SYSCLK/APB1÷4即PCLK1=42MHz时，42MHz/[6×(1+3+3)]=1Mbps。本项目现有张大头记录为500kbps，不能与固定1Mbps节点在同一物理CAN总线按两种速率同时工作；先核对能否统一实际支持速率或现有独立CAN通道，不默认改PCB/引脚。
3. 软件接口：外部代码使用HAL、CMSIS osDelay和阻塞HAL_Delay；本项目LOC-03要求标准外设库＋FreeRTOS原生API，移植报文编码/状态机思想，底层CAN和调度按当前工程适配，不混入HAL/CMSIS包装层。示例PA11/PA12也不是本项目已确认CAN1 PD0/PD1，不能覆盖成品PCB定义。
4. 完成判定：当前回调只传ExtId/StdId/data，没传IDE/DLC，扩展报文的StdId字段不应参与标准反馈匹配。必须根据真实IDE/DLC、Master ID及payload电机ID解析位置/速度/故障/温度、时间戳与超时，以误差和速度阈值/持续时间判断到位。尾部完整反馈解包是注释代码，P_MAX12.5/V_MAX45/T_MAX10只是示例，不能当本电机读回参数。
5. 机械与限幅：G6220中空云台与J4310减速关节的尺寸/输出速度/扭矩/零点与传动不相同。源注释2300度/秒和示例1800度/秒不是该型号许可参数。源码没yaw行程保护，Z与伸缩只按原车常数截断；本车需实测。保存当前零点不等于运动到机械原点。
6. 异步与超时：不能凭两次200ms延时认为同步/完成；发送结果、反馈在线、回零/运动超时、故障和臂盘互锁需要补齐。尤其不能把OS_Tower_Init中的无界等待照搬成整车状态机。
