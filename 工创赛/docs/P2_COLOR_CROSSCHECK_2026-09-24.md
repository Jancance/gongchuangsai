# P2六色初始样本联合检查

日期：2026-09-24。阶段：离线开发诊断，未通过六色自动分类验收。

## 方法与证据

脚本：`tmp/six_color_crosscheck.py`。对每张完整图像同时应用全部六个候选规则，不根据文件名或已知颜色选择检测器，不限定中央ROI。文件名对应的人工标签仅用于报告。

沿用红/黄/蓝/绿的HSV试验阈值、灰度≤60的暗区规则，新增浅蓝HSV候选范围H=90～115、S=25～180、V=100～255。5×5闭操作后保留外轮廓面积≥500px²的区域。全部阈值都未经过独立数据验证；暗区规则不能直接当黑色分类器。

输入原图副本、SHA256、规则配置、候选计数和拼图位于 `evidence/six_color_crosscheck_2026-09-24/`；`results.json`为机器可读结果。所有规则命中数不是物料数量，同一物料可能被多种规则重复命中。

## 后续实现顺序

1. 在已有原图上分离“候选实例生成”和“实例内部颜色判断”，消除重叠区域的重复计数；保留不确定输出。
2. 比较黑/深蓝的实例内颜色证据，排除高光并检查有效可见面积；不能只按亮度判黑，也不能仅取最大区域就认定正确。
3. 加入完整边界、形状及工作区约束，明确对新背景/位置/光照的适用范围。不得写死本批样本的中心坐标。
4. 规则冻结后使用新位置、双物料、空场与昼夜独立样本验证；物理抓取前另验收顶面中心、标定和P1接口。

## 后续同日开发：区域级颜色判定v0

新增独立离线脚本 `scripts/p2_color_probe.py`，仅依赖OpenCV/NumPy；不接相机、串口、主状态机或执行器。命令：

```powershell
python scripts/p2_color_probe.py --input-dir evidence/six_color_crosscheck_2026-09-24/inputs --output-dir evidence/six_color_probe_v0
```

所有输入共用一套规则：颜色和暗区掩膜合并生成候选，检查面积/边界/粗形状后，在候选内部排除接近饱和的像素，按颜色证据占比及领先幅度输出一个标签。黑色需暗像素占比高且可辨色彩证据少。规则无法区分、有效像素少或候选碰边时保留UNKNOWN。没有使用预期颜色、文件名、固定中心或只选最大区域来分类。

结果：七张开发物料图的内部候选标签与人工标签一致，白天空背景无候选。夜间红/黄/蓝仍有碰边背景候选，明确记录UNKNOWN:TOUCHES_BORDER；它们不是已解决的任意背景问题。夜间物料轮廓还包含部分阴影，浅蓝轮廓受高光影响；因此即使颜色标签匹配，轮廓质心仍不具备抓取或顶面圆心含义。

已运行额外软件检查：白天蓝图水平翻转仍为blue；黑/蓝图人工左右拼接获得black和blue两个区域；裁切穿过蓝物料后不输出有效颜色；空背景不输出有效颜色。上述均为已有图像的变换检查，不是实拍双物料验收。

输出 `evidence/six_color_probe_v0/` 包含逐图区域信息、拒绝原因、轮廓图和overview.png。这些是开发集回放结果，禁止宣称100%识别准确率或六色正式验收通过。下一项实物验证：新的黑蓝双物料、分离且完整入镜，使用当前光照和曝光50/增益30采集；相邻、遮挡、移动、不同位置与未知物体仍未测试。
