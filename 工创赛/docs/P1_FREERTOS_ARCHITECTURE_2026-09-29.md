## 任务和消息的候选分工

以下是任务职责候选，最终数量可合并或拆分；在真实通信量、控制周期和内存测得前不指定固定优先级数字。

| 职责 | 输入/输出 | 主要约束 |
|---|---|---|
| 安全监督 | 急停反馈、故障、Orange Pi心跳、定位新鲜度 → 全局安全状态 | 仅健康且本轮已启动才允许动作；200ms无有效心跳开始减速、500ms停止并禁止机构是既有工程目标，需实测 |
| 底盘控制 | 目标速度/位姿、HWT101、轮速反馈及有效X/Y → 各轮目标/状态 | 单一任务/参考时基推进漂移到位和连续过点；真实dt、统一轮速与加速度限制；超时/错误转安全状态，详见漂移专题 |
| CAN与机构 | CAN收发、两轴原点、夹爪、原270°驱动适配、集中高度参数 → 动作结果 | 原点、软行程、臂盘互锁；原料盘与车载盘高度分开，`ACCEPTED`与`DONE`分开，重复序号不重复动作 |
| Orange Pi通信 | USART6接收、CRC/序号/心跳 → 已验证目标；回传P1状态与几何版本 | UART中断/DMA收字节，任务解析；高度/工作平面/标定版本合同待实现，匹配后才放行抓放 |
| 雷达通信 | USART3数据、节点/区域、扫描序号 → 有效障碍事件 | 新阶段6（原5）集成；ISR/DMA仅收字节，任务做COBS/CRC及超时，14圈等待不阻塞安全/控制任务 |
| 扫描机构 | 升降/旋转目标、原点/到位状态 → 扫描姿态有效性 | 新阶段5实际扫描前完成独立调试和固定；新阶段7（原6剩余部分）集成自动联动，停稳且姿态已验证才扫描 |
| 低优先级服务 | 屏幕、蜂鸣、诊断日志、配置保存 | 成功蜂鸣次数可改，显示或日志慢不能拖住安全、控制与通信 |

ISR/DMA与任务之间采用有界通知、环形缓冲或队列；业务请求通过消息传递，不让两个任务同时读取同一个UART，也不在中断里解析完整雷达帧。共享外设由明确的单一任务或互斥机制管理。队列满、缓冲溢出和任务超时均可观察、可触发保守处理，不能静默覆盖旧数据。

定时与看门狗：FreeRTOS tick用于任务调度和一般超时；运动控制周期、脉冲/PWM与需更高确定性的采样使用适当硬件定时器/外设。独立硬件急停直接切断执行器使能；硬件看门狗仅在关键任务持续健康时喂狗，任务卡死、栈溢出或调度异常不能靠低优先级任务假装健康。软件安全任务不能代替硬件链路。
