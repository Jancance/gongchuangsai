# 最终使用教学与一次完整比赛模拟

日期：2026-10-12。来源：用户明确要求“最后要教我怎么用，加入计划中，最后所有项目完成，模拟比赛现场进行一次”。本文件为工程交付安排E，不新增官方规则；作为总计划第8阶段和P2阶段F的最后交付项，原八阶段顺序与两组职责保持。

## 收尾顺序与当前状态

各模块及整车功能完成并通过相应实物验收 → 最终使用教学/用户独立操作 → 一次完整模拟比赛 → 问题修复及必要复测 → 最终版本与资料归档。

当前只完成计划增加，没有开展教学验收或模拟。相机/毫米/运动跟随抓取、机构及整车场地仍有未闭环项，当前实际串口/动作禁用状态不变。已有地面白纸试验、软件测试及实物就位说明不能作为全部功能完成证据。普通开发过程继续按一步一个操作指导，最终再系统教完整使用方法。

## 交付项一：教会用户使用最终项目

使用最终验收版本与实际界面，提供中文使用说明、快捷操作页、配置备份及常见故障处理。教学覆盖全部项目的运行操作；视觉与搬运部分由视觉组负责，底盘/定位/雷达/公共F407由电控组负责，联合讲清整车入口与接口。不是只介绍源码或菜单。

| 教学内容 | 用户需要独立完成的操作 | 完成证据 |
|---|---|---|
| 开始与结束 | 按最终供电/检查顺序启动，辨认调试与比赛入口、运行状态，结束并正确关闭；会使用已验收的停止/故障处理方式 | 用户实际操作及状态记录 |
| 模式与现场颜色 | 选择正确窗口/功能，六色采样与HSV调整，候选配置保存/选择/回退，理解颜色工具S保存与主程序S叠放的区别 | 调参前后配置、单件/交叉/空场复测 |
| 标定与高度 | 查看有效安装/工作平面/几何版本，按实測值修改原料盘与车载盘的各自参数，知道安装或高度变化后需复核哪些项目 | 参数/版本一致，用户能说明变更影响 |
| 搬运机构 | 使用最终已验收入口检查回零、夹爪、270°盘工位/库存及动作完成反馈，区分接受请求与真正完成 | 机构状态和单件已验收流程复现 |
| 底盘、定位与雷达 | 按实物最终版本选择/验证起点、雷达扫描/定位状态及路线，识别缺包/旧结果/失效，使用已验收的停止或重新检查流程 | 完整扫描/有效状态及可追溯日志 |
| 任务与显示 | 检查完整任务码、两批任务、正确抓取/放置计数和完成状态，辨认未知/拒绝 | 已确认语义的任务与屏幕记录一致 |
| 文件和故障 | 找到实际配置与日志路径，导出证据，恢复上一稳定版本；按教程处理相机断连、错色/失框、通信/定位故障 | 用户自己完成一次备份/恢复/日志导出 |

助手先演示并给可复制操作，随后用户独立复现关键流程；需要反复依赖助手临时口述时不签署“已教会”。危险或未验收动作不作为练习入口。最终是否有一键环境管理/回退，以实现与验收的真实功能为准，当前仅候选配置/CLI方法可用，不提前编造最终界面。

## 交付项二：全部项目完成后模拟比赛一次

正式模拟前明确提醒用户准备真实尺寸的模拟场地、真实六色物料/工位、任务码/显示、障碍、已装机整车及同一比赛电池。先验收固定安装、几何与高度/版本、搬运/底盘/定位/扫描、通信时效/故障安全、单件和批次抓放、车道/回区及续航。双起点分项回归必须已有记录；用户要求的一次最终模拟不替代这些验收。

一次模拟按完整比赛流程组织：

1. 场地与物件位置按当前官方基线准备；记录版本、实际尺寸、灯光、原料盘/车载盘各自高度、障碍与物料，检查初始尺寸、屏幕及电池。未答疑的障碍数量/禁区等不自行冒充官方约束。
2. 用户完成赛前配置/必要颜色复核、启动自检和参数冻结；抽签选择本轮启停区与有效任务码，保存任务原文及本轮start_id。
3. 一键自主启动，按已确认四段任务码语义完成两批任务：识别、单件抓取、载台确认、跨区域运输、对应加工/暂存或码垛、显示与同区返回。按用户工程目标包含移动物料跟随抓取工况，不把等待物料停下改成最终目标。
4. 正式运行阶段不靠手动改阈值、触碰机器人/电脑或遥控补救。需要人工停止时按安全流程处理并记为中断/失败样本，不能把干预后拼接的段落记作一次自主完成。
5. 记录计时、任务与状态序列、抓放计数、载台/码垛结果、落环、车道与回区、最低电压、错误/恢复；按本轮已确认规则评估结果。日志与视频同步保存，并核对显示计数与实际物料结果。
6. 当次失败项形成清单，修复后做相应分项和必要整场复测；保留原失败记录，不因程序退出正常签署成功。最终归档实际通过的版本和完整运行证据。

“一次”指项目完成后安排一次正式完整模拟；既有双起点、连续两轮不换电及故障回归仍按原验收要求执行。该模拟可以抽中一个起点，另一个起点必须有先前独立完整回归证据；不擅自把用户一次请求扩大成新的强制轮数。模拟比赛流程是教学/工程演练，不等于官方赛成绩。
