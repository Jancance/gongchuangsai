# PAW3395＋HWT101底盘定位专项计划

> 2026-09-26当前变更：用户取消PAW3395和MaixCAM2；180°舵机升降雷达、ULN2003步进转动雷达；USART3改雷达，取消三夹紧及三占用检测旧用途，PB1保留270°三槽转盘。初始化成功蜂鸣次数可改。下文涉及旧硬件的内容仅供追溯，当前接口及待确认项以[雷达与手动修改计划](RADAR_AND_MANUAL_P1_PLAN_2026-09-26.md)和更新后的规则基线为准。外部F103工程不改，后续由用户手动修改，代码示例使用中文注释；实时X/Y定位尚未闭环。

> 状态：工程方案已选定，实物性能待验收  
> 更新日期：2026-08-27  
> 方案边界：替代OPS-9的相对底盘里程计功能；不把相对积分误称为无漂移绝对定位。

## 1. 方案结论与职责

- 主位移源：PAW3395光学位移模块，输出车体平面内相对位移 `delta_x/delta_y`。
- 主航向源：HWT101，输出Z轴航向角和角速度；项目不再采购或使用ICM42688。
- 电机编码器：只用于各轮速度闭环、堵转/打滑诊断和短时安全控制，不作为场地X/Y位置主里程计。
- STM32F407（P1）：完成PAW3395 SPI采样、HWT101 UART采样、时间同步、安装偏置补偿、位姿积分、质量门禁和失效停车。
- Orange Pi（P2）：使用车道、路口、启停区和功能区视觉观测修正累计漂移；最终抓取/放置继续使用局部视觉闭环。
- OPS-9：不作为计划内主定位器件；仅当本方案未通过实车门禁时，才重新评估为回退选项。

## 2. 定位数据流

```text
PAW3395 --SPI/MOTION--> STM32F407
HWT101  -----UART-----> STM32F407
电机编码器 -----------> STM32F407速度闭环/诊断
                         |
                         | RobotState + OdometryHealth
                         v
                       Orange Pi
前视/向下视觉 ----------> 车道、路口、功能区、启停区位置修正
                         |
                         v
               修正后的field位姿/短时轨迹目标
                         |
                         v
                      STM32F407
```

PAW3395与HWT101均是相对传感器。每轮必须由抽签的 `start_id=1/2` 装载已标定初始位姿；传感器离地、复位或质量失效后，必须停车并用视觉重新定位，禁止继续盲积分。

## 3. 坐标、补偿与接口

统一车体坐标：原点为底盘旋转中心，`x`向前、`y`向左、`yaw`逆时针为正，单位分别为mm和rad。

PAW3395若安装在旋转中心偏置 `r=(rx, ry)`，需要先扣除旋转引起的圆弧位移，再转入场地坐标。符号以实车正向测试为准：

```text
dx_body = dx_sensor + ry * delta_yaw
dy_body = dy_sensor - rx * delta_yaw

dx_field = cos(yaw_mid) * dx_body - sin(yaw_mid) * dy_body
dy_field = sin(yaw_mid) * dx_body + cos(yaw_mid) * dy_body
```

P1上报字段至少包含：

```text
timestamp_ns, pose_seq
x_mm, y_mm, yaw_rad
vx_mm_s, vy_mm_s, yaw_rate_rad_s
paw_delta_x, paw_delta_y, paw_squal, paw_shutter, paw_lifted
hwt_status, pose_valid, pose_age_ms
localization_source, localization_calibration_id, rejection_reason
```

P2发回的定位修正必须带时间戳、坐标系、标定ID、不确定度和修正来源；过期、跳变、坐标系不匹配或低置信修正必须拒绝。

## 4. 硬件与机械门禁

### PAW3395

- 使用完整传感器、匹配镜头和照明组件，不能只按芯片CPI宣传值判断可用性。
- 镜头参考面至跟踪表面目标为2.4mm，允许范围按手册2.2～2.6mm设计。
- 优先安装在底盘旋转中心附近；偏置量 `rx/ry` 必须实测写入带版本标定文件。
- 设计小行程浮动/随动安装、低摩擦防撞滑环、遮光和防尘结构，既保持高度又不遮挡光学窗口。
- 模块板VDD可接受范围以购买版本原理图实测确认；逻辑电平VDDIO不得超过3.3V。

### HWT101

- 安装面刚性固定，Z轴垂直，远离电机强振动和松动结构。
- 开机静止完成初始化，保存本轮航向零点；确认具体型号后锁定供电、波特率、输出频率和数据协议。
- 禁止将HWT101加速度积分为X/Y位置；本项目只使用其航向角和角速度。

## 5. 软件实施顺序

| 阶段 | 工作 | 出口门禁 |
|---|---|---|
| L0 器件核验 | 核对PAW3395模块版本/镜头/寄存器、HWT101具体后缀/协议/电平 | 两个模块在电机禁止状态下连续输出30分钟，无复位和解析错误 |
| L1 单传感器驱动 | SPI Motion Burst、MOTION中断、HWT101 UART解析、时间戳 | PAW位移符号和HWT航向符号与车体坐标一致；坏帧/超时可识别 |
| L2 机械样机 | 2.4mm浮动光学头、中心偏置测量、遮光防尘 | 全底盘姿态和允许地面起伏下不碰地、不失焦，初始尺寸仍合规 |
| L3 实地标定 | 实际赛道材料上标定X/Y比例、轴不正交、安装角、中心偏置和不同速度 | 前/后/左/右各1000mm重复10次，保留原始计数和误差分布 |
| L4 位姿融合 | 中点航向积分、角度解缠、异常增量/SQUAL/Lift/Shutter门禁 | 原地转360度不产生不可接受假平移；失效样本不进入位姿积分 |
| L5 视觉纠偏 | 起点、路口、功能区、启停区视觉位置修正和标定ID检查 | 人为加入累计误差后能够低速、安全收敛；错误地标不造成跳变 |
| L6 整场验证 | 两起点、随机障碍、两轮连续运行、故障注入 | 20轮统计达到本文件第6节门禁，且15秒前恢复/降级/停车 |

## 6. 替代OPS-9的验收条件

以下均为工程门禁，不是官方规则；实测前不得标记“已完成”。

1. 实际场地材料上，前/后/左/右各1000mm、每方向10次，最大终点误差目标不超过8mm，并分别报告均值、95分位和最大值。
2. 原地正反360度各10次，完成安装偏置补偿后，虚假平移目标不超过5mm；航向闭合误差单独统计。
3. 2.4m级典型路线连续20次，场地级到站误差95分位目标不超过15mm；最终放置仍由局部视觉闭环验收。
4. 覆盖灰色车道、功能区、接缝、阴影、强弱光、反光、灰尘和不同运动速度；不得只在鼠标垫上验收。
5. 每次 `Lift_Stat`、低SQUAL、异常Shutter、数据过期、HWT101超时或STM32复位都必须被检测，不允许静默累计错误坐标。
6. 定位失效后3秒内作出减速、停车或重定位决定，并在规则15秒窗口前恢复、降级或安全结束。
7. `start_id=1/2`分别至少10次完整回原启停区；以整车投影入区、速度为零和俯视视频为证据。

只有L0～L6全部通过，才能签署“PAW3395＋HWT101替代OPS-9”。任一关键门禁未通过时，先修机械高度、地面适应或视觉重定位，不得用提高CPI掩盖比例误差；仍不通过再重新评估OPS-9或其他冗余里程计。
