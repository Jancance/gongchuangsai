## 修改路线

只编辑实际工程 `USER/motion_action_plan.h` 的APP_MOTION_ACTIONS，重新编译下载。每项为 `{动作, 基础RPM, 运行毫秒, 相对角度}`：

```c
#define APP_MOTION_ACTIONS { \
    {MOTION_FORWARD, 15U, 8000U, 0.0f}, \
    {MOTION_LEFT,    15U, 8000U, 0.0f}, \
    {MOTION_TURN,     0U,    0U, 90.0f}, \
    {MOTION_FORWARD, 15U, 8000U, 0.0f} \
}
```

MOTION_FORWARD/LEFT/RIGHT表示前/左/右平移，基础速度3至15RPM、时长1至8000ms、角度填0；MOTION_TURN表示相对转向，速度/时长填0，角度允许+5至+90或-5至-90度，正为逆时针。转向保持现有5/3/1RPM减速及1度到位容差，不能在表里把转向变成匀速定时运行。当前只保留已测试的低速范围；改变速度、顺序、角度或次数后均需重新验证实际动作和空间。

动作数1至8，超过容量编译拒绝。启动校验非法种类、NaN/越界角度、速度/时长、平移与转向字段混用，并按动作运行上限加停止/间隔预算拒绝明显超过120秒的表。该预算不是完成时间保证，原35秒单段、120秒整组和全部安全截止仍独立生效；实际姿态/电机异常会停止，不能清故障继续。

## 调度与保护

App_CombinedTestStep逐项装载表，不创建新任务。每段速度和时长交给前端和执行器同时锁存：ChassisAuto_BeginTranslationTimed/Chassis_TranslationHoldCommandsAtSpeed，纠偏叠加后各轮幅值不超过基础+2RPM，最低基础3避免纠偏反转。旧单段函数保留包装，反馈保护仍30RPM。后端时限为该平移时长+1秒，不沿用原固定8秒兜底。

段间正常停稳、保持VM/使能、短暂停顿，再装载下一项；故障/取消不会重新装载。重复转向只在前一个实际会话成功、无trip且已经释放后初始化下一个局部HeadingSession，不清硬件/系统故障。各段结果数组容量8。只有最后一项成功、四轮停稳及VM关闭才整组成功。

串口仅ARM/START/KEEP/STOP，不接收任意动作表写入。原COM和健康时序/私有许可/失联/PC13取消/看门狗规则保留。组合TM1从55字段扩为56，末尾追加sequence_count；主机兼容历史48/51/55和新56，按实际动作数判断完成，不能写死四段。单段遥测仍48字段。最新主机必需与新固件配套，否则旧客户端不能正确识别非四段表。
