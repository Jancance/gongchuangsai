# 避障实现与几何限制

本文是实现细节；规则分类和验收边界以 [2027竞赛规则与设计约束基线](competition_requirements_2027.md) 的 `FIELD-*`、`OBS-*` 和 `RUN-*` 为准。

巡线、十字路口、全局换路、双起点和回启停区的完整逻辑见 [导航与回区专项设计](NAVIGATION_AND_RETURN_LOGIC.md)。

## 当前算法

前视相机在 LAB 亮度通道分割黑色区域，经形态学和连通域筛选后，取候选底边中心投影到地面毫米坐标。规划器将障碍按“障碍半径+车体半宽+边界余量”膨胀，再在车体中心允许区间内搜索局部横向走廊。

配置默认只是占位值，未标定前真实服务会拒绝启动。现场灰度、阴影、黑色线缆和车道边界都可能形成假目标，必须用真实场地图像调整阈值和组件几何约束。

## 关键几何事实

400mm车道、50mm直径障碍和240mm宽车体并不保证能够在任意横截面并排通过。若障碍位于车道正中且要求保留20mm间隙，局部侧绕可能没有解。因此：

- 机械宽度越小越有利。按新基线优先在约230–260mm范围内设计，当前建议目标为230–240mm；任何数值都不是避障保证，必须用包含软线、屏幕和传感器的完整动态转弯包络校核。
- 规划器无局部走廊时返回 `GLOBAL_REPLAN`，应走赛道网络中的另一条路线。
- 若场地要求必须在同一窄路段通过正中障碍，机械组必须重新计算并缩窄车体。
- 禁止为了“总能输出路径”而减小边界余量到零。

## 数据集与验收

采集正常、正中、左右边缘、十字路口、二维码/原料区入口、多个障碍形成狭窄通道、暗光、反光、运动模糊、相机丢帧、阴影、黑色任务物料和其他黑色非障碍物。每张图保存原图、标定版本、掩膜、连通域、毫米坐标、规划结果和拒绝原因。

100次动态测试必须零碰撞、零越界。出现未见过的失败样本时先加入失败语料库，再修改阈值；不得只对最后一张图调参。
