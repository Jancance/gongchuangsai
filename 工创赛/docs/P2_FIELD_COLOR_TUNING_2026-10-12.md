## 用已有工具实现可回退的现场操作（E）

固定最终相机位置与灯光，先锁定曝光、增益、白平衡，再做HSV；先退出其他预览。在香橙派终端，用当前有效配置复制出现场候选，保留原工作版本。cp -n只在候选不存在时创建，再次运行保留已有现场编辑：

```bash
cp -n /home/orangepi/p2-integrated-20261003/vision_app/code/config/material_color_thresholds.json /home/orangepi/p2-integrated-20261003/vision_app/code/config/material_color_thresholds_field_20261012.json
python3 /home/orangepi/p2-integrated-20261003/vision_app/run.py --feature color --config /home/orangepi/p2-integrated-20261003/vision_app/code/config/material_color_thresholds_field_20261012.json
```

工具已有启动/格式校验；第一行失败时不要继续创建空白现场配置，否则工具会退回旧默认预设。颜色顶面先采样，随后用正常、暗处及高光样本分别观察；避免采到手、白纸和背景。自动统计只是候选，人工检查蓝/浅蓝与黑/阴影混淆后再决定保存。

在颜色标定窗口中数字1红、2黄、3蓝、4绿、5黑、6浅蓝；拖动框选，滑条调范围，U撤销，C清当前采样，S保存，Q退出。S含义只针对此窗口；主程序S仍为叠放模式，原功能不变。

保存后用候选配置启动FOLLOW进行复测，不覆盖原工作配置：

```bash
python3 /home/orangepi/p2-integrated-20261003/vision_app/run.py --material-color-config /home/orangepi/p2-integrated-20261003/vision_app/code/config/material_color_thresholds_field_20261012.json
```

检查单件六色、蓝/浅蓝同时、黄/黑同时、纯空场和手部背景。至少关注标签/数量/误报/失检及处理时效，不因某一件有掩膜就冻结参数。不合适时退出，运行原默认入口即可回到原工作配置；不用人工反改六个滑条。光照/高度/几何变化须记录，不能拿更宽HSV处理完全削顶丢失的信息。
