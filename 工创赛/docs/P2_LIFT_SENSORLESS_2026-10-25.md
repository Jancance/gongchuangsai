# 35升降手动低速Senless回零

## 当前已确认输入

用户不装35原点开关，确认下方有挡块；方向request1/协议0向下，request2/协议1向上。用户本轮参数截图read_result1，mode0、direction0、rpm0x1E=30、timeout0x2710=10000ms、detect_rpm0x12C=300、current0x320=800mA、detect_time0x3C=60ms、auto_home0。以本台实际读取为依据，未将厂家默认值直接当实测。

正常升降保持3000RPM目标/加速档250/5000脉冲；回零使用独立的低速参数。当前位置模式02与回零命令中的模式02属于不同命令，不混为同一含义。

## 本次只试一遍

1. 重开实际Keil工程，下载本版、F5，VM请求1，等待约3秒身份读取完成。四轮断开、重力轴承托及原外部开关保持。
2. 用现有单次点动将机构放在下挡块上方约3～5mm，保持停止。request1下、2上，每次5000脉冲的3mm只是此前粗测，不连续累计盲走。
3. Watch将`g_lift_home_request=1`写一次，观察是否低速向下、接触下挡块后停止。默认不上电回零，不自动往返或重试。
4. 需要中止立即写`g_lift_home_request=2`；旧`g_lift_motion_request=3`在回零忙/失败时也会先退出回零再停车。均不发失能/松轴命令。
5. 回传实际是否碰到挡块/是否提前停/是否持续顶住，以及`g_lift_home_state`、`g_lift_home_result`、`g_lift_home_flags`。尚未碰挡块就停也需明确报告，不能仅看软件成功标志。

## 状态与边界

| 变量 | 说明 |
|---|---|
| home_state0 | 空闲 |
| 1～5 | 复核Emm、实际参数、使能/保护、编码器/校准状态，最后下发回零 |
| 6～7 | 监测回零与静止 |
| 8 / result1 | 驱动报告此次回零结束且读回速度0；必须结合真实挡块观察 |
| 9 | 失败锁存，不自动重试；普通上下运动也拒绝，先中止成功或另行排查 |
| 10 / result2 | 中止回零与立即停止均收到应答，不等同独立物理停止测量 |
| result3 | 准备阶段2.5秒或触发后11秒主控超时，可能已启动时尝试中止/停车 |
| result4/5 | 通信/命令格式异常，或驱动保护/编码器校准未就绪 |
| result6/7 | 身份/供电/运动忙不允许，或回零参数已偏离本次实测值 |
| home_reported | 仅驱动报告的原点状态，失败/中止/掉电失效；不是物理验收标志 |

本轮只使用实测方向0、30RPM、10秒、检测300RPM/800mA/60ms、auto0；任何改变都拒绝开始，不自动修参数、不保存参数、不启用上电自动回零。存储mode0保持，由`9A 02 00 6B`明确触发多圈碰撞回零。中止使用`9C 48 6B`，随后`FE 98 00 6B`停车。驱动器自己10秒超时，主控触发后11秒兜底；从3～5mm处开始是为了用短搜索验证，不直接从全高搜索。

本次必须看到启动后正在回零位，或匹配5号`9A 9F 6B`新完成通知，再看到失败位清零、编码器/校准正常且速度为0，才记软件完成。查询前FIFO清理也捕获通知，但每次触发在清理后清旧通知，默认空闲位不能冒充本次成功。驱动阈值可能因机构摩擦/重力提前触发，故仍要用户核实实物挡块接触。未采用单圈零点替代升降机械原点。
