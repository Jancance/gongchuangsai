## 程序与使用方式

原完整应用保留在板端/home/orangepi/p2-generic135-lightblue1-20261027/vision_app。原主程序、四工具、原阈值/跟踪/相机配置不因本轮记录器修订而替换。日常完整应用启动为：

```bash
python3 /home/orangepi/p2-generic135-lightblue1-20261027/vision_app/run.py
```

实时启动默认FOLLOW，点击预览按R进入三环。原像素预览会画候选中心，未标定时普通主程序终端不输出稳定Centers；这不等同于v2稳定输出接口已经整合到主程序。

本轮稳定像素取证仍使用独立记录器，可指定3～60秒并自动退出：

```bash
python3 /home/orangepi/p2_ring_pixel_audit_v2_20261027.py --app /home/orangepi/p2-generic135-lightblue1-20261027/vision_app --seconds 30
```

v2日志中的centers_px与usable_for_pixel_statistics保留候选兼容语义；pixel_ready要求新鲜、原detector_stable=true、置信度达到配置门。stable_centers_px在任一门失败时为空，终端Centers为这一稳定坐标，CandidateCenters单列。最多五类事件原图，每类只保留首次，首次stable恢复也可能位于尚未完全停止的运动中。

坐标单位为1920×1080原图像素，左上角原点，X右/Y下。当前纸面人工对应左输出1=数字3、中输出2=数字2、右输出3=数字1。没有实施任意摆法数字OCR，不直接反转原输出或改变发送协议冒充编号识别。用户尺寸为两段圆心距均150mm、已报最外圈外径95mm，资料保留，不据此开放毫米映射。
