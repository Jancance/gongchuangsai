# 三方向分段速度候选与动态时间预算

2026-10-28，本地软件候选。前进、左移、右移最高20cm/s均尚未实车验收。本轮没有打开串口、复位、烧录或发车。

## 现在可以改什么

在实际工程 `3.stm32f407工程/USER/route_config.h` 集中填写：

```c
#define APP_ROUTE_USE_CUSTOM 0
#define APP_ROUTE_SPEED_TRIAL_ENABLE 0
#define APP_ROUTE_FORWARD_MAX_CM_S 20.0f
#define APP_ROUTE_LEFT_MAX_CM_S    20.0f
#define APP_ROUTE_RIGHT_MAX_CM_S   20.0f
```

三个上限互相独立，是本阶段的软件候选上限，不是实测能力。每个方向上限必须大于0且不超过20cm/s。修改后每段仍在APP_ROUTE_ROWS(X)中填写自己的速度。

交付时两个开关都是0，原默认四段仍保留。两个开关均为1时，仅调试入口、模式3的PLAN0/default加载新速度路线，同时自动启用距离S曲线；无须另外打开旧APP_DISTANCE_SCURVE_ENABLE。其他模式和比赛入口不开放新候选。比赛自主任务调度仍未完成。

启用前先练习只读预览，开关可以继续保持0：

```powershell
D:/python/python.exe -X utf8 工创赛/scripts/p1_route_preview.py --candidate
```

`--candidate`只在电脑上按新规则预览，不修改开关，不连接小车。`--json`可输出参数文件SHA256、每段参考峰值、曲线时长、截止时间和预算。它不核对板上实际固件版本。

例如某段填写 `X(LEFT, 210.0f, 20.0f)` 表示相对当前车头左移210cm、参考速度上限20cm/s。前进使用FORWARD，右移使用RIGHT。转向仍用TURN、相对角度和度/秒，范围不变。

当前根文件示例仍为前进30cm/5cm/s、左移20cm/3cm/s、转向90度/5度每秒。软件完整构建另用隔离副本验证了前进/左移/右移各210cm、各20cm/s的三段表；这不是已验证的实车路线，不自动启用该表。

## 参考速度与电机转速分开

新候选的每段距离为10～210cm，参考速度为1.21cm/s至对应方向上限。数据存入MotionAction新增的reference_mm_s，不再把“填20”先向下取整成一个较低参考速度。

后台按当前几何与距离坐标比例计算 `ceil(参考速度/每RPM对应速度)+2RPM`，额外2RPM用于位置跟随；实际基速上限不超过52RPM，叠加原航向修正后单轮命令不超过54RPM，反馈保护80RPM。参考速度保持输入值，实际发送仍是整数RPM。80RPM保护只用于带明确路线候选标记的后端会话，不扩大普通定时/距离接口的权限。

前进仍沿用此前的距离比例，左右移仍无新增地面补偿。参考速度、编码估计和真实地速分开，不能把名义换算当成速度标定。后续实车按前进、左移、右移分别测量和校准。

## 短段与时间预算

参考曲线沿用40mm/s²、80mm/s³总预算，并扣除2RPM位置跟随的速度变化余量，实际参考A/J更低。第一版仍静止到静止、每段停稳再接下一段，不做连续过弯。

因此10cm短段即使填20cm/s，参考峰值也仅约4cm/s；210cm长段才可达到20cm/s参考峰值。电脑预览同时显示设定上限和本段实际规划峰值，避免把短段低峰值误认为参数没有生效。此处均为软件参考，非实车测得。

每段平移截止按实际S曲线计划计算：

`ceil(计划时长×1000)+2000ms原末端接近窗口+2000ms工程余量`

参考计划必须短于56秒，生成的平移截止不超过60秒；原末端接近2秒、2mm到距、50mm跟随误差、源/位置新鲜度、停车500ms等保护保持。2000ms工程余量不延长末端接近窗口，也不允许卡住后无限补行程。

整组预算为5000ms，加每段平移截止与6000ms准备/停车/间隔余量；旧定时段、转向段继续使用原预算。整组硬截止仍120秒，存储容量仍8段。已验证7个10cm短平移段可通过预算，长路线超预算会拒绝；不是所有8段表都能运行。转向仍按原30秒上限计预算。

`route_plan.h`整表检查成功才发布。`main.c`复核动作形状和预算；真正的曲线准备在临界区外进行，准备/提交核对方向、参考速度、距离、RPM、时限和曲线限值。高速度普通MoveStart/MoveDistanceStart调用仍被拒绝，只能通过明确的候选动作表提交。

转向接受时清除上一段平移的距离、参考速度和动态截止，避免短平移后的90度转向错误继承短时限。

## 电脑端匹配

TM1字段数未变。新候选的PLAN0回显与feedback_limit_rpm=80共同作为档位标记；target_theoretical_milli_cm_s字段在该候选中表示参考速度上限，包含跟随余量的基速RPM不能当成参考速度。它不是实时地速或实时曲线采样。

将来安排实车测试时，配套新主机须显式指定 `--action run-once --mode 3 --plan default --route-trial`。本轮没有执行该操作。普通/未指定启动不能启动该高速档；新主机可显式选择其他低速预设，收到改选回执及新健康窗口后才允许启动低速表。旧主机不支持新候选。

运行中档位、段数、距离形状或命令范围改变时停止；0.6秒无新遥测、设备1秒失去KEEP、令牌、CRC、源失效、VM/故障锁存、看门狗和停止流程保留。后台提前正常停止但distance_reached=0，不能被主机认作距离完成。

本次未增加免烧录参数下发、设备端路线版本/哈希回显、任意故障清除、自动重试、整场地图规划或避障。PLAN0和档位回显仍不能证明板上是哪份路线，恢复实车时须核对构建来源与参数记录。
