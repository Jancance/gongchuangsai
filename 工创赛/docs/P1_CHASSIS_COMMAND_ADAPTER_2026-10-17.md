# 轮速指令/反馈适配与自动三段指令准备（2026-10-17）

用户不希望逐项有线Watch核对，本轮用自动软件检查代替人工算数。现有chassis_kinematics.c/h增加纯适配函数及三种基本指令，main只改为引用共享的0/1/0/1方向表；未新增实车三段状态机，也没有下载/操作硬件。当前g_can_jog_request仍是原四轮正向10秒入口，不能把它当三段自动测试。

## 已实现

- Chassis_EncodeEmm：把逻辑带符号轮RPM映射到地址1～4及真实方向，正向表统一为g_chassis_forward_direction={0,1,0,1}，负向异或1。仅适用FW_Emm/S_Vel_IS Disable，一原始单位=一RPM。max_raw由调用方显式给出，协议允许上限3000不是批准运动速度，当前基本测试固定1。四轮全部有效才提交，任一无效输出四台有合法地址的零速目标，返回0，调用方必须拒绝执行。
- 当前不静默截断/放大不可表示的小数轮速，仅容许1e-4 RPM浮点计算误差；0.6RPM等直接拒绝并全清零。混合运动的细分速度策略尚未实现，不能因此推广为连续轨迹完成。
- Chassis_EmmFeedbackToLogical：把CAN1_ReadSpeed解析出的带符号整数RPM按同一方向表变成逻辑RPM。valid_mask须四台新鲜有效且正好0F；真实年龄由调用方负责，本函数不把旧数据自动视为有效。Emm的35反馈单位已按本地手册第71页核对为RPM，不把输入S_Vel_IS开关用到反馈。反馈与物理正向的对应仍需运行中实测。
- Chassis_BasicTestCommands：纯准备0前进/1左移/2俯视逆时针三种指令，调用实际运动学及编码，四轮绝对值固定1RPM，无供电、使能、等待或CAN调用。CAN顺序始终1左后/2右后/3左前/4右前。预计驱动方向分别前进0/1/0/1、左移0/0/1/1、逆时针1/1/1/1，须接保护后的实车观察确认。
