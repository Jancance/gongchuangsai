## 后续修改顺序（指导用户手动改）

1. 保留当前构建与源码回退点；一次核对35/28实际原点建立方式、当前位置反馈的符号/单位与0.01°设置、回零后的停止/回退位置。先明确有效坐标参考，不能将上电默认0、历史缓存或回零触碰最高点直接当工作坐标0。
2. 增加独立绝对目标接口与明确的方向、位置模式、单位和软件行程检查，不把旧相对接口直接全局改位。核实厂家绝对模式语义、CAN组包/接收准入及完成判定，保留原相对小步调试路径。
3. 将已验示教记录转换为本车参考系中的固定目标：安全顶部/避让高度、源夹取点、车载放料点、伸缩点和旋转点。105000与28000仅作为从已接受顶部参考到各点的候选行程，不直接冒充驱动绝对位置寄存器值或已标定毫米；需要对齐真实驱动零点、方向和回零回退偏移。
4. 动作组改为移动到目标点，再按本次真实到位/状态反馈接下一步。同一目标重复下发不得重复走相对行程；已经在目标处时需正确确认完成，不能继续要求非零位移导致卡住。失败不能只靠重发目标跳过故障或更新成功计数。
5. 主要正常循环按绝对目标返回安全高度，不再把“先升若干脉冲再碰撞回零”作为每次必走动作。首次启动/位置参考失效后重新建立参考；何时判定失效及恢复依实际驱动行为验证，不承诺掉电多圈绝对位置保持。既有预升回零方案作为原基线保留，待新绝对路径通过相关验证后替代，不立即让用户按新坐标运动。
6. 仅验证受迁移影响的坐标/到位/重复目标/停止与参考失效处理，并在一次实际抓放中观察新路径；不重跑未改变的旧单项。完成绝对接口迁移后继续底盘停稳→机械臂事务→物料留台且空爪回顶→运输许可的整车联调目标。

采用本车SPL＋原生FreeRTOS和现有仲裁/保护；参考车HAL、固定延时推进及仅凭ID置完成标志不直接搬入。设备相同目前为用户报告，重量差异外，机械传动、零位、装配方向和实际菜单/坐标仍以本机证据为准；不擅自改地址、导程、转换系数、速度、加减速或保护阈值。整车重量变化留给后续底盘载荷与稳定性验证，不用改电机协议来代替验证。

## 2026-11-03追加：所有电机对齐参考速度的要求

用户明确后续各电机应具备与参考车相同的速度。该目标与绝对位置迁移一起纳入后续手动修改，不以当前位置接口迁移为由额外降速，也不将相同指令配置当已达到相同实物速度。

本轮只读核对当前实际机械臂配置，普通自动运动已经与参考实际报文对应：35升降LIFT_X_SPEED_DECI_RPM=18464（1846.4RPM）；28伸缩EXTENSION_X_SPEED_DECI_RPM=1060（106RPM）；两轴加速/减速均45055RPM/s；旋转DM_CAN2_POSVEL_SPEED_DEG_S=300（300°/s）。35参考上层2800乘30溢出为18464，本车采用显式合法常量，不复制溢出。迁移绝对目标时保留这些速度/加减速和既有停止/互锁，若确需改值要明确说明依据，不静默降速。

底盘也纳入速度对齐目标，但当前团队低速测试配置不是参考自动速度。后续指导按本车轮径/单位/方向/速度缩放，将参考四轮实际指令与平移/旋转速度换算到本车接口，再安排完整装机带载验证。参考XYVmax1600、ZVmax750等为轮速合成前控制量，不能直接写成1600RPM或750RPM；UART/CAN不同本身不决定相同原始字段对应相同车速。保留原故障检测和停车路径，所需运行范围与监测阈值一起按物理单位复核，不绕过原限幅来冒充对齐完成。整车质量变化仍会影响加减速、制动和稳定性，相同配置是否达到参考实物速度需要反馈与现场观察。

夹爪参考只有PWM目标，没有独立可调速度命令；闭合135°/张开180°沿本车已验设置，不把对方PWM数值当速度或角度。参考回零只发启动命令，未读取其驱动回零速度菜单；不能宣称回零速度也已匹配，不凭普通运动1846.4RPM改写本车低速回零60RPM。本轮不扩大到未给出的参考载盘速度。
