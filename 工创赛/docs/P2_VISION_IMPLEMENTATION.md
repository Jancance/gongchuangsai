## 1. 分工与安全边界

- 输入 `p1`：电控公共F407平台、底盘电机/CAN、HWT与X/Y定位、连续运动、雷达和底盘故障处理。
- 输入 `p2`：Orange Pi感知/标定/目标与导航视觉，夹爪、270°三槽盘、机械臂动作组及相关搬运模块与实物抓放联调；与电控共同完成整场。
- P2 只输出观测、毫米位姿、视觉修正量和动作验证，不输出 PWM。
- P1 必须保留独立心跳停车和执行器限位；首版ToF上报`NOT_PRESENT`，P2失效不得导致继续运动。后续装配ToF后再启用其紧急停车门禁。
- P1动作结果与P2当前视觉证据共同成立后，才更新抓取或放置计数。

### R：代码与验收必须遵守

| FIELD-06/07 | 主体不得离开灰色车道；补光只能垂直向下。 |

| RUN-01～04 | 完全自主、一键启动；物料先入载物盘再跨区；落地后不推动；恢复必须留足15秒窗口。 |
| DSP-01/02 | 显示完整任务码、正确抓取数、正确放置数，字符高度不少于12mm。 |
| MECH-01 | 初始整机投影≤300×300mm、高≤400mm。 |

### E：当前采用的工程方案

- 专用扫码模块为主，OpenCV QR为独立备用；不一致时拒绝。
- 向下全局快门相机负责操作区，前视相机负责导航。
- 按2026-09-26用户决定取消PAW3395；HWT101提供航向，运行中X/Y来源在底盘阶段冻结并实测，视觉负责车道/路口/功能区纠偏。轮反馈里程计属于候选，开局雷达扫描不等于实时定位；不使用ICM42688。
- 传统OpenCV是基础路径；YOLO、RKNN、条形码插件均不得成为基础流程单点故障。
- 所有检测使用质量门、多帧跟踪、超时和 `UNKNOWN`，单帧结果不能直接触发机构。
- 回区暂按“整车四角均进入且速度为零”的保守标准实现。

### Q：保持锁定，不能写成正式规则

| 待确认项 | 当前防误用措施 |
|---|---|

| OBS-03 障碍数量、最小间距、禁放区域、碰撞/推动判罚 | 仅配置名义尺寸，数量和间距不硬编码。 |
| FIELD-05 回区判定 | 使用保守四角判定并标记为工程建议。 |
| 条形码码制、尺寸及是否为正式任务 | 只预留插件接口。 |
| CY-SCAN01照明合规性 | 未验证可关闭前，不依赖其照明。 |
| 决赛现场任务和改造时间 | 检测器采用插件式 `Observation` 输出。 |

## 3. 已落地的软件结构

```text
Frame/Scanner
  -> FrameQualityGate
  -> Calibration/Undistort
  -> Detector
  -> MultiObjectTracker
  -> Observation
  -> P2 state/navigation planner
  -> Safety/Evidence gate
  -> versioned UART frame
  -> P1 ACCEPTED/DONE/ERROR
  -> current visual verification
```

| 文件 | 当前职责 |
|---|---|
| `src/smart_carrier/models.py` | 统一观测、RobotState、ActionResult与三态运动模型。 |
| `task_code.py` | 四段语法、合法性、双通道多帧一致与QR-04执行锁。 |
| `quality.py` | 模糊、过曝/欠曝、旧帧拒绝。 |
| `tracking.py` | 轻量多目标跟踪及MOVING/STATIONARY/UNKNOWN。 |
| `navigation.py` | 灰色车道、路口迟滞、拓扑换路、首版纯视觉保守避障、可选ToF融合和回区四角判定。 |
| `verification.py` | P1 DONE与P2当前证据的幂等计数门。 |
| `p2_state_machine.py` | 有限重试、3秒恢复决策和安全停止。 |
| `protocol.py` | CRC16帧及确定性JSON负载。 |
| `replay.py` | JSONL离线回放摘要。 |
| `p2_selftest.py` | 不接触硬件的配置与环境自检。 |

当前这些模块是“接口和安全骨架”，不是实物视觉验收完成证明。物料、圆环、码垛、相机采集和扫码器驱动需在实物接入后按下列顺序实现。

## 4. 坐标系和P1/P2协议

### 坐标系

- `pixel_xy`：图像坐标，原点左上，x向右、y向下，单位px。
- `camera_ground`：对应工作平面，原点为标定板定义点，单位mm。
- `robot`：车体中心投影为原点，x向前、y向左、yaw逆时针为正。
- `field`：场地固定坐标，原点和朝向须由双方在场地图上签字冻结。
- `gripper`：夹爪工具中心点。主相机必须完成 `pixel -> ground -> robot -> gripper` 链。
- 任何坐标都带 `calibration_id`；相机、镜头、分辨率、裁剪、焦距或安装位变化即作废。

### P2统一观测

每个观测至少包含：

```text
timestamp_ns, frame_id, source_id, calibration_id, track_id,
confidence, age_ms, pixel_xy, ground_xy_mm, robot_xy_mm,
pose, uncertainty, visible_fraction, rejection_reason
```

标准类型为 `TaskCodeObservation`、`MaterialObservation`、`MaterialMotionState`、`RingObservation`、`StackObservation`、`LaneObservation`、`IntersectionObservation`、`ObstacleObservation`、`HomeZoneObservation`、`PlacementVerification`、`VisionHealth`。尚未实现的具体检测器必须先输出带拒绝原因的 `UNKNOWN`，不得伪造空成功。

### P1输入与动作结果

```text
RobotState:
  timestamp_ns, pose, speed_mm_s, angular_speed_rad_s
  yaw_rad, yaw_rate_rad_s
  pose_valid, pose_age_ms, localization_source, localization_calibration_id
  paw_squal, paw_shutter, paw_lifted, hwt_status
  tof_present, tof_status, tof_left_mm, tof_center_mm, tof_right_mm
  tray_occupied[3], gripper_state, motor_faults, heartbeat_age_ms

ActionResult:
  seq, ACCEPTED|DONE|ERROR, final_pose, error_code
```

串口外层固定为帧头、协议版本、长度、序号、命令、载荷和CRC16。重复序号不得重复物理动作。200ms无心跳减速、500ms无心跳停车由P1独立实现。

## 6. 实施顺序与门禁

1. **V0 数据与标定**：双相机枚举、锁参、录制；内参与独立验证；主相机平面/手眼链；前视鸟瞰。门禁：RMS≤0.5px、95分位≤1px，并单独报告毫米误差。
2. **V1 任务码**：CDC驱动、OpenCV QR备用、四段解析、多帧共识、超时和拒绝日志。门禁：合法100/100，非法/冲突全部拒绝；QR-04未确认时仍不可执行。
3. **V2 六色物料**：LAB/HSV、参考色漂移、轮廓/中心/姿态/抓取点；建立蓝/浅蓝、黑色、反光、阴影、遮挡集。门禁：独立集≥99.5%，报告混淆矩阵和拒绝率。
4. **V3 跟踪与运动**：补偿相机运动，稳定track ID，三态运动判断。门禁：100段序列不误换ID；不确定必须UNKNOWN。
5. **V4 数字与圆环**：ROI透视矫正，模板/笔画约束，圆弧RANSAC、椭圆与亚像素边缘，建立位置映射。门禁：50次真实落环优先1环，留存每次证据。
6. **V5 码垛**：第一层顶面/倾斜、第二层落点、放后层数/偏心/倒塌验证。门禁：连续30次不倒，失败可回放。
7. **V6 导航**：接入P1经验证的实时X/Y、HWT101航向及健康状态；灰色通行区、边界/中心/航向，近中远分支和路口迟滞；在路口/功能区生成带不确定度的视觉位置修正。门禁：两个起点均能稳定离区并识别路口，定位失效时不盲转；不恢复已取消的PAW。
8. **V7 避障**：仅车道ROI内检测黑色圆柱，结合尺寸/底边/区域语义区分黑色物料；动态包络膨胀；左/右/停/全局换路。门禁：随机100次零碰撞、零越界。
9. **V8 回区和恢复**：拓扑返程、入口局部定位、四角入区；断相机/旧帧/低置信/心跳失联故障注入。门禁：3秒内决定恢复/降级/停止，两个起点各≥10次回原区。

## 10. 历史采购结论（旧版本快照）

以下保留原方案来源，不作为当前采购指令；2026-09-26已取消PAW3395及三路占用检测旧用途。当前器件和定位缺口以最新总计划及LOC-01～07为准，本次整合不恢复旧采购。

立即采购/核验：PAW3395光学位移模块及匹配镜头、HWT101、2.4mm浮动安装样件和实际场地材料样片、短USB线和固定件、刚性ChArUco板、毫米网格/钢尺、垂直漫射补光、主相机遮光罩/可拆偏振片、照度记录工具、三个载物盘占用传感器及六色/灰/黑材料样片。

条件采购：前视相机无法锁参或滚快门不可用才更换；首版纯视觉避障在近距盲区、黑色圆柱或故障注入测试中无法满足零碰撞/零越界时，再采购3个VL53L1X加1个备件并启用预留接口；ToF仍对黑色目标漏检时再评估低位超声；双摄掉线/压降才加由唯一车载电源供电的工业有源Hub。

不采购：ICM42688。暂不采购：OPS-9、临时双目、高价雷达、基础流程专用YOLO/RKNN服务、无aarch64 UVC/锁曝光/稳定身份的相机。PAW3395＋HWT101未通过专项门禁前，不能把“替代OPS-9”标记为完成。
