## 已交付

`src/smart_carrier/source_markers.py`：至少4个拟合点与3个独立验证点；支持实际透视单应性，验证点不参与拟合。输出拟合/验证各自RMS、P95和最大毫米误差。重复、共线、非有限、超图像范围及验证点不在拟合覆盖区内时拒绝；按输入的工程门限判断独立验证结果。

`scripts/pick_source_markers.py`：从保存的原尺寸图片按编号点选像素。可缩放窗口，点选坐标保持原图尺寸；U撤销、S全部选完后保存、Q取消。不打开相机或串口。当前只有源码检查，没有Orange Pi/VNC窗口实测。

`scripts/source_marker_calibration.py`：fit生成离线映射报告；preview映射同平面三位置/真实盘心标记，并可预览纯平移纠偏量。未通过独立验证、标定版本/分辨率/姿态/平面不符、目标超覆盖区域、纠偏超配置上限时拒绝。输入错误生成明确失败报告，避免沿用同路径的旧通过结果；输入原件不覆盖。

所有输出固定motion_allowed=false。独立验证通过只表示这些实测检查点的局部平面映射通过，不会设置生产profile的geometry_verified，不写固件或生成动作事务。

## 现场第一步：采集盘面标记

沿用已到位的第2段停车/机构姿态，不重跑第1段。标记采集期间原料盘和车体静止，旋转、伸缩、升降不变。

1. 在可见盘面贴6个小十字P1～P6，分散覆盖实际要观察的区域，至少四点不共线。不要只贴一小簇。
2. 在这些点包围的内部另外贴V1～V3，三点不共线；这三点仅做独立验证，不参与求H。若空间不足，最低允许4个拟合点加3个验证点，须同时修改模板的点列表。
3. 保存该姿态的一张**原尺寸图片**，不能用VNC窗口截图或缩放图代替。记录实际相机/镜头、图像尺寸、安装版本、机构保持姿态、盘面离地高度。姿态ID应能对应现场日志或姿态记录，不把命令角度当实测反馈。
4. 定义一个可重复测量的车体固定点作原点，写清其位置。X向车体右、Y向车体前，均mm，坐标指标记点的水平位置；用水平投影/直角尺量，不能把倾斜直线距离当水平坐标。分别记录9个十字中心的X/Y。也可先测盘面标记的局部坐标，但必须另测该坐标系相对车体的平移和方向后再换成车体坐标。
5. 复制`calibration/source_markers_template_20261105.json`为本次实测文件，填写上下文、实测毫米和工程误差门限。模板空值有意保留，不带虚构尺寸或已通过标志。门限根据尺量精度和实际抓取余量定，不能在看到结果后反复放宽以求通过。

在工程根目录运行（输入名为示例，需使用本次真实文件）：

```powershell
python scripts/pick_source_markers.py source_original.png calibration/source_markers_template_20261105.json --output calibration/source_markers_measured.json
python scripts/source_marker_calibration.py fit calibration/source_markers_measured.json --output calibration/source_markers_result.json
```

点选工具只填写image_px，其他实测项须补全后再fit。raw模式允许先检查原始图的局部经验映射，但不代表CAL-03畸变验证通过；undistorted模式必须提供实际镜头标定版本，并使用该版本真实处理过的图像，不能只改字段。

## 三位置与纠偏的连接边界

A模式目前输出拟合的图像圆心，透视投影不保证其等于真实物理圆心的投影。不能直接把A中心送入H就作为底盘目标。首轮纠偏使用测定的真实盘心标记；后续自动A需将真实外圆边缘映射到盘面后重新拟合物理圆，或使用经验证的相机/平面几何。本轮没有完成该自动A桥接。

盘面H只适用于盘面点。M通常检测物料顶面中心，其特征平面高度不同；先取得对应高度的映射或已验证三维模型，不能套盘面H。名义三角形可用于几何检查，不足以确认当前相位/颜色或把未知目标当成抓取点。相机或机构姿态变化后必须重新匹配标定/验证，底盘纠偏后重新观测，不继续使用先前目标像素。

preview输入包含与标定完全相同的context、calibration_id，以及targets列表（id、kind、image_px）。kind仅接受physical_marker或feature_on_calibrated_plane；A的fitted_circle_center被拒绝。可增加alignment：center_marker_id指向真实盘心标记、desired_center_chassis_mm填写经实际可达/净距验证的目标盘心、max_translation_mm填写本次平移上限。

```powershell
python scripts/source_marker_calibration.py preview calibration/source_observation.json --calibration calibration/source_markers_result.json --output calibration/source_preview.json
```

纯平移时，建议车体位移=当前盘心车体坐标−期望盘心车体坐标，前提是场地目标静止且航向保持。圆本身不能提供车体偏航角，所以不生成旋转纠偏。该输出只供离线检查，不包含轮指令/安全轨迹，不能直接送到旧像素串口或位置执行器。

随后还需实际量取4310旋转中心、旋转零向、夹爪TCP相对伸缩参考点的关系、有效行程与升降抓取平面，验证三个位置可达及避让。当前70mm来自已成功准备动作，不是任意三位置均可达的证明。不能直接按100mm轨道半径计算伸缩命令。完成这些测量后再做同批并行机构与失败出口模型，才接纠偏/抓放执行；单件入载台确认与三件完成后的第3段门禁保持。
