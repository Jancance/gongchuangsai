## 目前真正具备的范围

- 同一主程序、原生FreeRTOS、唯一CAN任务管理CAN1四轮Emm及35/28的X协议、CAN2的4310；任务A提交事务，底层发送不跨任务抢FIFO。夹爪PA0/TIM2、载盘PB1/TIM3与雷达PWM的TIM4分开。
- 按键前不向4310/伸缩发送运动或使能命令；夹爪上电140°。转盘上电角默认-1，表示未填写、不输出默认0°位置PWM。
- 按键后先完成4310与伸缩各自的读取/参数检查和准备屏障，再在同一服务轮并行释放；跨CAN1/CAN2不是硬件时间同步。4310从约180°沿逆时针正向到同圈360°（显示0°），速度150°/s，即既有300°/s的一半。近零点不额外绕一圈，非预期初始姿态、超驱动量程拒绝。新半圈扫掠方向不能套用旧另一半圈通过结论。
- 两轴分别到位后才允许底盘；4310保持到位位置，正常底盘停车不切掉机构需要的共享VM。驱动、总线、任务或取消异常仍撤销供电。到原料区后的DM180°由第2/5段动作表执行。
- 伸缩/升降对上层使用固定目标，并用本次反馈计算剩余差值。当前X底层仍为模式2的相对报文；不是已迁移驱动绝对协议，也不是掉电机械绝对位置恢复。同一目标已经到位时不再强制走非零位移。
- 第1～8段共享状态机，距离和速度逐行配置；每段机械臂动作逐行配置，支持独立重复三件的槽位选择。正常完成可按键重新开始，失败/取消不自动清锁存。

尚未具备：现场可靠实时X/Y、真实障碍地图与动态避障、视觉到机械坐标、真实任务/颜色/实例/三槽库存适配、可量化落点/净距、三分钟表现。不得因上述软件结构存在就签这些项目通过。

## 怎么改距离、速度和每个动作

第1段底盘原行：

```c
{VF(15.0f,5.0f),VL(105.0f,10.0f),VSTOP},
```

仅举语法例：`VF(18.0f,6.0f)`表示前进18cm、参考速度6cm/s；不是要求本车现在改成这个值。第2～8段在同一数组各自的中文注释下面改，不会要求重新到另一个文件找参数。当前普通曲线距离范围1～210cm、速度1.21～20cm/s；命令量程、轮速及规划可行性仍检查，实际速度需反馈验证。

动作表示例：

```c
VA_Z(105000.0f,1846.4f)  /* 升降固定目标，虚拟脉冲；速度RPM */
VA_DM(180.0f,300.0f)     /* 旋转目标deg；速度deg/s */
VA_EXT(10.0f,106.0f)    /* 伸缩目标mm粗标；速度RPM */
VA_GRIP(135.0f,500U)    /* 夹爪角度；命令后等待ms */
VA_SLOT(1500U)          /* 本件槽位；等待ms */
```

一行的目标和速度可单独改；全局角度/高度宏是共用值，RPM上限宏属于保护参数；实际动作速度看该行第二参数。若只想改某一段，就把那一段相应行的宏换成该段数值。35/28/4310可改速度；夹爪和载盘PWM没有独立速度命令，只能改角度及等待，等待不是实际速度或到位反馈。

## 真实反馈和三分钟演练

vehicle_arm_rows中的7/8/9是原料→载台、工位放稳、工位→载台的观察出口。VehicleMission_Observe接口匹配run/stage/item/row/kind；当前没有把视觉/真实库存串口适配器接上，不能靠Watch设成功。默认需要该观察，缺失不推进下一件/下一段，正确次数保持0，不把动作次数当正确次数。当前接口仍不是正式任务事务、观测新鲜度和重启幂等协议验收。

真实扫码恢复时设VEHICLE_SCAN_BYPASS=0，只锁存本轮合法四段码并在有序停车后发送page0任务码；发送成功不等于屏幕确实显示。提前停车改变起点时，当前连续模式会拒绝沿用名义第2段路线，需补真实位姿重规划；单段模式可先验扫码及屏幕。用户原先“扫码器有读码表现”不补写成主控已接受本轮合法四段帧。

八段的路线/机构/反馈分别现场通过并补齐未知参数后，再将VEHICLE_RUN_ALL=1、VEHICLE_REHEARSAL=1，运行按键起180000ms总截止。初期无物料演练可在明确无物料的范围选择相应观察旁路，不登记正确次数；带物料正式自动不能以旁路替代真实确认。默认低速和停留值不保证三分钟跑完，需实测优化。
