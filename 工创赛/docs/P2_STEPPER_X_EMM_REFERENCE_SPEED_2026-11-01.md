# 35/28：X与Emm差异、参考速度及73mm下降输入（E，2026-11-01）

## 用户范围与结论

用户先给场地下降量7.3cm，再要求35/28速度参考此前DM所在整车代码，随后问X与Emm是否精度更高、若是则改X。查同版厂家手册后，未能证明本机切X会得到更高实际精度；本次不触发条件式切换，保留两台已验Emm。此前已授权的参考速度按正确单位换算安装，不更换电机硬件/固件或写驱动菜单。73mm只记录几何需求，不擅自换成下降脉冲。

## 本质区别：两套固件/算法，不只是换报文

厂家《ZDT_X42S第二代闭环步进电机用户手册V1.0.5_260527》第8页对比：Emm普通为电压模式力矩环与位置闭环，EmmTurbo为力矩位置双闭环；X为力矩/速度/位置完整FOC三环，支持力矩/力位混合及标准梯形加减速，厂家推荐机械臂/复杂运动。X也有刚性一般、大转盘结构可能晃动的描述，不能用“三环”直接推出本机定位更准。本机Turbo和细分未实际读回，不把普通/默认表当本机实测参数。

| 项目 | Emm | X |
|---|---|---|
| 命令位置 | 脉冲数，取决于步距角/细分 | 角度单位默认0.1度，S_PosTDP可选0.01度输入 |
| 加减速 | 0～255档，公式非线性 | 独立加/减速，直接RPM/s |
| 速度 | 默认整数RPM，S_Vel_IS可选0.1RPM输入 | 0.1RPM |
| 实时位置反馈 | 65536计数/圈≈0.005493度/计数 | 默认0.1度/计数；位置误差帧单位0.01度 |
| 物理精度 | 由闭环/编码器校准/负载/机械共同决定 | 同样需要本机实测，不能按命令小数位承诺 |

1.8度电机若16细分，Emm指令0.1125度/脉冲；64细分为0.028125度，256细分0.00703125度。X开0.01度命令比16细分的Emm更细，但比256细分Emm更粗。这里都是输入分辨率，不是可保证的机械落点精度。MPlyer内部插补描述针对脉冲控制，不能不分模式把它当CAN绝对精度提升。切固件不会增加编码器硬件位数。

X的独立梯形和完整速度环可能改善某些负载下的运动表现，当前没有同工况对照数据；不能拿DM由MIT改位置速度后体验去证明张大头Emm→X必更准。当前定位优先补本机MStep/实际毫米映射/机械回差/重复到位数据。如果将来为控制特性对比切X，需要按实际板卡代际/固件支持性及单位一起迁移，不能只改FWType后沿用旧Emm脉冲。

厂家手册第77页选项bit0步距类型、bit1固件、bit7缩放；第78页FWType切换命令支持性按具体型号代际核实。当前源只使用已识别的节点5/6 Emm，不发D5切固件、不改细分/S_PosTDP/S_Vel_IS，不触发重新校准或清零。

## 参考速度逐字节核对及实际安装

参考tower.c的Motor_AbsPosition是16字节X梯形格式，速度字段以0.1RPM计、加减速度字段为RPM/s；不能按误写的“RPM/步数”注释理解。

- 35正常任务实参2800，经speed*30传入uint16：84000截断为18464，报文对应1846.4RPM。源码存在溢出，不在本项目复现溢出运算，而明确用等效整数1846RPM（Emm默认整数速度）。不是把2800直接当本车RPM，也不是发84000RPM。
- 28正常任务实参2000，经*0.53为1060，X报文对应106RPM。参考遥控模式1500对应79.5RPM，不是本轮采用的普通自动任务速度。
- 参考加速/减速固定0xAFFF=45055RPM/s；Emm acc255对应20000RPM/s，为可选非0曲线档位中最近值，无法精确相同；acc0为直接启动，不当“更高一档”使用。

## 73mm下降需求与下一项

用户对下降到可夹高度的明确回答7.3cm，登记为约73mm，和参考场地table_h730（盘面73mm高）是两个不同物理量，不能因数值相同混为一谈。现有35粗估曾约1666.7脉冲/mm，来源是单次约数；参考X角度换算44.94和本车Emm脉冲也不能直接互换。当前尚未冻结本机细分/导程，73mm不直接填73脉冲、不套车载32000，也不擅自扩大50000下降上限。
