# 平台验收清单

本文件只覆盖平台层验收。整机比赛验收还必须逐项执行 [2027竞赛规则与设计约束基线](competition_requirements_2027.md) 第10节，不能用平台压力测试代替规则验收。

## 自动项目

先用断开的电机使能完成：

```bash
CAMERA_HOURS=8 STRESS_DURATION=6h UART_FRAMES=100000 \
  bash scripts/orangepi/platform_acceptance.sh
```

通过标准：双相机无永久掉线和停帧、UART 100000帧无丢失/CRC错误、温度低于75°C、磁盘剩余超过15%、服务配置无占位符。

## 人工项目

- [ ] 冷启动20次，全部在60秒内进入 READY。
- [ ] 主/前视相机分别拔出，车先停、服务记录原因，重插后只能恢复感知，不能重放运动。
- [ ] 断开 STM32，200ms减速、500ms停车。
- [ ] 杀死主进程，STM32独立停车；systemd重启后仍保持禁止运动。
- [ ] 注入坏 CRC、半帧、粘包和重复序号，STM32不重复动作。
- [ ] 填满磁盘到剩余约15%，健康服务报警且不继续保存诊断图。
- [ ] 遮挡前视相机、使用旧标定ID、制造过期帧，均进入 SAFE_STOP。
- [ ] 模拟无局部通道，返回 GLOBAL_REPLAN，不越界强行通过。
- [ ] 安全关机后制作可恢复镜像，并在备用TF卡实际恢复一次。

所有证据放入带日期的 `diagnostics/` 目录，包括原始日志，而不只保存“通过”截图。

## 整机导航追加门禁

以下项目当前尚未由现有代码完整实现，后续必须按 [导航与回区专项设计](NAVIGATION_AND_RETURN_LOGIC.md) 完成后再勾选：

- [ ] 灰色车道直道、弯道和光照变化巡线，整车动态包络不越界。
- [ ] 十字路口左转、直行、右转均连续稳定识别，同一路口不重复计数。
- [ ] `start_id=1/2` 共用状态机，分别从抽签区出发并返回同一区。
- [ ] 黑色障碍位于中心、边缘、路口、入口及狭窄组合时零碰撞、零越界。
- [ ] 无安全局部通道时实际完成拓扑换路；无替代路线时安全停车。
- [ ] 回区时整车四角投影均在300×300mm内且STM32速度为零。
- [ ] 相机、车道、路口、定位或通信失效均在15秒前恢复、降级或安全结束；首版ToF状态保持`NOT_PRESENT`，后续装配后再增加ToF失效注入。
- [ ] `FIELD-05`、`OBS-03`相关技术答疑已复核；未确认时按保守标准测试并明确标注。

## PAW3395＋HWT101定位追加门禁

以下均为工程验收，实测前不得把“替代OPS-9”标记为完成；项目不使用ICM42688。

- [ ] PAW3395匹配镜头、板载稳压和逻辑电平已核对，镜头参考面至实际地面在2.2～2.6mm范围，浮动结构不碰地、不遮光且初始尺寸合规。
- [ ] HWT101具体型号、供电、UART协议、输出率、启动零点和复位行为已记录；Z轴方向与车体yaw正方向一致。
- [ ] 前/后/左/右各1000mm、每方向10次，分别报告均值、95分位和最大误差，最大终点误差工程目标不超过8mm。
- [ ] 原地正反360度各10次，完成PAW旋转中心偏置补偿；虚假平移目标不超过5mm，航向闭合误差单独记录。
- [ ] 2.4m级典型路线连续20次，场地级到站误差95分位目标不超过15mm；最终抓取/放置由局部视觉误差另行验收。
- [ ] 灰色车道、功能区、接缝、阴影、强弱光、反光、灰尘及不同速度均有原始PAW质量数据和误差报告。
- [ ] `Lift_Stat`、低SQUAL、异常Shutter、PAW/HWT数据过期、HWT超时和STM32复位均能阻止错误积分并进入安全恢复。
- [ ] `start_id=1/2`分别完成视觉初始定位、路口/功能区纠偏和回原区；错误或过期视觉修正不会造成位姿跳变。
- [ ] 定位故障3秒内决定恢复/降级/停车，并在15秒规则窗口前完成；全过程保存P1原始数据、融合位姿、P2修正和俯视真值视频。

详细实施顺序见 [PAW3395＋HWT101底盘定位专项计划](LOCALIZATION_PAW3395_HWT101_PLAN.md)。

## 视觉系统追加门禁

按 [视觉系统专项](VISION_SYSTEM_REQUIREMENTS.md) 验收，禁止用单张成功截图替代数据集和整机结果：

- [ ] 数字模板对完整、旋转、透视、模糊、残缺和相似负样本均有混淆矩阵及歧义拒绝。
- [ ] 二维码连续帧一致且四段合法；条形码后端、码制和校验可追溯。
- [ ] 六色物料实例输出ID、姿态、抓取点和毫米误差，蓝/浅蓝及黑物料/障碍不混淆。
- [ ] 圆环完整/残缺识别报告拟合残差、可见比例并稳定跟踪，1环局部精定位达标。
- [ ] 物料track无异常跳号，能在自运动补偿后区分移动、静止和未知。
- [ ] 码垛能识别层数、顶层、偏心、倾斜/倒塌，并在放置后重新验证。
- [ ] 太阳直射、阴影、反光ABS/PLA、过曝和欠曝均有质量门禁和安全降级。
- [ ] 相机独立验证重投影、去畸变残差、静态像素重复性、地面毫米误差和整机落点误差分别记录。
- [ ] 相机/镜头/焦距/分辨率/裁剪/安装变化会使旧标定失效，系统能拒绝错版本。
