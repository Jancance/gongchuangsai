## 1. 工作归属

| 主责 | 工作及交付 |
|---|---|
| 电控组：公共平台 | F407标准库、FreeRTOS、时钟/任务/中断、公共通信驱动、统一时间、状态与故障监督 |
| 电控组：底盘与定位（核心） | 四轮通信/反馈、运动学、速度闭环、HWT航向、实时X/Y方案、视觉纠偏接入和有效性 |
| 电控组：连续运动 | 位置/朝向联合到位、连续过点、加减速与加加速度约束、轮速限幅、车道扫掠及停靠 |
| 电控组：雷达 | 180°升降、ULN2003转向、标定/扫描、雷达协议、开局地图与自动联动 |
| 视觉组：感知 | 六色/任务码、物料/圆环/码垛、移动预测、坐标与高度标定、当前视觉证据 |
| 视觉组：搬运机构 | 夹爪、270°三槽盘、机械臂动作组及相关搬运轴；对应驱动适配、回零/软行程、工具/槽位标定、取放Z、臂盘互锁、库存及实物抓放 |
| 两组共同 | 到工位/停稳握手、抓放后运输条件、坐标/时间/版本一致、双批次与双起点整车验收 |

视觉组负责到机构动作和实物抓放；相关模块在STM32执行时，也归视觉组搬运工作包开发和联调。电控组提供公共F407平台、总线服务、底盘状态及整车故障接口。分工调整本身不改变PCB、引脚或执行器供电，不把舵机线路改接香橙派。

## 3. 交接接口

- 电控提供带时间戳和有效性的底盘位姿/航向/速度、到工位及实测停稳状态、故障和动作允许状态。
- 视觉/搬运模块提供目标工位/朝向、机构运输姿态/扫掠占用、物料稳定入载台证据、运输允许状态、抓放完成或故障。上位机继续发送结构化目标/动作请求，F407执行模块进行驱动和互锁。
- 双方统一run_id、动作序号、坐标/单位、时间关系、原料盘高度/几何版本及标定版本；ACCEPTED与DONE分开，重复请求不重复执行。
- 公共F407资源统一管理：搬运轴与底盘共享CAN1时由公共服务发送/分发；PB9夹爪与PB6雷达升降共用TIM4周期；PB1三槽盘与PB0蜂鸣相关TIM3资源须协调。模块不得各自重配公共定时器，PWM周期/电平按实物确认。
- 车载盘分度前底盘停稳、机械臂退出扫掠区；分度到位停稳后才允许手臂进入。跨区运输前确认物料入载台并处于运输姿态。源料盘运动预测抓取与车载盘静止分度分开处理。
