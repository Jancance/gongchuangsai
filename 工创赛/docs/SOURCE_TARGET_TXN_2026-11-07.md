## 接口（视觉侧 -> 固件）
视觉侧写下面这组字段，然后 `g_src_txn_revision+1` 提交一次事务；固件经 **IT 请求11** 消费一次：

| 字段 | 含义 | 校验 |
|---|---|---|
| `g_src_pick_deg` | 机械臂取件角 | 0~270 |
| `g_src_chassis_dx_mm` / `dy_mm` | 底盘毫米纠偏 | ±20mm |
| `g_src_slot` | 目标载盘槽 | 1~3 |
| `g_src_txn_seq` | 事务序号 | 与上次成功序号相同即判重复 |
| `g_src_txn_tick` | 提交时刻(ms，读 `g_src_now_ms`) | 龄期 >3000ms 判过期 |
| `g_src_txn_revision` | 提交计数 | 与 `consumed` 相同即"无新事务" |

结果码 `g_src_txn_result`：0 未提交 1 接受 2 无新事务 3 过期 4 越界 5 序号重复；
被拒时同时置 `g_it_rejected=1`，**不置 it_cause、不进故障态**，视觉侧可重发。
