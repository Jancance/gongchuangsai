## 两个雷达的节点ID与共线条件

雷达调用手册1.35（协议6）允许1～254节点ID；上位机手册要求尚未编号时逐台连接配置，不能把两个默认ID1同时在线改号。先单接第一台保留ID1，再单接第二台保存为ID2，分别确认握手和保存，再讨论共线。

节点ID与启停区zone是两个字段。本工程建议映射区1→舵机/升降/节点1、区2→舵机/升降/节点2；这只是上层映射，仍要向选中的雷达发送SELECT_ZONE并验证回复，不用节点ID代替选区。

本地F407例程README说明雷达下位机PA9/TX为开漏，接收线上只放一个4.7k上拉到3.3V。在两台实物都确认属于这一开漏串口版本、未选节点不持续输出的条件下，可采用：

```text
主控 PD8 / USART3_TX ─┬─ 雷达1 RX
                     └─ 雷达2 RX
雷达1 TX（确认开漏）─┬─ 主控 PD9 / USART3_RX
雷达2 TX（确认开漏）─┘      │
                           4.7kΩ（总线上一处）
                            │
                           3.3V
各模块GND共地；雷达供电按其额定5V接整车相应电源支路。
```

PDF确认了节点寻址，但未给出两台TX并接的电气原理图；开漏信息来自配套例程README。若实物TX为推挽或接线版本不匹配，不直接并联，应增加双路TX/RX切换或收发缓冲；软件设ID不能消除推挽冲突。此前提出的74HC4052是可选替代方案，不是本轮强制硬件。

启动时先停止残留事务，关闭未选节点的连续扫描与点云，只对选中ID握手、选区和发扫描命令；仅处理当前节点与当前事务结果。供电恢复/换节点后清除旧结果并重新握手。没有做实物并线或总线冲突验证。

## 本次代码与调用

实际入口仍为根工程 `3.stm32f407工程/gongxun-f407.uvprojx`。新增HARDWARE/RADAR_SERVO，使用STM32标准库，不引入HAL。

- `RadarServo_Init()`：统一配置TIM4，PB6/CH1和PB7/CH2都输出0°命令，50Hz。按APB1实际时钟计算1µs计数，错误时钟拒绝初始化。
- `RadarServo_SetAngle(id, angle_deg)`：id=1或2，角度0～180°；非法ID、超范围及NaN拒绝，不影响另一通道。返回1仅说明命令写入，不证明机构到位。
- 重复调用Init不会把已命令角度强制复位。两路更新使用CCR预装载，不重置整个定时器。
- `RadarZoneSwitch_Service(now_ms)`：PA1防抖50ms，未稳定时zone=0。
- `RadarZoneSwitch_Lock()`：稳定后锁定1或2；锁定期间拨开关不会改变本次锁定值。任务间锁定/解锁使用临界区；本轮结束、机构停稳后才允许上层解锁。
- main只初始化两路收拢0°，按键任务只采样PA1；拨开关不会驱动舵机。尚未绑定出发事件或设定两套展开角度。
- 强制离线版本不配置舵机GPIO/TIM、不产生PWM，`g_radar_servo_state=2`。

观察变量：`g_radar_servo_state`（1=PWM就绪/2=离线/3=时钟不适用），`g_radar_servo_angle_deg[2]`、`g_radar_servo_pulse_us[2]`；`g_radar_zone_ready/selected/locked`。

首次空转另加`g_radar_servo_test_id/angle_deg/request/result/sequence`调试邮箱：先写id、angle，最后request=1，每请求只处理一次，只允许0～15°且VM关闭、底盘不活动、无安全/RTOS/CAN故障；离线拒绝。result1仅说明PWM写入，2未就绪、3参数拒绝，sequence处理后递增。不得改写只读结果来制造成功，不把此小角度入口直接用于展开扫描。电脑端probe_servo.py绑定精确镜像和预期序号，不自动重复动作。

配置脉宽暂按500µs→0°、2500µs→180°，在radar_servo_config.h集中设置。用户只确认180°PWM舵机，型号/脉宽和安装零位未确认，因此这些是待实物验证的标称参数；首次下载前先确认0°收拢位、避开机械硬限位。没有宣称0°物理位置已经标定，也没有下载本次程序。

完整有效扫描得到0个障碍，可报告“本轮未检出障碍”；超时、断线、缺结果或overflow应报告“扫描失败/环境未知”，不能当空场。手册的8秒操作超时是候选，不是保证能扫完的实测时间。

后续USART1无线可回传节点、启停区、扫描序号、障碍数量、坐标mm、方格及置信度，电脑显示列表或地图。与现有控制报文做完整帧发送仲裁，不能混写串口破坏运动心跳。本轮尚未加入雷达串口驱动、自动展开升降、扫描事务或电脑显示程序。
