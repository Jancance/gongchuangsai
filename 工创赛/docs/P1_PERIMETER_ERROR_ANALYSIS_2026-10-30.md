# 外围两圈误差机制审阅（2026-10-30）

当前平移执行是距离闭环和HWT航向保持；XY只作观察和检查点记录，没有根据地图XY纠正横向位置。main.c提交平移成功时将s_hold_target设置为当前s_heading_source.yaw_deg，即每段保持本段开头的实测朝向，不是整组固定地图方向。若前段或转向留了角度残差，下一段会接受它作为新目标。转向也是相对当前朝向的±90度，不消除此前地图航向残差。

第一圈点1/2/4/5/7/8地图航向分别-90.472/-90.988/88.890/88.406/-91.900/-91.301度；第二圈为-90.433/-90.889/89.263/88.862/-92.169/-91.631。第三条平移（段5）在第一圈估计增量(+50,+1800)mm、第二圈(+39,+1800)mm；末条侧移（段8）为(+1799,-61)/(+1799,-71)mm。可见后半圈横向估计增量明显，与该段继承的地图航向偏差几何上相符。1度偏角沿180cm可产生约31.4mm横向分量。XY估计本来使用同一yaw，因此这只是代码行为与数据一致，不能单独证明真实分段漂移；HWT漂移、起点对齐与滑移仍不能排除。两圈外部终点尺量分别(+27.5,-45)、(+24,-57.5)mm，仅支持总体偏前/左。

heading_controller.c的保持控制为0.8*角度误差-0.25*角速度，静止小角/角速死区0.3，±2RPM限幅，80ms角速度滤波、10RPM/s限斜率；整数RPM迟滞为超过0.65才进一档。稳态零角速、零命令附近约0.8125度才能使0.8*误差达到0.65RPM，因此0.3度死区之外也可能没有实际非零轮速纠偏；该0.8125只是该状态下的量级，不是完整动态等效死区。1RPM轮周速度约4.03mm/s。没有据此直接改阈值或扩大控制量，以免引入顿挫/摆动。

CB1记录四轮依次发送，相邻22ms，首末66ms、整组67ms，例子已保存JSON；这是观测到的顺序发送，不是测得所有电机机械响应同延迟。可能造成换速时各轮短时不一致及航向纠偏滞后，但本次没有隔离对照证明贡献比例。max_queue559ms是组内记录的最大值，包含准备/历史上下文，不能说每个运行命令都延迟559ms。不得仅据CAN1_SINGLE_TX_WAIT_MS20把它当帧间隔常量，也不应直接删CAN等待。

位置报文每圈65536计数、77mm轮径，对应软件换算最小单位约0.00369mm；这不等于机械编码器真实精度、分辨率或地面定位精度，驱动可能细分/换算。单计数量化远小于厘米误差，不支持优先归咎其位数。轮滑移、轮径/滚子差异、非同时采样、安装与地面响应仍存在。航向由HWT反馈，不能把偏航全部归为编码器角度。
