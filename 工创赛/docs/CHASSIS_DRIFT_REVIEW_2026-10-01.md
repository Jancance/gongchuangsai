## 2. 视频能说明什么

视频展示小车接近作业圆环区域时改变车身朝向，可作为平移与转向衔接的效果参考。拍摄有跟随/转动取景，不能把屏幕中的像素移动直接换算成场地速度。逐帧时间段见两份观察报告；画面没有提供位姿、轮速、控制方式或同步日志。

| 视频时间 | 可见动作 | 结论边界 |
|---|---|---|
| 0.000～1.667秒 | 从远侧沿灰色区域接近近侧圆环，托盘侧大体朝镜头 | 以平移为主，不能从跟拍画面测速度 |
| 1.667～2.000秒 | 相对地面位置继续变化，车身朝向明显改变 | 支持平移中变向的效果观察；不排除抽样间隔内短暂停顿 |
| 2.333～3.667秒 | 从近侧圆环附近向场地左上侧转移，托盘侧总体维持近似朝向 | 可借鉴侧向/斜向移动；小幅朝向变化与相机变化混合 |
| 4.000～4.300秒 | 相邻帧位置和投影朝向变化较小 | 接近停留状态，缺少结束后持续停稳证据 |

不能由该片段确认：参考车自主运行、采用说明中的控制器、S曲线、精确90°转向、毫米终点误差、无短暂停顿、最终连续停稳、本车载物稳定性或车道合规。视频最后一帧接近终点也不能代替持续停稳验收。

## 3. 说明文档可借鉴的控制结构

1. 保持实时位姿估计`(X,Y,yaw)`，将世界坐标目标转换成车体前后/左右速度。
2. 沿程误差、横向误差和航向误差分别反馈，合成为`vx、vy、omega`。
3. 在经包络检查的转向窗口内开始改变朝向；平移和旋转共享轮速、负载及剩余时间约束。
4. 平移采用加速度/加加速度受限参考，航向接近目标时减速；两者都要在最终轮速上复核。
5. 到位要求连续新鲜观测稳定，不能第一次进入角度容差便宣布完成。
6. `MoveToPose`解决单段位置和朝向同时变化；`MoveThrough`解决多段不中途停车，二者可以组合，但必须分别验收。

这些是合理的工程分层思路，原说明未给出完整实现，不能据此确认其具体控制逻辑正确。

## 4. 实现前必须修正的细节

### 4.1 坐标符号矛盾

原文声明世界`+X`向初始左侧、`right>0`向车体右侧，但其变换在`yaw=0`时给出`worldX=right`，两者相反；yaw正方向也没有充分说明。原文坐标定义和公式不能同时照抄。

本车沿用连续运动计划：车体系`vx`向前、`vy`向左、`yaw/omega`逆时针为正；控制内用mm、s、rad，显示才转成度。场地坐标固定，两个抽签起点分别设置初始位姿，不因切换起点而偷换地图轴。转换在确认坐标合同后采用：

```text
vx =  cos(yaw) * VX + sin(yaw) * VY
vy = -sin(yaw) * VX + cos(yaw) * VY
```

其中`VX/VY`为同一固定场地坐标下的速度；`yaw=0`表示车体前/左轴分别与场地X/Y轴对齐，真实初始yaw由起点标定决定。先验证0、±90°、180°及任意角度正反变换，再接电机。原附件坐标若继续使用，需明确转换层及yaw正方向。

### 4.2 四轮公式缺少独立旋转维度

原文四行中`forward`与`rotation`系数完全相同，其4×3映射矩阵只有秩2；给各轮再乘方向符号仍不能使它具备三自由度。因此按原文字公式，纯前进与纯旋转得到相同轮速模式。该公式可能是简化/抄写遗漏，缺少源代码时不能视为可用逆解。

技术核对后的候选：对标准45°滚子、与WPILib上述源码相同排布的矩形麦轮底盘，正轮速表示各轮产生前进分量，令`a`为半轴距、`b`为半轮距、`k=a+b`：

```text
左前轮线速 = vx - vy - k * omega
右前轮线速 = vx + vy + k * omega
左后轮线速 = vx + vy - k * omega
右后轮线速 = vx - vy + k * omega
```

这是一组有条件的候选模型，不是本车已验证的电机符号。实际滚子排布、轮编号、安装旋向不符时重新推导；最后独立处理电机正向符号。轮周线速度与`k*omega`均为mm/s，不能直接把deg/s与mm/s相加。轮半径`r`确认后，`轮rpm=60×轮线速/(2πr)`；电机rpm再按实测传动比换算。若CAN速度单位为rpm等，按实际协议换算，不把脉冲输出教程当成CAN命令。

逆解用于目标轮速，正解用于检查和反馈里程计；轮编码器只测轮/电机运动，打滑时仍可能偏离整车运动。四向、原地转向和组合运动均须按本车实测确认。

### 4.3 路径方向、长度和横向修正要一致

原文选择最接近的车体轴作为路径方向，却仍用目标欧氏距离作沿程长度，目标有侧向分量时两者不一致。首版采用`d=(目标-起点)/距离`的单位向量；零距离转为单独航向任务。若以后采用先沿轴再横移，需明确二维参考曲线，沿程长度取投影，单独规划横向终点，不能混用两套定义。

采用`cross=d_x*误差Y-d_y*误差X`、左法向`n=(-d_y,d_x)`时，纠偏项应为`-K_cross*cross*n`。原文只写正比例标量，没有交代作用方向；先证明正/负横偏都会收敛，避免正反馈。

### 4.4 转向窗口与航向门控不是安全证明

窗口应根据角度、可用角速度/角加速度、轮速余量、HWT延迟及停稳余量估算所需时间，再映射到剩余路径；不只取固定距离。短路程大角度不满足条件时提前转向、降速或选另一种经包络检查的通行方式。

原文`allowedRemaining=remainingDistance*headingRatio`缺少进度变量和使用方式，不能直接证明位置与朝向会同时到位。实施时为平移/朝向建立共同参考进度，记录连续展开的角度；旋转滞后时限制平移进度与速度，防零角度除零、反向、超越终点以及“平移被锁住而旋转也无法启动”的死锁。必须有超时与安全出口；是否允许原地追上航向由当前位置扫掠空间决定。

### 4.5 平顺、里程计与最终到位仍缺实现证据

- 原文jerk逐步积分只是轨迹生成框架，不能单独保证刹停和无越过；需验证短行程、非零初始加速度、可变dt、重规划及速度反向。控制使用真实dt，周期超限有显式处理。
- 四轮统一缩放可保留当前瞬时速度组合比例，但反复缩放仍影响参考进度和加速度；参考轨迹必须同步降速，复核每轮速度/加速度与负载限值，处理控制积分饱和。
- CAN速度指令或累计发送脉冲是命令，不是测量；可验证的轮反馈＋HWT＋视觉纠偏是X/Y方案候选，需要阶段3冻结。预测航向只作短时间估计，记录置信度和延迟，不延长失效门禁。
- `DONE`要求位置、航向、实际平移/旋转速度和持续稳定时间同时满足阈值；位置/HWT样本必须新鲜，重复旧样本不能累计稳定次数。偏离容差时回到受限修正或安全失败。
- 原文`chassis_tracking_host_test: PASS`只是一条作者声明，本次没有其测试代码和原始输出，不能记成本项目测试通过。
