## 1. 规则事实、工程建议和待确认项

### 规则事实（R）

- `RUN-01`：机器人必须完全自主、一键启动，运行中不得遥控或人工接触。
- `RUN-04`（R）：15秒停滞会触发结束，等待转盘按基线的额外8秒处理；程序超时与故障恢复实现见E类RUN-05/RUN-06。
- `PWR-01`：比赛及调试使用机器人内唯一电源，不能中途换电。
- `MECH-01`：初始整机投影不超过 300×300mm，高度不超过 400mm。
- `MECH-04～MECH-05`：决赛改造需要真实装车使用，因此必须保留可用扩展接口。

### 工程建议（E）

- `RUN-05/RUN-06`（E）：异常有有限重试、降级、安全出口和超时，不能将这两项工程实现要求标成正式R规则。
- 首版 PCB **不安装三个 ToF**；相关接口只预留，BOM 标记 `DNP`。这不是规则变化。
- 吊塔两个运动轴各安装一个原点开关：35升降轴使用下方原点，28第二轴使用一侧原点；完成回零后依靠闭环编码器和软件行程运行。机械结构仍需设置不会损坏设备的缓冲/止挡。
- 限位优先用常闭（NC）触点，断线也能表现为故障；接口增加上拉、RC滤波、ESD保护和机械防松。
- 急停必须通过硬件回路切断执行器使能或动力，STM32 引脚只读取急停状态，不能作为唯一安全链路。
- 底盘四个轮电机不装行程限位，依靠闭环驱动器故障反馈、速度约束和硬件急停。

### 待技术答疑/实物确认（Q）

- 六个闭环步进驱动器与 DM4310 的 CAN 协议、波特率、节点 ID、终端电阻和供电电平。
- DM4310 是否为 CAN 型，以及是否能与步进驱动器共用总线；不兼容时使用独立 CAN2。
- PAW3395 所购模块的供电和 IO 电平。裸传感器可能不是 3.3V IO，未确认前禁止直连。
- HWT101、串口屏、MaixCAM2、CY-SCAN01 的实际串口电平；RS232 信号不得直接接 MCU TTL。
- 原点开关实际结构、常闭/常开逻辑、安装行程和失效状态。
- DM4310上电是否能返回输出轴绝对角度、是否存在单圈/多圈歧义，以及断电移动后能否恢复正确角度。
- ToF 是否在后续障碍实测中成为必需，仍需以黑色障碍漏检、碰撞和越界测试决定。

## 3. 限位、启动和安全输入

EXTI 的线路编号跨端口共享。为避免限位、托盘传感器和后续 ToF 因同号 EXTI 互相抢占，首版固件采用 **1kHz 定时扫描全部机械输入**，连续稳定 20～50ms 后才改变状态；只有 PAW3395 `MOTION`（PE4）保留 EXTI4，硬件急停状态 PE15 可选用 EXTI15作快速告警，但急停切断本身必须走独立硬件链路。启动键也采用定时扫描去抖。

| 等级 | 功能 | 引脚 | EXTI/采样方式 | 默认逻辑 |
|---|---|---|---|---|
| 必装 | 一键启动 | PC13 | 1kHz扫描 | 按下有效，软件去抖 |
| 必装 | 两档起点选择 START_SELECT | PA1 | GPIO输入，1kHz扫描 | 低=启停区1，高=启停区2；启动时锁存 |
| 必装 | 吊塔升降原点/下限 | PE8 | 1kHz扫描 | NC，断线故障 |
| 必装 | 吊塔横移/第二轴原点 | PE10 | 1kHz扫描 | NC，断线故障 |
| 建议 | 夹爪完全张开 | PE12 | 1kHz扫描 | NC或霍尔，实物确定 |
| 建议 | 夹爪闭合/夹到物 | PE14 | 1kHz扫描 | 只作辅助，不能代替力学保护 |
| 必装 | 硬件急停状态反馈 | PE15 | 硬件链路＋扫描/可选EXTI15 | 急停或断线有效 |
| 条件预留/DNP | DM4310机构原点 | PD3 | 1kHz扫描 | 绝对角度掉电恢复门禁未通过时安装 |
| 预留 | 备用机构限位1 | PE9 | 1kHz扫描 | 首版不装 |
| 预留 | 备用机构限位2 | PE11 | 1kHz扫描 | 首版不装 |
| 预留 | 备用机构限位3 | PD4 | 1kHz扫描 | EXTI4已给PAW MOTION，只轮询 |
| 预留 | 备用机构原点 | PD7 | 1kHz扫描 | NC优先 |
| 预留 | 备用慢速输入 | PE13 | 1kHz扫描 | 与启动键共享EXTI13但不启用中断 |

每个限位接口建议使用三针 `GND / SIGNAL / 3V3`，兼容机械开关和开漏传感器。长线使用双绞线、施密特缓冲或光耦/隔离输入；PCB上至少预留 1k～4.7k 串联、10k上拉、1～10nF滤波和TVS位置。最终阻容值需根据线长和开关抖动实测。

### 3.0 两档起点选择与一键启动（2026-09-10增补）

用户要求增加保持型单刀双掷开关，允许上电前或上电后选择，再通过原PC13按键启动。原消息两个模式均写“启停区1”，暂按既有双起点计划解释为模式1=启停区1、模式2=启停区2；此解释待用户确认，若确为同一起点的两条路线，应另设route_variant，不混用start_id。

R：FIELD-02要求按抽签起点出发并回到同一区；RUN-01要求一键启动、运行期间不人工操作。开关用于输入抽签结果，不代表可自行选择比赛起点。E：使用PA1（LQFP100第24脚），不占用PA0补光PWM；以下数值为工程候选。

接线：保持型SPDT ON-ON，公共端COM接GND；档位1触点经1k接PA1；档位2触点不连接。PA1端用10k上拉3V3，10nF到GND。开关用三针接口：1=GND/COM，2=档位1信号（串联电阻外侧），3=NC/档位2。不能根据开关脚的外观猜COM，需万用表确认。切换过程开路会被上拉，不会短接电源；拔线同样表现为档位2，本单输入方案不提供断线识别。

PC13仍独立接启动常开按键至GND；增加10k上拉3V3，可预留按键信号串联1k和PC13对地10nF。不用SPDT切换PC13线路，也不用它切电源。两个输入使用定时扫描，无需EXTI。

软件行为：
1. 上电清除本轮锁存状态，不自动启动；PA1连续稳定50ms后建立pending_start_id，并在屏幕显示候选起点。PC13必须先稳定释放，再接受新按下事件，避免按住按键上电自动启动。
2. 未启动时持续采样PA1，允许上电后切换；任何原始电平变化立即撤销起点稳定资格。切换期间按下启动不缓存、不自动补发，提示重新按键。
3. PC13连续按下20ms且选择有效、自检就绪时，将候选值锁存为active_start_id，并建立新的run_id/config_revision。启动事件消费一次；按键长按不能重复启动。
4. 启动准备期间冻结active_start_id。P1将run_id、config_revision、start_id及路线/地图版本与P2同步（沿用现有帧封装，载荷为待实现扩展，不擅自分配命令字）；P2确认匹配后才允许底盘出发。超时或不匹配不得运动，取消准备并要求重新释放/按下启动；迟到ACK不可启动新一轮。
5. P1按active_start_id初始化里程计，P2选择对应出发路径、视觉初始条件和返程目标；本轮始终返回该起点。
6. RUNNING/FINISHED/FAULT状态下拨动开关不得改变active_start_id、清零位姿或重置任务；只记录变动。本轮结束/故障后，通过明确的准备复位流程或重新上电进入待启动，不能自动再运行。MCU复位后也不恢复运动。

门禁：两档分别上电；上电后切换；切换同时按启动；按住启动上电；长按启动；运行中拨动；P2超时/错误/迟到确认；双起点出发返程。当前仅完成资源与行为规划，尚无固件或实物验收。已检查FIELD-01～03、LOC-02/03、RUN-01/06、DSP-01；待确认模式2文字含义、开关实物脚序、线长及实测去抖。

### 3.1 上电回零状态机

```text
BOOT
→ 所有执行器禁止，读取急停/限位/CAN故障
→ 若原点开关已触发：低速反向脱离，确认释放
→ 低速向原点搜索（带总行程和时间上限）
→ 连续有效20～50ms
→ 反向退回固定距离
→ 更低速度二次靠近
→ 连续有效后置零
→ 检查原点、配置的软件行程和编码器/驱动器反馈合理性
→ HOMED，才允许进入READY
```

任一开关同时矛盾、搜索超时、始终触发、断线或驱动器报警时进入 `FAULT`，不得继续盲走。回零动作期间也要持续接受硬件急停。

35升降轴在PE8回零后移动到配置的升降初始化偏移；28第二轴在PE10回零后移动到配置的第二轴初始化偏移。初始化偏移以电机圈数/角度和机构毫米值同时保存，修改工作初始位只改参数，不移动原点开关。因为取消末端限位，固件必须同时实施最大位置、最大速度、最大回零时间、最大搜索距离和驱动器故障门禁。

DM4310首版优先使用CAN返回的绝对角度和装配零偏，不主动安装原点开关。只有在以下实物门禁全部通过后，PD3才能保持DNP：连续断电重启、断电期间手动改变轴角度、跨过角度零点后重启，系统仍能唯一确定实际机械角度；机构有效范围不产生单圈/多圈歧义；异常角度不会造成碰撞。任一项失败，就在PD3安装原点传感器并执行回零。

| 蜂鸣器 | PB0 | TIM3_CH3/GPIO |
| 向下补光灯调光/使能 | PA0 | TIM2_CH1/GPIO，PWM或开关输出 |

载物确认按转盘变更计划执行：机械臂放料完成与当前占用/视觉证据共同提交库存；不再等待三料盘舵机夹紧DONE。PD10～PD12只保留占用检测资源，传感器布置待定。

## 6. ToF 延后方案与扩展资源

首版不采购、不焊接、不接入三个 ToF。为了避免二版PCB大改，只保留下列接口：

| 未来功能 | 引脚 | 首版状态 |
|---|---|---|
| I2C2_SCL | PB10 | 连接扩展座，DNP |
| I2C2_SDA | PB11 | 连接扩展座，DNP |
| ToF_L_XSHUT | PC8 | 扩展座，DNP |
| ToF_C_XSHUT | PC9 | 扩展座，DNP |
| ToF_R_XSHUT | PA8 | 扩展座，DNP |
| ToF_L_INT | PD13 | 扩展座，DNP |
| ToF_C_INT | PD14 | 扩展座，DNP |
| ToF_R_INT | PD15 | 扩展座，DNP |

PD13、PD14、PD15分别与PC13启动键、PE14夹爪到位、PE15急停反馈共享EXTI13～15。首版ToF为DNP，因此没有运行冲突；后续启用ToF时，三个INT只能作为1kHz轮询输入，或者在二版PCB中改到不冲突的引脚，不能直接把两组同号信号都配置成独立EXTI。

扩展座必须带 3.3V、GND、SCL、SDA、XSHUT、INT，并预留I²C上拉但首版不装。未装时固件必须上报 `tof_present=false`、距离状态 `NOT_PRESENT`，不得用0、最大量程或历史值伪装有效距离。是否启用 ToF 由后续黑色障碍100次随机测试决定；未装ToF期间，P2不能把“视觉未见障碍”等同于近距安全，P1仍需实现速度上限、急停和通信失联停车。

额外预留：PA2～PA3（定时器/编码器/ADC）、PC4～PC5（ADC/GPIO）、PE9、PE11和PE13（慢速GPIO）。PA0已经分配给垂直向下补光灯的PWM/使能控制，PA1已经分配给两档起点选择。这些预留引脚必须在原理图标为保留功能，未经评审不能随意占用。

## 7. P1 实施计划与门禁

### P1-0：原理图冻结

- 核对 LQFP100 符号、每个物理脚号、AF、供电脚、VCAP、晶振和调试口。
- 完成 CAN、串口、电平转换、限位保护、舵机电源和 DNP-ToF 扩展座。
- 输出引脚复用检查表和电源预算。
- 门禁：无重复引脚、无同号EXTI冲突、所有复位态安全。

### P1-1：最小板与安全链路

- 只焊 MCU、电源、SWD、状态灯、急停输入和一个限位输入。
- 验证复位、下载、看门狗、棕断和执行器默认禁止。
- 门禁：拔掉限位线能进入故障；按急停不依赖软件即可断使能。

### P1-2：CAN与六个步进电机

- 先单电机、再同总线多节点，最后接四轮＋吊塔。
- 固定节点ID、波特率、命令超时和故障码。
- 门禁：总线负载、错误帧、断线与重复命令测试通过。

### P1-3：吊塔回零和软限位

- 完成两轴各自的“脱离—搜索—退回—二次靠近—置零—移动到配置初始化偏移”。
- 建立软限位、最大回零时间和最大搜索距离。
- 门禁：每轴连续100次回零无撞击；开关短路、断线、粘连均安全报错；软限位越界命令必须被拒绝。

### P1-4：定位与串口

- PAW3395＋HWT101接入，完成相对里程和航向融合。
- 接 Orange Pi、MaixCAM2、串口屏和可选扫码器。
- 门禁：时间戳、质量门控、丢包、CRC、心跳和500ms停车通过。

### P1-5：舵机、DM4310与托盘

- 分批接入PB9夹爪、PB1载物转盘候选驱动、DM4310和载物检测，按转盘变更计划验证分度与库存。
- 验证峰值电流、压降、复位干扰和机构限位。
- 门禁：满载动作不导致STM32、Orange Pi或CAN复位；夹紧有多证据确认。

### P1-6：P1/P2闭环

- 冻结 `RobotState`、`ActionResult`、命令序号和CRC16协议。
- P2只发目标，P1执行并回报 `ACCEPTED/DONE/ERROR`。
- 门禁：旧观测、重复序号、P2断线和动作超时均不会重复动作或失控。

### P1-7：整车与扩展决策

- 两个起点、完整赛程、同一电池完成压力测试。
- 在不装ToF条件下完成随机障碍安全验收；若近距盲区不能通过，再启用预留接口并回归测试。
- 门禁：连续完整流程通过后才冻结PCB和固件版本。
