# 独立 ICM/编码器短窗观测：high 冻结方案

2026-11-15。仅本地方案/数学审查，无硬件、网络或 Git 操作。本文件收束并替代 `observer_design.md` 中整段累计 I/J 和杆臂补偿两项；其他原控制隔离边界保持。

## 1. 结论与范围

可以进入 medium 的最小实现：200 Hz 维护加速度历史，按用户最新决定每 20 ms（50 Hz）计算一次已到达编码器锚点到最新 IMU 样点的前进/向右位置及速度外推，IO1 最多 2 Hz。没有必要每 5 ms 遍历历史，也没有必要引入新任务、滤波参数或控制接口。

20 ms 周期减少观测快照等待下次计算的时间；串口 IO1 仍最多 2 Hz，因此不会自动变成 50 Hz 显示。每次只扫描有界的 128 点历史，50 次/秒约 6400 个历史点访问，工作量有明确上界，适合作为本版最小实现；这不是板上耗时结论。真实耗时、任务余栈和采样时序影响留待以后授权测量。提高观测预测频率不改变原控制，也不能证明地面误差下降。

这是**依赖原轮/HWT位置的短时延迟外推**，不是独立地面定位，也不识别或修正累计轮地滑移。不能用外推位置仍接近轮位置来证明实尺右偏消失。首版不补偿传感器安装偏置 `r=(-20,+90) mm`（车前/左），高度未知；输出必须保留 `lever_compensation=0` 的说明。

新模块只读原快照；禁止写入控制、纠偏、到位、STOP、VM、健康/故障或看门狗路径。新模块的 WAIT/INVALID 只是自己的诊断。HWT 仍是原主航向源，原 half/PID/130RPM/距离比例/保护均不变。无下载、复位、串口命令或发车授权由本方案产生。

## 2. 数学核与原失败根因

两次已到达的共同时间轮位置为 `(t0,p0),(t1,p1)`，`Δ=t1-t0>0`，估计时刻为最新有效 IMU 样点 `t>=t1`，`h=t-t1`，轮均速 `u=(p1-p0)/Δ`。F/R 两轴分别使用：

```
C = integral[t0,t1] ((s-t0)/Δ)*a(s) ds
D = integral[t1,t] a(s) ds
E = integral[t1,t] (t-s)*a(s) ds
v_hat = u + C + D
p_hat = p1 + u*h + h*C + E
```

只保存 128 个 `{uint32 tick_ms; float aF,aR;}`，约 1536 B 静态 RAM，不保存整趟 I/J。每次查询用 uint32 差先得到短窗相对时间，再转秒，禁止把大绝对毫秒 tick 直接转 float。

每个相邻有效样本上的加速度按分段线性模型处理。在裁到边界后的 `[l,r]` 上，`d=r-l`：

```
A = d*(a_l+a_r)/2
B = d*d*(a_l+2*a_r)/6   // integral (s-l)*a(s) ds
前锚段对 C 的贡献 = ((l-t0)*A+B)/Δ
后锚段对 D 的贡献 = A
后锚段对 E 的贡献 = (t-l)*A-B
```

必须在 t0/t1 处裁段并线性插值**加速度**。这对线性加速度/常 jerk 是精确积分。查询仅使用时刻不晚于 t 的已到达历史；不为了求当前估计插入尚未到达的下一 IMU 样点。

旧 `validate_observer.m` 的恒等式成立，但 `interp1` 线性内插二次/三次 J 后除以 22 ms，会放大速度数值误差。仅常加速度 `a=-150 mm/s²`、5 ms 栅格、锚点落在格内 3/2 ms 时，J 内插误差就达 `0.00045 mm`，除以 `0.022 s` 后为 `0.02045 mm/s`，可直接突破旧 0.01 速度断言。旧失败脚本/log/receipt 保留，不能将其误写为预测公式被证伪，也不能靠放宽断言掩盖不一致插值。

若加速度线性插值残差有界 `|e_a|<=ε`，局部核误差有解析界：`|e_v|<=ε*(Δ/2+h)`、`|e_p|<=ε*(Δ*h+h²)/2`。恒常残余偏置时等号成立。该界不包含编码器误差、姿态/时间/杆臂误差，不能当总地面误差界。

## 3. 最低姿态与时间处理

- 坐标采用已记录安装假设：传感器右/后/下转车前/左/上，矩阵 `[0 -1 0;-1 0 0;0 0 -1]`；路径角 θ 用原 HWT 与现有 heading offset/path heading 得到，`aF=cosθ*a_front-sinθ*a_left`，`aR=-sinθ*a_front-cosθ*a_left`。原始安装/三轴 gyro 的全姿态实物符号仍未完整验收，不因数学检查通过写成已标定。
- 复位后、自动运动开始前收集 200 个独立、连续、有效样本作六轴均值；这是**静止假设**，未新增传感器阈值来声称真正静止。均值尚未就绪时，自己的状态是 WAIT_CAL，绝不阻碍原运行。运动开始时仍不足 200，不把运动样本补入本会话的静止均值。
- `m=mean(acc_body)`，`g0=g*m/|m|`，`b_a=m-g0`；gyro 减起前均值并转 rad/s。仅分离径向均值差，无法从一个静止姿态识别真实横向零偏。不可把归一化时的差值遗漏，否则初始残余径向偏差会随倾角投影。
- 重力使用二阶传播：`c=ω×g_old`，`g_new=g_old-dt*c+0.5*dt²*(ω×c)`，随后归一到 9806.65 mm/s²。a_body 取同一时刻的 `acc_body-b_a-g_new`；dt 和 gyro 更新次序必须和验证脚本一致，不用运动加速度反向拉重力，不增加 AHRS/互补参数。
- HWT 使用当时已经发布、且 `angle_ms<=sample_tick_ms` 的最新角，按零阶保持处理，角年龄须小于现有 100 ms 上限；记录其 age。不得拿比该 IMU 样点更晚的角回填已经写入的历史。HWT 角的低采样率/保持误差是首版已知局限。
- `sample_tick_ms` 是当前 RAW 驱动服务关联时间，不是已校正的 ADC 采样时刻。保留原字段及这个口径，不改驱动、不把时间一致性模型当硬件同步通过。

重力传播跨越整个启动/会话的 gyro 偏差、长期 idle 漂移、动态俯仰/横滚与未知杆臂仍可造成误差；局部积分只限制该误差进入 p/v 的时间窗，不消灭误差。首轮重复测试本来每趟 reset 的流程可直接支持，不据此声称长时间多会话精度通过。

## 4. 生命周期和诊断边界（均为 E）

- 原 ICM owner 每个新 sample_sequence 最多处理一次；重复样本不积分。必须一致核对 sample_sequence、edge_sequence 的相邻增量，以及 skipped_edges/read_races/transfer_errors 是否增长；不能只看 sample_sequence 仍逐一递增就宣称没有缺边沿。接受实际 dt 为 1..20 ms，序号/计数表明缺数、dt 为零/倒退/过大、无效 HWT、非有限数时，清加速度局部历史及轮锚对，只置自己的 reason，不拼断点、不补零、不向原模块写恢复。以上所有数值阈值都只影响 observer 诊断。
- 缺历史后可在有效数据重新连续覆盖时重建；重力跨断点的近似必须保留诊断记录，不清零后伪称无断点。RAW 已失效则按其现状报告，不在 observer 内重启硬件。
- 只接收同一 `anchor_valid/reference_set_ms` 的新共同轮样点，按 pose.sample_ms 去重。参考改变、continuity_lost、pose invalid、共同样点倒退时重建自己的历史/锚对，绝不拼旧会话，也不调用 SetPose/ResetRecords。
- 冻结轮锚有效区间 `1<=Δ_ms<=250`，`0<=h_ms<=200`，并要求 t0..t 全部落在连续的 128 样本历史内。这些只是观测数值/新鲜度边界，不是新增停车阈值，也不是适用于整场定位的规则。短 Δ 会放大位置量化/噪声形成的均速误差，本版不另加滤波或对其许诺精度。
- 每 20 ms 最多计算一次（50 Hz），估计 timestamp 是该次最新 IMU 样点时间；打印时间另列。发布快照同时给出 valid/reason、sequence/reference、t0/t1/estimate tick、轮锚年龄、HWT角年龄、F/R位置速度、轮原位置及加速度。valid 只表示该模型当前有可计算的数据，不表示完整标定/地面精度。
- IO1 最多 2 Hz，沿已拟定状态帧后空隙低优先级尝试；串口忙则跳过，禁止等待/重试/新增命令；IR1 和原心跳/状态逻辑保持。CRC/最大字段长度/缓冲容量必须验证。

## 5. 实施前证据及验收

已独立读取 medium 最终 `observer_local_matlab.m` 与 summary：本机 R2020a 实际退出 0，205 项数学检查通过，常加速度/jerk 双轴含 22 ms 异步锚、最新样点因果裁剪、缺历史/30 ms gap、tick 回绕、轴变换、二阶重力传播与 single 局部积分均覆盖。最大 double p/v 误差约 `7.11e-14 mm / 3.98e-13 mm/s`，single 约 `1.82e-5 mm / 2.75e-4 mm/s`。这些只是合成数学数值，不是传感器噪声、板上耗时或实车精度。原 attempt1/旧失败原件不得覆盖。

C 实施验收只需与本次范围相称：

1. 真正编译此 C 核的 ARM 定向测试，对照上述同一解析运动及边界，特别检查异步裁段、Δ=1 ms 接受/Δ=0 拒绝、uint32 回绕、起前均值、重复/断序/参考改变、invalid 不输出可信零值。
2. 三实际 Keil 配置 0 错误；非专项 allocated 与旧基线比对，产品控制源及未授权输入保持。只增加本模块、必要只读接线/IO1/parser/工程条目，GBK/CRLF 不改。
3. 核对同 owner/发布一致性、静态 RAM、局部栈、无全程 I/J、无任务/栈/优先级调整、无阻塞 TX；实机时序、余栈、200 Hz 完整性及通信负载另待授权观察，不由构建推断通过。
4. 交接明确候选只在本地；旧板上仍 3966ed37…1113d，新 ELF 会改变 RAM 地址，旧固定 SHA/地址的 176 B reader 不能直接沿用。正式 C GO 及后续下载仍由协调者按授权边界给出。

已核基线：R RUN-01/PWR-01/MECH-01/02；E LOC-01/02/03/05/07、MOT-02/04、RUN-06；Q FIELD-05/OBS-03/QR-04 保持待技术答疑。未闭环：完整三轴标定/实物符号、高频同窗采集、延迟与振动/滑移、地面沿程真值、长时姿态漂移和真实运行开销。
