# P1 速度过渡与制动前置

本机 MATLAB R2020a 第四次运行退出0。22条显式 q/a/目标速度向量与264个记录的断言组通过，另有保留曲线内的逐样本范围与接点断言。通过轨迹见 `p1_retained_trajectories.json`，曲线输入、预期控制点、q/a/j、逻辑轮向与0.1RPM见 `p1_kernel_vectors.json`，边界和发送时序数值见 `p1_kernel_summary.json`。attempt1/2为较早模型，attempt3因MATLAB只接收标量断言失败，原日志和脚本已保留。第四次日志中“59 scenarios”合计包含相关验证组，独立向量数以上述22条为准。

- **速度输入输出** `velocity_candidate(q0,a0,q1,dt_ms,limits)`。车身前三列的平移单位分别是mm/s和mm/s²，航向是rad/s和rad/s²。输出4×3速度控制点、整数毫秒总时长、平移/航向弧长上界。20ms递增到8000ms，按位移/加速度跳过必要时间以下的候选，最坏400次候选。平移分量、航向和真实几何映射的四轮速度先用控制包络，需检查越界时精确计算线性映射后三次速度的内部驻点。向量加速度、jerk及轮端导数用四等分后的控制包络。近边界399.9mm/s、向外3mm/s²可制动，400mm/s、向外50mm/s²无解。
- **制动输入输出** `brake_reservation(q,a,request,limits)` 从兑现边界的q/a向零求解。请求包含当前时刻及四轮+航向五个源时刻、最大新鲜年龄、计算/排队/四轮批次耗时、前方/后方/横向/航向空间、平面单位切向、锁定航向方向（-1/0/+1）、反馈误差和混合批次附加偏移的上界，以及丢部分应答。计算输出前后侧与角度保留量、时长、原因。350mm/s且向外90mm/s²的例子在93ms预算下需要986.204mm，数学曲线时长4520ms；较窄余量必须提前制动。此数值仅对应冻结的测试条件。
- **发布选择** `proposal_reservation` 先验旧状态可以制动，试采样候选曲线实际下一时刻，保留该点非零a重验后续停车。输出advance、brake（保留仍有效的旧停止曲线）或fault（旧停止条件也失效，交现有故障STOP）。模拟短段中当前制动预算202.553mm，拟发布前缀消耗3.602mm，拟发布后要再有208.400mm，故保留当前制动曲线。长合成路线直线以400mm/s到峰后停，往返速度曲线各4s，总理想1600mm。合成斜向达到两分量各400mm/s，总理想3201.78mm；说明有限实场路段通常达不到此峰值。
- **轮端** 77mm轮径、209mm旋转臂，轮序LR/RR/LF/RF，正向方向位0/1/0/1，0.1RPM最近整数编码且上限3000。候选四轮加速度250RPM/s、jerk1400RPM/s³是工程敏感性假设，无带载实测；标记为区间假设。28ms成功、ACK丢失且可能已应用、200ms延迟敏感性和16种旧/新混合掩码已检查。真实刚体轮约束剩余项用 `[1,1,-1,-1]/4`，投影误差仅表示理想轮指令投影，不能证实混合期实际滑移。向量制动证明条件包括主调用方给出有效曲线坐标、经过检验的反馈及混合失配上界。实际时序、栈、算时、发帧原子边界、误差校核及旧停止计划的有效性需P2真实owner和后续现场验证。
- **交付边界** MATLAB先验只有制动/前缀的数学校核及条件包络。软件q导数用车体系，不能直接当非零wz时的惯性系物理加速度。SDK日志和本次模型不替代各轮/航向带载测量。当前尚无P1 C写入。R核对FIELD-01/02/06、OBS-01/04、RUN-01/04/07、PWR-01、MECH-01/02。E LOC-02/03/04/05/06/07、MOT-01/02/03/04、RUN-05/06；Q FIELD-05/OBS-03/QR-04待技术答疑确认。
