## 2. 最小候选的精确定义

增加独立编译宏，**默认OFF**，只对baseline40调试模式、PLAN9、dir1、kind5、102预算、2100目标这一条已精确放行的左移路径开启。隔离构建候选可显式ON，普通工程默认及原候选可一键回退；不扩成运行时可配置框架。旧20 cm/s `APP_LEFT_BACKWARD_RATIO=0.01670644`、`Chassis_LeftTrimCommands`及其52 RPM限制保持原字节，不为40 cm/s放宽它们。

设当前左移profile基速整数b（0…102 RPM），现HWT有效纠偏h保持原±min(b,2) RPM；新增向后量：

```
beta = 0.04
t = floor(beta*b + 0.5)          // 整数RPM，0…4；不是全程精确4%
LR =  b - t - h
RR = -b - t + h
LF = -b - t - h
RF =  b - t + h
```

四轮顺序LR/RR/LF/RF、驱动方向0/1/0/1的既有映射保持。−t是四轮同符号的车体向后分量；它与旋转纠偏h正交，不以改目标航向代替。b=0时t=0/h=0，最终STOP继续既有停止帧，不留下向后残速；小b时t=0、方向不被反转。实现可新增一个小而独立的PLAN9混轮函数，在已有profile命令生成的两个必要入口调用；不要触碰前进专用`Chassis_Baseline40Budget/Commands`或启用其全正混轮旁路。

### 左距投影：保持真实测量，不扣假想补偿位移

当前真实编码器到距对逻辑轮位移做`(LR−RR−LF+RF)/4`，并按四轮共同源时间括点插值后求均值。公共向后分量−t的投影为`(−t+t+t−t)/4=0`，HWT旋转项也在理想轮投影中抵消。因此加入向后分量**不应改变左距计算或阈值**。

本PLAN9不复制旧路线LeftTrim的`s_left_trim_mm/s_position_trim_mm`命令积分扣除，不从实测编码器位置中减去“应该走过的补偿距离”，不伪造健康/里程。不增加spread50之类历史保护：实际当前到距代码无该per-wheel spread判定，只有既有mean/目标+50/profile误差等约束。实际四轮响应不同导致剩余投影误差仍是真实测量，不人为扣掉；保留所有既有保护和停止能力。

### 连续参考的速度/A/J预算

- 左移参考峰保持400 mm/s，主轴预算b≤102，HWT纠偏仍±2；beta=.04取整的t峰4，因此四轮命令绝对峰≤102+4+2=108 RPM，低于既有反馈保护130。108是命令预算，130是反馈限值；反馈不被伪装限幅或清故障。允许Encoder 0.1RPM编码的原函数和协议单位保持。
- 不能只凭108<130就放行加减速。新增正交分量后，快轮连续变化按(1+beta)放大。为保留原总轮等效A150/J300预算，**先除1.04，再扣完整原随动余量**，而非只除扣完后的剩余量：

```
f = pi*77/60 = 4.031710572106901 mm/s/RPM
follow = 2 RPM; omega = 1
A_reference = 150/(1+0.04) - f*(2*follow*omega)
            = 128.1039269423 mm/s^2
J_reference = 300/(1+0.04) - f*(6*follow*omega^2)
            = 240.0810115963 mm/s^3
```

- 最小代码位置：候选ON且精确左移白名单时，现`MotionDistanceAcceleration/Jerk`向原Prepare/Validate公式返回150/1.04、300/1.04；原公式继续扣原follow余量。其余输入仍返回原值，**PLAN8前进值与路径不变**。只调整本候选内部余量，配置/报告仍明确总预算150/300，实际左移profile稍变慢。不得私自降低400参考。
