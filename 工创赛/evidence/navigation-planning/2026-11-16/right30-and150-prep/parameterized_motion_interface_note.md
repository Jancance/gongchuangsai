# 参数化运动接口：当前事实与比赛接口目标

用户要求：比赛调用应可给方向、前进/平移距离、峰值速度等参数，并按此前各方向实测参数使用。此文件是接口边界说明，本轮只增加30cm测试参数，不新建重复控制器或放开正式比赛入口。

## 已有可复用层

- motion_profile.h/c的MotionProfile_Prepare(plan,distance_mm,&limits)已经接收距离和speed(mm/s)、acceleration(mm/s²)、jerk(mm/s³)，短程自动去掉匀速段并降低实际参考峰速；结果有peak_speed/duration_s。纯规划，不发CAN/不授运动许可。当前仅静止到静止单段，不等于支持运动中重规划/连续过点/任意初末速度。
- MotionProfile_LimitTranslation已可按方向向量和四轮能力/纠偏预留统一时间缩放V/A/J；不应独立削顶各轮或改公共轮径。数学边界不是实物许可，斜向及全速工况仍待验证。
- ChassisAuto_PrepareTranslation/PrepareRouteTranslation与BeginPreparedTranslation已有prepare/执行分离。显式reference路线入口仍受APP_ROUTE门禁、当前20cm/s上限、RPM预算与配置来源限制；不能宣称正式任意距离/速度已开放。

## 需要保持的参数合同

1. 调用层统一单位和车体/场地坐标；方向决定已有距离倍率、速度到轮速换算、纠偏及轮能力预算，不能给四向统一套一组调参。
2. 当前BASELINE40前/后纵向倍率1.0218254，后退为继承非独立标定；横移主距离不套该倍率。前专用横偏修正仅PLAN8/mode0；左2%仅已验证PLAN9/mode1；右10/12/13和后11不误套。普通/旧route其他分支另有条件，不能混称同一组。精确源码及有效A/J见direction_parameter_matrix.md。
3. 峰值速度参数是上限。300mm同400上限时，实际参考峰167.930895mm/s而非400；1500/2100可到400。上层应区分requested speed ceiling、generated reference peak和真实轮反馈/地面速度。
4. 未来只在现有层上整理通用调用、方向限制和状态反馈，不为每个距离写控制函数。PLAN12/13是调试用有限工况选择，底层曲线仍同一个；有限调试白名单不直接变成无约束比赛入口。
5. 参数化能力不等于所有距离已实车准确。参考DONE、到距状态、STOP发送、反馈归零、物理停稳与实际位移各有语义；仍需已验证距离/速度/载荷范围和定位有效性，不用时间到或目标值冒充真实位移。

## 下一次实测安排边界

同一组合候选包括150cm及30cm，不必先安装150旧候选再安装30版本；获得硬件/场地授权后安装组合候选一次，分别按摆位单趟采集，每趟沿既有reset1/START1与RAW保存。300是短距离起停工况，不是与1500同速标定；保实际速度曲线后再解释长度相关误差，不能两点拟合就唯一断定比例。当前硬件动作仍0。
