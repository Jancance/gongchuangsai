## 安全不变量

- 启动、相机失效、标定失效、STM32 心跳超时或路径不可行时输出 `SAFE_STOP`。
- 像素坐标不能直接发送给 STM32；必须经带版本的标定转换为毫米坐标。
- `ACCEPTED` 与 `DONE` 分离；相同序号重发不能重复物理动作。
- STM32 是最终运动安全责任方，必须独立实现 200ms 减速、500ms 停车和硬件急停。
- 局部车道净宽不足时请求全局换路，绝不强行侧绕。
