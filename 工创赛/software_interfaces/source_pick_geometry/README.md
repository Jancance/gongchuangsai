# 原料区目标几何/反馈检查候选

`source_pick_geometry.h`只做静态换算和单个反馈样本检查，没有CAN、串口、PWM、RTOS任务、运动请求、真实到位DONE或库存接口。未加入实际Keil工程、未改其0～180°/通用50mm/源准备70mm限制，所有计算结果`motion_allowed=0`。

实现之前已在用户本机MATLAB完成对应几何与顶部轨迹/故障候选验证，见`docs/INTEGRATION8_TOP_MOTION_2026-11-05.md`。这些模型不等于整车或完整动作通过。

坐标为初始车体X向右、Y向前，旋转正方向俯视逆时针；目标/停车平移输入单位mm，航向输入deg。固定几何例为回零半径165mm、最大伸缩170mm、源参考角180°。235−70=165仍为本轮输入关系，不宣称实物零点误差为0。

- `SourcePick_Solve`计算停车平移/航向后的目标伸缩和角度。物理越程、角度越界、非法数值拒绝；即使物理范围内，未达到调用方声明的端点余量也返回`SPG_MARGIN`。候选三个点均未满足原10mm余量，不能因为字段里有数字就执行。
- `SourcePick_FirmwareSupports`按显式给出的固件能力检查目标。以当前实际源码0～180°和通用伸缩0～50mm检查时，三个候选均不支持；测试中用360°/170mm只是比较假设，不是修改固件或设定已验机械软限位。
- `SourcePick_SampleWithinTolerance`只检查某个反馈样本的位置、速度、年龄及参考曲线已经完成。候选角度±0.2°、伸缩±0.1mm、关节自身TCP误差上界2mm与最大反馈年龄100ms均为E设计条件，实车达到情况未验。该函数不累计稳定样本、不验证相机/TCP/轮次/标定ID、不发STOP、不授权抓取，也不把几何余量未通过变成通过。调用方未来仍须接完整事务和当前姿态/标定/接触证据。

`joint_error_upper_mm`用最大半径圆弧弦长加径向差作为关节本身位置差的上界，不包括视觉、安装、车体停车、编码器系统误差、回差或负载变形。

运行`python -X utf8 scripts/check_source_pick_geometry_20261105.py`，检查从本轮MATLAB保存的三处目标交叉生成C向量，包含yaw逆变换、负/过行程、原10mm余量拒绝、非法/陈旧/未来反馈、计时回绕、曲线未结束、1.6°残差、速度未停稳和伪造许可拒绝。GCC以警告为错误；ARMCC只做Cortex-M4单元编译，不是完整固件编译或实车验证。

当前源区50mm抓取底面候选、约69mm下降及9mm带料竖向间隙属于场景几何数据；本模块**不生成升降虚拟脉冲**，旧105000示教值不是69mm标定。
