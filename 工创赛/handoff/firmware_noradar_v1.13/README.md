# STM32 无雷达整车工程 v1.13

打开 `gongxun-f407.uvprojx`，选择 `Vehicle_Integrated`；`Vehicle_Offline` 为离线目标。当前版本独立目录内包含所需源码、头文件和驱动，无需复制旧版本目录。Keil 编译器使用既有 ARM Compiler 5 工具链。

本次只上传 v1.13 累积后的工程，不补传 v1.12 等中间版本；远程原有历史版本保留。本目录保留 Integrated/Offline 的本版 AXF、BIN，排除中间编译文件、旧版 BIN 和个人调试布局。

## 版本内容

- 原料区提前准备距离600mm；需要转向的工位由底盘开始转向后同步机构准备，转完才接入视觉纠偏。
- 三工位普通伸缩200RPM，加减速600RPM/s；原料左右恢复160度预收，无额外600ms等待。
- 原料升降上下主指令保持3000RPM，动作到位/离站容差1mm；运动途中越界窗口仍为2mm，两者独立。
- 第三件释放保留PWM生效和200ms，用真实完成/到位证据放行离站；粗加工名义停车点(356.5,1170)mm，保留附近转向的几何校验。
- 视觉有效观测年龄500ms；必要的停止、通信和越程判断保留。细节见 `validation/烧录与变更说明.md`。
