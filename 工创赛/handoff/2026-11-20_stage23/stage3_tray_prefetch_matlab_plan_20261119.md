# 第三阶段回收提前转槽：MATLAB 前置草稿

以 2026-11-19 原始实车采样为基线：对齐后至软件结束 56.953 秒（放置 29.172 秒、回收 27.781 秒）。槽盘在松爪时未到原槽，实物回收失败。20 秒指标从 `align_done` 开始，到第三件完整回原槽为止；模型只估计时间和动作顺序，无法证明落稳或达成实车指标。

1. 离散事件模型从每件回收下降动作启动对应原槽的槽盘预转。按该次实际转槽命令发出时间起算 700 ms，沿用基线等待，不把旧放置预取或前一件标志算成当前回收完成。用 run、阶段及本件身份标记有效预转；自动 mode 1 及同轮请求 32 进入回收、换件和故障时清理旧预取标志。确认请求 32 沿用原任务映射与 X，采用请求时合法回收 Z。
2. 槽盘预转与回收下降并行，保留夹紧、到顶、缩回和回盘偏航的必要顺序。松爪同时要求本件预转已经启动、符合原有 700 ms 完成条件、已到真实顶位且其余原有动作完成。测试预转先完成、迟于机械臂、未启动、被拒绝、旧计时未清和错槽映射。模型分别检查 699/700 ms；固定等待不代表实体槽盘有到位反馈。
3. 遍历物理环顺序及任务颜色/原槽颜色排列，核对三放后沿放置顺序回各自原槽、每次松爪完成才计数与换件。注入 STOP 或参考失效与预转启动、机械臂完成或松爪放行同拍，验证不会新发转槽或松爪续动作。保留模式 0 / 2 的原动作。单独记录已发出的槽盘 PWM 与停机时的观测边界，不把取消模型事件当成已实现物理停车。
4. 从实车采样分解可重叠、仍串行和无法根据 0.45 秒采样分辨的区段。先输出基线和提前转盘带来的模型时间差；没有更细测量前不声称达到 20 秒。70 mm 空回程的测量参考点及生效范围未定，此草稿不改变其路径或行程。
