# P2 视觉数据目录

本目录只保存目录规范和小型清单；原始视频、连续帧和大模型文件不得直接提交到 Git。

建议在采集盘建立同名结构：

```text
data/
  raw/main/          向下全局快门相机原始数据
  raw/front/         前视导航相机原始数据
  raw/scanner/       扫码原文、时间戳与通道来源
  annotations/       六色、圆环、数字、车道、路口、障碍、码垛标注
  test/              与调参数据隔离的独立测试集
  failures/          现场失败回归集
  replay/            P1遥测、P2观测、动作结果与时间同步记录
  manifests/         SHA256、设备身份、工况、标定ID和标签清单
```

每段采集必须记录：日期、操作者、相机 `source_id`、VID/PID、序列号、USB物理端口、分辨率、像素格式、实际帧率、曝光、增益、白平衡、焦距/安装高度、照度、场景标签、`calibration_id` 和文件 SHA256。

测试集不得参与阈值或模板调节。蓝/浅蓝、黑色物料/障碍、太阳直射、阴影、反光、遮挡、转盘运动、路口和双障碍必须有独立标签。身份或运动状态不能确定时，真值使用 `UNKNOWN`，不得强行归类。
