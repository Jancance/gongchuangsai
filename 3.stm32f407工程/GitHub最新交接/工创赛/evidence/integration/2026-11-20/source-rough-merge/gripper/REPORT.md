# PB9 夹爪与雷达共用 TIM4

夹爪接线采用队友 `f0393093` 的 PB9/TIM4_CH4。映射参数与本地一致，180° 张开对应 1833 µs，140° 抓取对应 1537 µs。`APP_ZONE2_MISSION_ENABLE=1` 时使用 PB9，普通构建仍使用原 PA0/TIM2_CH1。候选的 `Vehicle_Offline` 走无硬件初始化分支。

雷达初始化继续独占 TIM4 时基，PB6/CH1 与 PB7/CH2 保持原有控制。机构入口在 `RadarServo_Init()` 成功后、首次 `jiazhua()` 前调用 `Gripper_Init()`。提前初始化会将 PB9 保持低电平并拒绝夹爪指令，雷达就绪后可重新初始化。首次启动和同帧重启使用清零的 CCR4 开通输出，发布脉宽后等下一次自然更新。停止关闭 CH4、拉低 PB9 并清空 CH4 的活动值与预装载值。`Gripper_PulseApplied()` 可供机构动作等待最近一次脉宽进入 PWM 周期，机械到位仍由上层动作判据决定。

## 本机证据

- 编码前运行 MATLAB R2020a 9.8.0.1323502，退出码 0。按 APB1 42 MHz、TIM4 84 MHz 计算 PSC=83、ARR=19999。遍历 20,000 个相位，检查初始顺序、首次脉宽、换脉宽、非法输入、停止和同帧重启，核 CH1/2 的计数和脉宽模型未受扰动。UIF 在写 CCR4 后清除，极端时序可能多等一个周期。MATLAB 启动有本机偏好和缓存文件警告，脚本执行到 PASS。 [模型](validate_gripper_tim4.m) · [标准输出](matlab_stdout.txt) · [标准错误](matlab_stderr.txt)
- 主机夹具编译正式夹爪、雷达及 STM32 标准外设库，对映射寄存器验证候选、候选离线、普通配置三档。覆盖 PB9 复用、CH4 启停和无效脉宽拒绝，并检查夹爪启停全过程保留 TIM4 的 PSC、ARR、CNT、CEN、EGR 和雷达两通道配置。UIF 由夹具注入，外设预装载时序由 MATLAB 模型单独验证。 [夹具选择与构建](verify_gripper_registers.ps1) · [执行结果](register_results.txt)

## 规则与待验收

- R 核对 `RUN-01`、`PWR-01`、`MECH-01/02`。硬件仍须按同一内置电源、上电收纳尺寸、自主启动与出发后展开要求分别核实。
- E 核对 `RUN-06`、`CAL-05`、`MECH-06`。验证覆盖信号应用与停止，实际物料抓放、槽位标定、臂爪线缆扫掠及净距仍需现场证据。
- 本项无新增 Q 判断，整车方案的 `QR-04`、`FIELD-05`、`OBS-03` 继续待技术答疑确认。此处证据均为离线，没有烧录、示波器测量或实车操作。
