## 整车流程

| 段 | 目的地 | 到站任务 |
| --- | --- | --- |
| 1 | 从启停区 1（格 4）或区 2（格 0）到扫码格 2 | UART5 接收本轮合法四段码，一次锁存和记录原码，后台更新 `page0`。若无码，沿场地 +X、−X 在允许范围内小幅横移重扫。有码且底盘停稳即可接下一腿，屏显异步完成。 |
| 2 | 原料格 14，朝 +Y | 视觉精纠偏后按第 1 段颜色顺序逐件抓取和装槽。 |
| 3 | 粗加工格 10，停点 (290,1200) mm，朝 −Y | 视觉精纠偏后，按第 2 段环位三放三收，三件回槽。 |
| 4 | 暂存格 22，中心 (1200,2160) mm，朝 −X | 按第 2 段平放空环，记录第一批逐件确认放稳的颜色与环位。 |
| 5 | 原料格 14，朝 +Y | 按第 3 段颜色顺序抓取第二批，逐件装入空槽。 |
| 6 | 粗加工格 10，使用同一停姿 | 按第 4 段环位完成第二批三放三收，三件回槽。 |
| 7 | 暂存格 22，使用同一停姿 | 按第 3 段颜色顺序、当前槽记录与第一批确认的色环映射码垛。视觉定位落点并检查目标的在位或稳定性，颜色映射由任务和库存给出。 |
| 8 | 返回抽签选中的同一启停区 | 主控核实回到对应区域并停稳，自动在 UART4 串口屏切到 `page1`。保留原来的“成功抓取次数”“成功放置次数”两行，直接显示本轮已确认结果。切页无需裁判口径开关或人工操作。 |

以规则示例 `156+123+516+231` 验证映射。第一批红、黑、浅蓝落环 1、2、3。第二批黑、红、浅蓝在粗加工落环 2、3、1，到暂存则叠在环 2、1、3。所有工位只消费本轮扫码任务，槽位记录和动作回执按本轮、批次、工位和件号绑定。整场共用任务身份，每次工位请求使用新的递增编号，重复回执不能重复记账或执行。

## 从导航到工位

- 雷达返回的当前路径目标格与整车段序决定工位及批次。主控用同一轮地图、当前实际位姿、目标航向、停车确认和四轮反馈确定到站。经过工位格不会直接触发。视觉修正完毕后，下一腿使用车辆最新测得的姿态。
- 末段低速直行时，由主控按**实际沿路径剩余距离**在约 50 mm 处尝试一次预定位。联合扫掠验证合格时，只允许 DM4310 和伸缩在安全高度进入视觉预备位。若需要转弯、余距或净空不足，完成停车后再预定位。底盘与机构都停稳后才接受本轮新鲜视觉观测并做精纠偏，随后执行下降和抓放。
- 底盘导航、局部视觉纠偏和机构动作通过同一控制权交接，底盘停稳后按站自动调用模块。每个工位完成运输收臂、确认货物状态及轮端控制权释放，才接下一腿。沿用已确认的安全顶、X0、DM0 顺序和队友 PB9 机构标定。
- 远端活动派发接口已有 Source、Rough、Stack。第一批暂存复用 Stage3 已有平放分支，补独立的暂存入参、暂存实车标定与平放完成后的收臂尾段。第二批码垛复用 Stack，并将已确认的底料环位传入。粗加工的环位标定和高度不直接套作暂存实测。第一批某环未确认放稳时，按真实库存状态处理该目标。
- 预计动作时间只记诊断。短暂丢帧重新取样。安全且有可信进展的动作继续，持续无进展先做有界恢复，恢复失败按故障处理。核对导航、区域派发、精调、轴组和低层启动各自的旧截止，覆盖驱动严重故障、停不住和过期反馈。

## 香橙派和屏显

- 竞赛视觉上电自启，预先读取参数并构建各工位处理链，相机和串口各有一个所有者。普通行驶期间保持程序就绪，停用工位识别和纠偏输出。用 STM32 本轮站点、批次、姿态身份启动对应处理，换站清理旧帧和跟踪状态。验收从工位激活到首个有效新帧的时间。
- 现场在香橙派直接接 HDMI 屏和键鼠，用原有颜色标定工具在待机调试阶段预览六色 HSV 并保存。调色工具和比赛入口指向同一个本地持久配置。退出调色后由正式入口接回相机。断网冷启验证上次保存的值确实被活动识别分支载入，覆盖蓝与浅蓝辅助分支。更新程序时保留现场配置。
- `page0` 显示四段完整任务码。回区停稳后，`page1` 使用现有 HMI 两行，确认事件去重后计数。物料转移动作与计数证据分别保留，屏发送或切页不进入底盘控制环。
