# 工位机构软件接续

2026-11-20。活动机构和轴驱动来自队友提交 `f0393093`，本地导航的轮端有界 CAN 接口沿用现有实现。原料、粗加工、暂存底层、暂存码垛按整车工位票据进入同一个机构派发器。原料完成及粗加工、暂存完成均经过安全顶、X0、DM0。粗加工每件回收时也先到安全顶、缩回 X0，再转到载盘。工位流程取消固定动作总时长的退出条件，轴组保留按反馈位置进展刷新的监督。驱动故障、回零保护和停止回执仍参与判断。

暂存底层按用户确认复用粗加工三环动作几何，码垛层减少下降 60 mm，即 24000 虚拟脉冲。按环 1、2、3，底层约 61802.22、60795.02、63002.22 脉冲，码垛层约 37802.22、36795.02、39002.22 脉冲。它们是工程设置，需在暂存区按停姿、载物和真实净空验收。

工位按任务、批次、件号与色环绑定，放置等释放后保持原环位的机械观察姿态，收到新鲜稳定占位观测才确认。夹爪与载盘没有独立的落件及夹紧反馈，相关源区及回槽回执使用舵机命令、已知停留和轴组状态，实际抓牢及装槽待实车核对。

MATLAB R2020a 实际运行 `check_station_axes.m` 的 128 条模型轨迹，另核三环上下层深度、指定色环映射、生产举升深度边界及有进展的长动作。见 `matlab-station-axes.log`、`matlab-storage-depth.log` 和 `matlab-storage-progress.log`。使用 Keil ARMCC 分别以正式和 Offline 宏编译 8 个机构源码单元，两套均 0 错误 0 警告。整机链接及实车结果以各自报告为准。

已核规则 R `SRC-01/02`、`VIS-01`、`RUN-01/02/04/07`、`MECH-01/02`、`PWR-01`。工程 E 涉及 `MOT-03/04`、`VIS-10/12/14/15`、`CAL-05`、`RUN-06`。裁判统计和未发布的官方口径仍待技术答疑确认。未进行硬件操作。
